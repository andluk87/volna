# Волна 0.12.27: редактор, звонки, аккаунты и интерфейс клиентов

Windows использует вертикальные папки слева, список чатов и область переписки. Названия, правила, исключения и включения папок остаются общими с Android/Web. Правая кнопка на папке открывает настройку или удаление; правая кнопка на чате позволяет добавить его в папку. Удаление папки сохраняет переписки.

Эмодзи открываются над полем ввода. При ширине окна от 1250 пикселей доступна отдельная правая колонка: панель не перекрывает переписку и остаётся открытой при наборе текста. Кнопка в заголовке закрепляет/открепляет панель. При уменьшении окна она возвращается во всплывающее размещение. Открытая панель информации имеет приоритет над колонкой эмодзи.

Список закреплённых сообщений открывается в области чата. Можно вернуться в переписку или открепить все сообщения после подтверждения, если позволяют права чата. Сервер проверяет права каждого изменения; при частичной ошибке список перечитывается. Контакты, история звонков, настройки и профиль в Windows открываются поверх переписки. Цвета обновляются вместе с общей темой.

История звонков Web/Windows объединена с сообщениями по времени. Видны направление, аудио/видео, время и длительность; нажатие повторяет звонок. Общий список доступен из меню и настроек. Сервер выдаёт страницы по 50 записей; общий список поддерживает «Ещё звонки», переписка показывает последние 50 записей в загруженном диапазоне сообщений. Очистка истории с подтверждением скрывает ваши завершённые звонки на всех клиентах; история собеседника и активные звонки сохраняются. Чатовые записи перечитываются каждые пять секунд.

«Звук и камера» сохраняет выбор устройств локально для следующих звонков. Проверка микрофона и предпросмотр камеры запрашивают разрешения только по нажатию. Проверка останавливается при закрытии окна, смене устройства или нажатии остановки; видеопредпросмотр не передаёт изображение собеседнику. Если выбранное устройство отключено, отображается ошибка; можно вернуть «По умолчанию». Windows открывает системную панель звука фиксированной командой `ms-settings:sound`. Доступность выбора выхода в Web зависит от `setSinkId` браузера.

Локальный переключатель приёма звонков отключает показ входящего звонка в этом открытом клиенте, позволяя ответить с другого устройства. Он не изменяет системные настройки Android и подписки Web Push: эти уведомления настраиваются отдельно в разделе уведомлений.

Android больше не отключает текстовый редактор во время отправки. Текст сразу становится обычным пузырём с индикатором ожидания; поле освобождается, сохраняет фокус и клавиатуру. Собственная текстовая отправка не запускает переход с подсветкой всей строки. Переходы к закреплениям, найденным сообщениям и ответам сохраняют подсветку.

Если Android-отправка не удалась, текст возвращается в пустое поле. Если уже набрано следующее сообщение, исходный текст и пользовательские эмодзи сохраняются в локальной очереди аккаунта; кнопка «Вернуть неотправленный текст» позволяет восстановить их без перезаписывания текущего черновика. Web/Windows сохраняют ошибочную отправку в пузыре с кнопкой повтора и следующий текст в редакторе.

Проверено: 136 Node-тестов без пропусков, 68 Android unit-тестов без пропусков, сборка и проверка APK версии 12027, React render, сборка Web, Windows NSIS и его метаданные/контрольные суммы. Браузерный сценарий использует реальные компоненты приложения и API с тестовыми SMS-сессиями; Windows bridge имитируется. Проверены ширины 1140/1436, переключение темы, папки/переименование/удаление, размещение эмодзи, модальные контакты/звонки, проверка микрофона и захват именно выбранной камеры, очистка и открепление, задержанная отправка с сохранением следующего текста. Проверки папок/уведомлений и видеозвонков выполнены повторно. Видеопроверка использует тестовые камеры и имитацию ICE, поскольку политика облачного Chromium блокирует UDP; это проверка управления медиатреками, а не качества сети TURN.

После обновления на физическом Android проверьте несколько отправок подряд с открытой клавиатурой, набор до подтверждения предыдущего сообщения и восстановление текста при отключении сети. На Windows 10 проверьте смену темы, папки, изменение ширины окна, меню/контакты/закрепления, выбранные реальные микрофон/камеру/наушники и звонок через вашу сеть TURN. Сборки в облаке используют проверочный API `example.invalid`; для установки используйте сборку на вашем сервере с прежними `.env` и подписью Android по [инструкции](UPDATE-0.12.27.md).


## Форматирование во всех клиентах

Доступны жирный (`**текст**`), курсив (`__текст__` или `*текст*`), подчёркнутый (меню), зачёркнутый (`~~текст~~`), моноширинный (одинарные обратные апострофы), блок кода (тройные апострофы), скрытый (`||текст||`), цитата (`> текст`) и гиперссылка. В Web/Windows меню открывается правой кнопкой в редакторе или через вложения → форматирование. Android: кнопка форматирования рядом с вложениями. На физической клавиатуре поддержаны Ctrl/Cmd+B/I/U/K. Сначала выделите текст; без выделения вставляется заготовка.

Для блока кода можно указать язык, например `js`, `python`, `json`, `sql`, либо оставить поле пустым. Подсветка выполняется безопасным лексическим разбором, код никогда не запускается. Подчёркивание сериализуется ограниченной конструкцией `<u>текст</u>`; произвольный HTML не поддерживается и отображается как текст. `__` теперь означает курсив согласно ТЗ; старые сообщения с этим маркером также показываются курсивом. Разметка сохраняется в тексте сообщения, поэтому читается одинаково между клиентами. Пользовательские эмодзи сохраняют диапазоны после форматирования.

Спойлер скрыт до нажатия; повторное нажатие скрывает его снова. При создании ссылки через меню допускается только HTTP(S), активные схемы и адреса с логином/паролем отклоняются. В Windows контекстное меню использует Electron/Chromium: редактирование, форматирование, предложения исправления и добавление слова в словарь. Доступность словаря зависит от системной проверки орфографии и загрузки словарей Chromium. В Web проверка орфографии остаётся функцией браузера. Отмена и повтор в редакторе поддерживают текст и пользовательские эмодзи.

## Аудиофокус Android

Самоуправляемый звонок Telecom получает системный аудиофокус через `ConnectionService.onConnectionServiceFocusGained`; приложение больше не запрашивает его повторно через AudioManager. Принятый входящий звонок переводится в активное состояние до инициализации WebRTC. При отсутствии поддержки Telecom используется обычный запрос с ожиданием отложенного разрешения; отменённый звонок прекращает ожидание. Поздно созданное системное соединение не перехватывает звук у резервного режима. Потеря системного фокуса освобождает микрофон/камеру и подтверждается Android.

Причина ошибки из диагностики .26 соответствует отказу отдельного запроса AudioManager; конфликт владения фокусом исправлен в коде. Это не заменяет проверку на Samsung SM-S731B Android 16: в облаке физического устройства нет. Проверьте исходящий/входящий вызовы, заблокированный экран, повторный вызов после завершения, гарнитуру и входящий обычный телефонный звонок. Управление физическими кнопками по-прежнему делегируется Telecom и системным настройкам; ограничение производителя не обходится принудительным перехватом.

Официальный контракт: [ConnectionService — получение и освобождение фокуса](https://developer.android.com/reference/android/telecom/ConnectionService#onConnectionServiceFocusGained()).

## Уведомления нескольких аккаунтов Android

Каждый сохранённый аккаунт получает собственную подписку событий. Переключение экрана, выход из одного аккаунта и обновление его токена не отключают остальные подписки. Сообщения и реакции используют независимые теги и ссылки перехода; одинаковый групповой чат на разных аккаунтах не подавляет уведомление невыбранного аккаунта. Настройки звука и предварительного просмотра остаются отдельными для каждого аккаунта.

Для звонков невыбранных аккаунтов выполняется отдельная проверка и показывается уведомление с именем аккаунта и переходом в его чат. После перехода работает обычный экран входящего звонка. Звонок другого аккаунта не захватывает микрофон текущего разговора и не переключает аккаунт автоматически; прямое принятие с полноэкранной системной карточки остаётся у выбранного аккаунта. Одновременно приложение ведёт один разговор. Уведомление закрывается после завершения/ответа или передачи выбранному аккаунту.

На устройстве: войдите в два аккаунта, отправьте каждому сообщение и реакцию при открытом чате другого аккаунта, затем в фоне и при блокировке экрана; нажмите каждое уведомление и проверьте открытие нужного аккаунта. Повторите после выхода из одного аккаунта и для входящих звонков. Доставка зависит от разрешения уведомлений, каналов, фоновой работы и настроек энергосбережения Android. Web/Windows сохраняют текущую модель одного подключённого сеанса.
