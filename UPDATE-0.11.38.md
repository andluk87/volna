# Волна 0.11.38 — переработка Android

Полный исходный проект: нативный Android на Kotlin/Jetpack Compose, Windows на Electron, Web, API, распознавание голоса и Docker-сборщики обоих клиентов. Версия package/lock-файлов и Android versionName — 0.11.38, Android versionCode — 11038. Новые Android-экраны используют API Волны, без WebView.

## Обновление на действующем VPS

Загрузите новый архив в домашний каталог рядом с существующим проектом и распакуйте поверх него. Существующие `.env`, база, вложения, модели, резервные копии и `artifacts` остаются на месте:

```sh
cd ~
unzip -o volna-messenger-0.11.38.zip -d .
cd volna-messenger
VOLNA_BUILD_NETWORK=host sh scripts/build-clients.sh
```

Это сборка Android и Windows в Docker с публикацией обновлений и одним обновлением сервера/Web после успешной сборки обоих клиентов. `host` предусмотрен для Linux VPS при проблемах DNS в сети сборщика. Если обычная сеть Docker работает, достаточно `sh scripts/build-clients.sh`.

Если сейчас нужен только новый Android и сервер/Web:

```sh
VOLNA_BUILD_NETWORK=host sh scripts/build-android.sh
```

Для Windows отдельно: `VOLNA_BUILD_NETWORK=host sh scripts/build-windows.sh`. Для сервисов без сборки клиентов: `VOLNA_BUILD_NETWORK=host sh scripts/update.sh`. `build-android.sh` не пересобирает Windows; для обоих клиентов используйте `build-clients.sh`.

Сохраняйте весь `artifacts`, особенно ключ подписи в `artifacts/android-home`: без прежнего ключа Android не установит новую версию поверх старой. Ограничения CPU сборщиков не добавлены. Кеши SDK, Gradle, npm, Electron и NSIS остаются постоянными. При первой сборке этого выпуска могут скачаться новые компоненты Coil для GIF и видео; далее они используются из кеша. Режим `ANDROID_BUILD_OFFLINE=auto` сначала пробует кеш и при отсутствии зависимости один раз повторяет сборку с сетью.

Если TURN уже работает, его настройку повторять не нужно. Для первоначальной настройки предусмотрено `VOLNA_BUILD_NETWORK=host sh scripts/build-clients.sh --enable-calls`.

## Что изменено в Android

- Нижняя навигация «Чаты / Контакты / Звонки / Профиль», компактные строки, одинаковые контурные иконки, фильтры, архив, пользовательские папки и переключение сохранённых аккаунтов. Положение списков сохраняется при переходе между разделами.
- Общий поиск по именам, username, названиям чатов и текстам доступных сообщений. Нажатие на результат или блок ответа открывает исходное сообщение, включая старую историю.
- Пузырьки до 75% ширины и 560 dp, группировка автора, тихие метаданные, ссылки, реакции, список участников реакции, меню долгим нажатием и выбор до 50 сообщений.
- Поле ввода растёт до шести строк. Запись и реальная звуковая волна находятся на месте поля ввода; микрофон пульсирует во время записи. Удержание — запись, отпускание — отправка, смахивание влево — отмена, вверх — фиксация. Сохранён режим короткого нажатия: начать / повторным нажатием отправить. AAC, 48 kHz, 128 kbit/s, mono; расшифровка выполняется сервером.
- Неотправленное голосовое сохраняется в личном хранилище приложения. После ошибки или перезапуска доступен повтор с прежним идентификатором сообщения и уже загруженным вложением. Запись удаляется после подтверждения отправки либо отмены пользователем.
- Панель вложений: галерея, камера, файлы, местоположение, контакты и музыка. До десяти фото/видео в альбоме; подпись необязательна. Место определяется по отдельному разрешению Android или вводится вручную; отправляется после подтверждения. Контакт отправляется именем и username. GIF и WebP можно выбрать с устройства.
- Полноэкранные профили пользователей и групп, редактирование собственных данных, вкладки медиа/файлов/ссылок/голосовых/анимаций. Для групп сохранены роли, приглашения, блокировки, передача владения и добавлен режим публикации только администраторами.
- Настройки карточками: аккаунт, оформление, безопасность, уведомления, память, папки и устройства. Светлая/тёмная/системная тема, фон чата, акцент, цвет исходящих, текст, размер интерфейса, плотность, радиус, аватары, время, анимации и энергосбережение с предпросмотром.
- Реальная история звонков на сервере. Камера с собственным предпросмотром и переключением сторон; камера и показ экрана переключаются отдельно. Сворачивание звонка, выбор аудиовыхода, гудки, фоновые сервисы и экран входящего вызова сохранены. Web/Windows отображают видео камеры, приходящее с Android.
- Последние сообщения, чаты, контакты, история звонков и просмотренные профили доступны из локального кеша. При новых сообщениях во время чтения старой истории положение сохраняется; появляется переход к последним. Статус прочтения отправляется по видимым сообщениям. Уведомления открывают нужный аккаунт, чат и сообщение.

Полная карта требований и оставшихся различий: [ANDROID-REDESIGN-0.11.38.md](ANDROID-REDESIGN-0.11.38.md).

## Скачивание и обновления

После успешной сборки на вашем VPS:

- Android: `https://volna.lknet.ru/download/volna-android.apk`.
- Android-манифест: `https://volna.lknet.ru/download/volna-android-version.json` — version_name 0.11.38, version_code 11038.
- Windows: `https://volna.lknet.ru/download/volna-windows.exe`.
- Windows-feed: `https://volna.lknet.ru/download/windows/latest.yml` — version 0.11.38.

Установленные клиенты используют прежний механизм проверки обновлений. Android скачивает и проверяет APK внутри приложения, затем показывает системное подтверждение установки. Windows использует свой feed. Бинарные файлы не включены в исходный ZIP: их создают сохранённые Docker-сборщики. Здесь APK/EXE не собирались — в среде нет Docker/Android SDK.

Проверьте опубликованные файлы:

```sh
sh scripts/check-downloads.sh all
docker compose ps
curl -fsS https://volna.lknet.ru/download/volna-android-version.json
```

## Проверка на телефоне после установки

1. Установите 0.11.38 поверх старого APK. Проверьте вход через Telegram и пароль, четыре раздела, поиск, возврат из чата и переключение аккаунтов.
2. Отправьте многострочный текст; ответьте на старое сообщение, откройте оригинал, измените сообщение, поставьте реакцию и выберите несколько сообщений. Прочитайте историю и получите новое сообщение с Web: список должен сохранить место чтения.
3. Проверьте оба режима записи, отмену и фиксацию, скорость/перемотку и расшифровку. Отключите сеть перед отправкой, перезапустите приложение, включите сеть и повторите: голосовое должно прийти один раз.
4. Отправьте несколько фото, фото с камеры, GIF и документ; откройте, сохраните и поделитесь вложением. Проверьте выдачу разрешения на местоположение и предварительный просмотр координат до отправки.
5. Проверьте темы, увеличенный системный текст, три кнопки навигации/жесты Android и клавиатуру. Очистите кеш медиа: черновики и неотправленные голосовые должны остаться.
6. Позвоните Android ↔ Android и Android ↔ Web/Windows. Проверьте камеру, её выключение и смену, показ экрана, микрофон, аудиовыход, сворачивание и входящий вызов с погашенным экраном. Для проверки TURN используйте разные сети. После завершения проверьте историю.
7. Проверьте уведомления о сообщении, ответе, упоминании и реакции. Нажатие должно открыть нужную переписку и сообщение, включая другой сохранённый аккаунт.

Результаты автоматических проверок и ограничения: [VALIDATION.md](VALIDATION.md). Компиляция Kotlin и JVM-тесты запускаются Docker-сборщиком до публикации APK; ошибка останавливает выпуск. Проверки исходников/API здесь не заменяют испытания телефона.
