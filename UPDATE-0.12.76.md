# VLN 0.12.76 — просмотр медиа по ТЗ

Фото и видео листаются по общей истории чата, включая разные сообщения и альбомы. При открытии старого файла сервер отдаёт соседний диапазон, затем страницы в обе стороны; вся медиатека не скачивается заранее. Жесты 1–4×, перемещение увеличенного фото, двойное касание, скрытие панелей и закрытие вниз. Отправитель, время, подпись, информация, кеш, повтор загрузки и синхронизация удаления. Галерея с фильтрами, месяцами и 3–4 колонками.

Из прежней папки сервера с `compose.yaml` и существующим `.env`, одной вставкой:

```sh
( set -eu; test -f compose.yaml && test -f .env; volna_update_dir=$(mktemp -d); trap 'rm -rf "$volna_update_dir"' EXIT; git clone --depth 1 --branch v0.12.76 https://github.com/andluk87/volna.git "$volna_update_dir/source"; git -C "$volna_update_dir/source" archive --output="$volna_update_dir/source.tar" HEAD; sh "$volna_update_dir/source/scripts/backup.sh"; if [ -d android-native/app/src ]; then mkdir -p backups; volna_source_backup=$(mktemp -d "$PWD/backups/android-source-0.12.76-XXXXXXXX"); mv android-native/app/src "$volna_source_backup/src"; fi; tar -xf "$volna_update_dir/source.tar" -C .; sh scripts/build-clients.sh )
```

Команда создаёт резервную копию, сохраняет прежние исходники Android в `backups/`, загружает тег `v0.12.76` и запускает общий сборщик. `.env`, база, аккаунты, переписки и ключ подписи Android сохраняются.

После сборки откройте в VLN `Настройки → Обновления → Проверить обновления` и подтвердите установку поверх прежней версии. Обновите Windows поверх прежней версии и перезагрузите Web через `Ctrl+F5`.

Проверьте: откройте не последнее фото в длинном чате; пролистайте конец альбома и видео. Увеличьте фото и потяните вбок — должно переместиться фото, а не смениться файл. Закройте просмотр: переписка остаётся на прежнем месте. В галерее переключите фильтры и плотность сетки. Удаление текущего элемента выбирает ближайший доступный.

Кеш Web/Windows ограничен текущей сессией; Android хранит файлы отдельно для аккаунтов. Отозванный доступ проверяется сервером, контекст удалённого сообщения больше не открывает файл по старой ссылке.

Проверено: 170 Android-тестов, 199 Node-тестов, сборки и браузерные сценарии; APK ~103.1 МиБ, ниже старого лимита обновления.

[Подробное соответствие ТЗ, API, проверки и границы](docs/MEDIA-VIEWER.md). Нативного iOS-проекта нет; на iPhone используется Web. Замеры 60 FPS/150 мс на физических устройствах и запуск Windows EXE здесь не выполнялись. Календарь и CDN относятся к расширенному этапу.
