# VLN 0.12.65 — оформление Windows

## Папки и поле сообщения

Боковая панель Windows получила залитые иконки папок и двух облаков для «Все чаты». Неактивные папки серые, выбранная использует общий акцент темы и ровную подложку. Цвет метки папки больше не окрашивает её кнопку в панели: он сохраняется в настройках и метках чатов. Счётчик расположен у верхнего края иконки, не разрывается на строки; у неактивной папки он серый, у выбранной и «Все чаты» — акцентный. Вместо шестерёнки «Ред.» показаны ползунки.

Поле ввода — ровная полоса высотой 48 px: скрепка слева, текст, эмодзи справа и микрофон у правого края. Убраны лишние отступы и обводка; значки и базовая линия текста выровнены. При нескольких строках поле растёт, при наличии текста микрофон сменяется отправкой. Сохранены вложения, голосовые, форматирование и выбор эмодзи.

## Верхняя полоса окна

В Windows используется `titleBarStyle: hidden` с нативными кнопками через Electron `titleBarOverlay`. Полоса высотой 28 px окрашена в тему приложения и не зависит от системного серого цвета активного/неактивного заголовка. Она остаётся областью перетаскивания; системные сворачивание, разворачивание, закрытие и изменение размеров сохраняются. Обновление светлой/тёмной темы передаётся отдельным проверяемым IPC-вызовом текущему окну, включая дополнительные окна чатов.

Окно переписки, меню, диалоги, информация, панель эмодзи и звонка учитывают высоту полосы. Контекстное меню сообщения также не заходит под неё. Профиль Windows, путь `userData`, сеансы, автообновление и разрешения не изменены. На других ОС сохраняется прежняя системная рамка.

Нативный Android остаётся **0.12.64** с темами из предыдущего выпуска; его оформление и версия не меняются.

## Обновление одной командой

Запустите из прежней папки сервера с `compose.yaml`, `.env` и `artifacts`:

```sh
( set -eu; test -f compose.yaml && test -f .env; volna_update_dir=$(mktemp -d); trap 'rm -rf "$volna_update_dir"' EXIT; git clone --depth 1 --branch v0.12.65 https://github.com/andluk87/volna.git "$volna_update_dir/source"; git -C "$volna_update_dir/source" archive --output="$volna_update_dir/source.tar" HEAD; sh "$volna_update_dir/source/scripts/backup.sh"; if [ -d android-native/app/src ]; then mkdir -p backups; volna_source_backup=$(mktemp -d "$PWD/backups/android-source-0.12.65-XXXXXXXX"); mv android-native/app/src "$volna_source_backup/src"; fi; tar -xf "$volna_update_dir/source.tar" -C .; sh scripts/build-windows.sh )
```

Команда делает резервную копию, обновляет исходники по тегу, собирает и публикует Windows-установщик и ленту обновления, обновляет сервер/Web. Прежние Android-исходники сохраняются в `backups`, чтобы последующие сборки не подхватили устаревшие файлы; APK при этом не пересобирается. `.env`, данные и ключи подписи сохраняются.

После завершения обновите Windows-клиент через приложение или `/download/volna-windows.exe`. Новая рамка появляется после установки и перезапуска клиента, а не только после обновления сервера.

## Проверка

Проверяется настоящий интерфейс в Chromium с имитацией Windows bridge: переключение папок разных цветов, счётчик из трёх цифр, расположение элементов ввода, отправка нескольких строк, светлая/тёмная тема, потеря фокуса, узкое окно и расположение панелей ниже заголовка. Снимки сравниваются визуально. Дополнительно проверяются параметры нативной рамки, IPC-входные данные, размещение контекстного меню, рендер React, прежние меню/реакции и полоса обновления, production-сборка Web.

Сам Windows-установщик и системные кнопки на настоящей Windows в этой Linux-среде не запускались; их проверка выполняется после сборки на целевой машине.
