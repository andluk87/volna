# VLN 0.12.64 — темы групп на Android

Доработка относится к Android и серверному контракту тем. Общая навигация приложения, папки, оформление чатов и Windows-интерфейс сохраняются.

## Что изменилось

- Полноэкранный список тем с аватаром группы, участниками, поиском и меню. Вместо больших карточек — компактные строки: эмодзи, название, автор и превью последнего сообщения, время, непрочитанное, закрепление, закрытие и отключённый звук.
- Закреплённые темы идут первыми в заданном порядке, остальные — по последнему сообщению. Открытие темы не меняет порядок.
- Долгое нажатие открывает действия: перейти, отметить прочитанной, настроить уведомления, скопировать ссылку, изменить, закрепить, переместить, закрыть или удалить при наличии прав. Системная общая тема не удаляется; её можно скрыть.
- Создание и редактирование вынесены на отдельный экран. Можно выбрать эмодзи из встроенного каталога с категориями и поиском или оставить стандартный значок. Название — 1–64 кодовых точки Unicode; одинаковые названия допустимы. Новая тема открывается после успешного ответа сервера.
- Меню переключает список тем, общую ленту и горизонтальные вкладки. Вкладки показывают иконки и непрочитанное, прокручиваются к выбранной теме. Режим сохраняется на устройстве для группы. Возврат из темы открывает список.
- В переписке темы используются существующие сообщения, вложения, реакции, ответы и отдельные черновики. В шапке темы показаны её название и значок, под ними — родительская группа. Сохраняется последнее показанное сообщение для возврата к позиции чтения.
- В общей ленте можно искать по сообщениям всех тем и переходить по метке к конкретному сообщению. Состояние прочтения обновляется для реально показанных сообщений соответствующих тем; поиск не отмечает всю историю прочитанной.
- Настройки уведомлений темы: наследовать группу, все сообщения, упоминания/ответы, без звука, полностью отключить. Режим «Без звука» использует отдельный Android-канал без звука и вибрации и не сбрасывает счётчик.
- Темы включаются владельцем; создание и управление имеют отдельные политики. Участник, создавший тему, не получает административных прав на её изменение/удаление. Администратору можно разрешить управление либо оставить его владельцу. Сервер проверяет права независимо от интерфейса.
- Не более пяти закреплённых тем. API поддерживает 1000 тем, курсорную выдачу страницами; Android-список загружает по 50 и использует LazyColumn. Поиск учитывает регистр кириллицы и ё/е.
- Административные действия записываются в `topic_audit`. В событиях существующего транспорта передаётся `topic_event`; редактирование Android передаёт ревизию, устаревшее изменение отклоняется с 409. После переподключения данные обновляются.

Отключение режима сохраняет истории и темы. Общая лента доступна через меню. Удаление темы требует явного подтверждения и возвращает открывшийся экран к списку.

## Обновление одной командой

Выполните из прежнего каталога сервера, где находятся `compose.yaml`, `.env` и `artifacts`:

```sh
( set -eu; test -f compose.yaml && test -f .env; volna_update_dir=$(mktemp -d); trap 'rm -rf "$volna_update_dir"' EXIT; git clone --depth 1 --branch v0.12.64 https://github.com/andluk87/volna.git "$volna_update_dir/source"; git -C "$volna_update_dir/source" archive --output="$volna_update_dir/source.tar" HEAD; sh "$volna_update_dir/source/scripts/backup.sh"; if [ -d android-native/app/src ]; then mkdir -p backups; volna_source_backup=$(mktemp -d "$PWD/backups/android-source-0.12.64-XXXXXXXX"); mv android-native/app/src "$volna_source_backup/src"; fi; tar -xf "$volna_update_dir/source.tar" -C .; sh scripts/build-android.sh )
```

Команда сохраняет резервную копию, обновляет исходники по тегу, собирает APK и обновляет сервер. Прежние Android-исходники сохраняются отдельно в `backups`. Ключ подписи остаётся в существующем `artifacts/android-home`: APK необходимо собирать в прежней установке и устанавливать поверх, сохраняя данные приложения. После сборки обновите телефон через приложение либо `/download/volna-android.apk`.

## Границы проверки ТЗ

Этот выпуск использует действующие числовые идентификаторы чатов/тем и сообщений вместо замены базы на UUID. Общая тема остаётся прежним чатом группы; старое название «Общие вопросы» не переименовывается автоматически. Черновики, режим отображения и позиция чтения хранятся на устройстве, права/уведомления/прочитанность — на сервере.

Нагрузочный SLO p95 500 мс на целевом сервере требует отдельного замера. Это не выпуск для iOS и не трёхколоночный Desktop-интерфейс из ТЗ. Нативный APK проверяется сборкой и Robolectric/Compose; проверка на физическом телефоне остаётся необходимой перед широким развёртыванием.

Проверено перед выпуском: 188 общих Node-тестов; отдельные проверки новых ограничений и совместимости старых названий; 127 Android-тестов, включая Compose-сценарии списка, меню и создания с эмодзи; сборка APK 12064 и наличие встроенного каталога/шрифта. Снимки списка проверены в светлом и тёмном оформлении.
