# VLN 0.12.79 — Android: аватарка собеседника в уведомлении

Для уведомлений сообщений фото передаётся в Android Person, крупное изображение и ярлык диалога. Android/One UI сам добавляет маленький значок VLN поверх аватарки. При отсутствии фото используется круг с инициалами; фото группы и автора сообщения разделены.

Изображение догружается в фоне и обновляет ту же карточку без повторного звука. Повторные уведомления используют кеш; карточки, которые уже удалены или прочитаны, не должны появляться заново из-за завершившейся загрузки изображения. Источники данных и проверка авторизации разделены между аккаунтами.

Из прежней папки сервера с `compose.yaml` и существующим `.env`, одной вставкой:

```sh
( set -eu; test -f compose.yaml && test -f .env; volna_update_dir=$(mktemp -d); trap 'rm -rf "$volna_update_dir"' EXIT; git clone --depth 1 --branch v0.12.79 https://github.com/andluk87/volna.git "$volna_update_dir/source"; git -C "$volna_update_dir/source" archive --output="$volna_update_dir/source.tar" HEAD; sh "$volna_update_dir/source/scripts/backup.sh"; if [ -d android-native/app/src ]; then mkdir -p backups; volna_source_backup=$(mktemp -d "$PWD/backups/android-source-0.12.79-XXXXXXXX"); mv android-native/app/src "$volna_source_backup/src"; fi; tar -xf "$volna_update_dir/source.tar" -C .; sh scripts/build-clients.sh )
```

Команда создаёт резервную копию, сохраняет прежние исходники Android в `backups/`, загружает тег `v0.12.79` и запускает общий сборщик. `.env`, база, аккаунты, переписки и ключ подписи Android сохраняются.

После сборки откройте в VLN `Настройки → Обновления → Проверить обновления` и подтвердите установку поверх прежней версии. Обновите Windows поверх прежней версии и перезагрузите Web через `Ctrl+F5`.

После сборки обновите Android до 0.12.79 и проверьте **новое входящее сообщение**. Старая карточка в шторке могла быть создана предыдущей версией.

Проверка на телефоне:

1. В чате у собеседника должно быть установлено фото. Сверните VLN и получите сообщение.
2. В шторке должна появиться аватарка; небольшой значок приложения рисует система в своём стандартном месте (на вашем One UI — справа снизу).
3. При медленной сети сначала возможны инициалы, затем фото без повторного сигнала. Без фото остаются инициалы.
4. Проверьте быстрый ответ, переход в чат и групповое сообщение. Догрузка фото не должна возвращать уже убранную карточку.

Проверено: 186 Android unit/UI-тестов, включая реальные данные Notification/Person/Shortcut и Android 8.1; сборка APK (~103 МиБ, все четыре ABI, ниже прежнего лимита 120 МиБ); 210 Node-тестов, React render-тесты и production-сборка Web. Фактическое отображение шторки Samsung/One UI здесь проверить нельзя — нужен ваш телефон. Windows-исправление авторизации 0.12.78 сохранено.
