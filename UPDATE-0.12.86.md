# VLN 0.12.86 — Android по видео-референсу и публикации

Обновлены основные экраны Android: палитра, размеры строк и аватаров, профиль, настройки, контакты и звонки. В профиле работают публикации с текстом/фото/видео и личный архив. Подробности: [результат по ТЗ](docs/ANDROID-TELEGRAM-STYLE.md).

Из прежней папки сервера с `compose.yaml` и `.env`, одной вставкой:

```sh
( set -eu; test -f compose.yaml && test -f .env; volna_update_dir=$(mktemp -d); trap 'rm -rf "$volna_update_dir"' EXIT; git clone --depth 1 --branch v0.12.86 https://github.com/andluk87/volna.git "$volna_update_dir/source"; git -C "$volna_update_dir/source" archive --output="$volna_update_dir/source.tar" HEAD; sh "$volna_update_dir/source/scripts/backup.sh"; if [ -d android-native/app/src ]; then mkdir -p backups; volna_source_backup=$(mktemp -d "$PWD/backups/android-source-0.12.86-XXXXXXXX"); mv android-native/app/src "$volna_source_backup/src"; fi; tar -xf "$volna_update_dir/source.tar" -C .; sh scripts/build-clients.sh )
```

После сборки установите Android 0.12.86 через `Настройки → Обновления`. Для публикаций требуется новый сервер; таблица добавляется автоматически. Данные, учётные записи и ключ подписи сохраняются.

Проверка: переключите четыре вкладки, вернитесь в чаты и проверьте позицию списка. В контактах проверьте поиск, обе сортировки и меню действий. В профиле проверьте выбор фото, редактирование и возврат из настроек. Создайте текстовую публикацию, затем фото/видео; с другого аккаунта проверьте просмотр. Перенесите запись в архив — другой аккаунт не должен видеть её или открывать вложение. Верните запись и проверьте удаление.

Светлая тема, выбранные шрифты, масштаб и кастомизация вкладок сохраняются. Значения по умолчанию следуют референсу; на телефоне с изменёнными настройками размеры и цвета могут отличаться.

Проверено: 198 Android unit/UI-тестов, 216 Node-тестов, render-тесты и production-сборка Web; APK 103.21 МиБ, четыре ABI, ниже лимита 120 МиБ. Два размера Android, сохранение прокрутки, профиль/архив и возврат из настроек проверены автоматически. Материалы сравнения предоставлены отдельным архивом.
