# Волна 0.12.98 — темы, просмотр медиа и варианты отправки

## Windows и Web

- Темы группы: вкладки или отдельный список слева, поиск тем, создание, переход между темами и общая лента «Все» с переходами в исходные темы. Выбор расположения общий для группы. Отключение тем сохраняет истории.
- Настройки группы: название, описание, права отправки, темы, реакции, приветствие, приглашения, участники, администраторы и недавние действия. Права проверяются сервером; настройки сохраняются кнопкой «Сохранить». Журнал собирает действия с момента обновления и ранее сохранённые действия с темами.
- Приветствие от службы «Волна» при новом вступлении; `{name}` подставляет имя. Пустой текст отключает приветствие. Реакции можно разрешить все, отключить или выбрать набор; ограничения действуют и в темах.
- Фотографии занимают доступное место без обрезания. Управление поверх изображения, боковые стрелки, подпись/автор/дата, миниатюры, масштабирование, рисование, сохранение и пересылка. Windows временно переключается в полный экран и возвращает прежний режим при закрытии.
- Открытый из переписки альбом листается только внутри этого альбома. Полная история фото и видео доступна через раздел медиа. Ограничение альбомов добавлено и в Android.
- Меню скрепки открывается при наведении мыши; на сенсорном экране сохраняется нажатие.
- Нажатие на дату открывает календарь. Выбранная дата загружается с сервера независимо от текущей прокрутки; для пустого дня выбирается ближайшая история. Доступна загрузка более ранних и новых сообщений, учитываются личная очистка истории и доступ к темам.
- Правая кнопка на кнопке отправки: «Отправить без звука», «Отправить позже», «Когда будет в сети» в личном чате; доступны анимированные эффекты. В меню чата есть список отложенных сообщений с отменой и отправкой сейчас.

Отложенная отправка хранится на сервере и продолжает работать при закрытом клиенте и после перезапуска. Вложения удерживаются до отправки/отмены. Перед отправкой заново проверяются права: при их утрате сообщение остаётся в списке с ошибкой. Ожидание активности работает только когда отправителю разрешено видеть статус получателя. Отправка в выбранное время зависит от работающего сервера; после остановки просроченная очередь обрабатывается при запуске.

## Голосовые и статус активности

Голосовые показывают кнопку воспроизведения, волну, длительность/размер и раскрываемую расшифровку обычным текстом по ширине сообщения. Расшифровка больше не сохраняется в базе сообщений или кэше Android, не рассылается другим устройствам и не возвращается в истории. Она живёт в памяти открытой карточки; сворачивание или закрытие убирает её, новое раскрытие запускает распознавание заново. Сервер удаляет старые значения поля при запуске, Android обновляет кэш без удаления исходных сообщений. Старые резервные копии автоматически не переписываются. Само голосовое сохраняется как раньше.

«В сети» означает видимое окно с фокусом хотя бы на одном устройстве. Фоновые вкладки, свёрнутый Windows и служба уведомлений Android не считаются активностью. Закрытие без доступной сети определяется по истечению подтверждения активности (до 25 секунд). Для недавнего посещения показываются секунды. Настройки приватности статуса сохраняются. **Обновите все клиенты:** старые версии не отправляют новый статус активного окна.

Распознавание остаётся локальным на сервере, модель и постоянный кэш не меняются. При отсутствии сети контейнера воспользуйтесь [импортом модели из 0.12.97](UPDATE-0.12.97.md). После подготовки модели сверните/раскройте расшифровку, чтобы распознать заново.

## Обновление одной вставкой

Из существующей папки проекта с `.env`:

```sh
( set -eu; test -f compose.yaml && test -f .env; volna_update_dir=$(mktemp -d); trap 'rm -rf "$volna_update_dir"' EXIT; git clone --depth 1 --branch v0.12.98 https://github.com/andluk87/volna.git "$volna_update_dir/source"; git -C "$volna_update_dir/source" archive --output="$volna_update_dir/source.tar" HEAD; sh "$volna_update_dir/source/scripts/backup.sh"; if [ -d android-native/app/src ]; then mkdir -p backups; volna_source_backup=$(mktemp -d "$PWD/backups/android-source-0.12.98-XXXXXXXX"); mv android-native/app/src "$volna_source_backup/src"; fi; tar -xf "$volna_update_dir/source.tar" -C .; python3 scripts/improve-transcription.py; VOLNA_BUILD_NETWORK=host sh scripts/build-clients.sh )
```

Установите Windows 0.12.98 и Android 0.12.98 поверх текущих приложений, Web перезагрузите. Сервер и клиенты должны быть обновлены вместе. Команда сохраняет резервную копию и использует существующие настройки адреса сервера; сборки этой рабочей среды с `example.invalid` предназначены только для проверки.

## Проверки

Проверены настоящий API и Chromium в режимах Web/Windows: наведение на скрепку, тихая отправка, выбор времени в отдельном диалоге, календарь с незагруженной историей, продолжение истории, общая лента, список тем и настройки группы. Отдельно проверены альбомы, видео и постраничная галерея на 205 сообщениях, масштабирование, удаление, офлайн-кэш, рисование и сохранение, временные расшифровки. 247 Node-тестов прошли. Серверные тесты проверяют восстановление очереди, однократную отправку, права, приватность, удержание вложений, календарь, приветствия, реакции и устаревшие сигналы активности. Собраны Web, Windows renderer и Android APK; выполнены 227 тестов Android, включая очистку кэша расшифровок. Физический Windows и телефон в этой среде недоступны; обновление на вашем сервере автоматически не выполнялось.
