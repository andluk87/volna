# Волна Native Desktop 0.1.3 — проверка соединения Windows

[Скачать установщик Windows x64](https://github.com/andluk87/volna/releases/tag/native-v0.1.3). Установите поверх 0.1.2, предварительно закрыв приложение; сеанс сохранится. Сервер обновлять не требуется.

Новый отчёт 0.1.2 показал, что все API-запросы завершаются через 20 секунд без HTTP-ответа. `http2: false` в таком отчёте не доказывает установленное HTTP/1.1-соединение: HTTP и TLS могли вообще не состояться. Точная причина на компьютере пока не установлена.

В 0.1.3 по умолчанию используется явное прямое подключение, без автоматического выбора прокси Windows. Для сетей с прокси есть режим «Системные настройки прокси» в настройках; смена режима применяется после перезапуска. Проверка сертификатов HTTPS сохраняется.

«Настройки → Проверить подключение» проверяет `/api/health` напрямую и через системные настройки без входа, запроса кода или изменения аккаунта. Кнопка копирования включает результаты и DNS-ответ для имени сервера. Если тайм-аут сохраняется, пришлите этот отчёт после завершения обеих проверок.

Диагностика обычных запросов теперь показывает выбранный режим, начало подключения, установление TLS, отправку HTTP, получение заголовков, шифр, числовой протокол TLS, ошибки сертификата и число принятых байтов. Есть также незавершённые запросы; `-1` означает, что соответствующее событие не наблюдалось (в том числе при повторном использовании соединения). `sent_ms >= 0` подтверждает отправку запроса, `headers_ms >= 0` — получение заголовков. Наличие TLS-бэкенда само по себе не подтверждает рукопожатие.

Записываются только метаданные в память процесса: тела, заголовки, сертификаты, пароли, токены, коды входа и текст поиска не сохраняются. Последние 40 завершённых операций дополняются активными запросами. Настройки прокси не содержат учётных данных.

Проверки охватывают режимы сети, два запроса встроенной проверки, этапы HTTP, отсутствие секретов в отчёте, настоящий тайм-аут и восстановление списка чатов. Windows-пакет отдельно проверяет запуск, HTTPS и QR. Ограничения предварительного клиента и лицензии — [desktop-native/README.md](desktop-native/README.md).
