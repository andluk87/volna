# VLN 0.12.63 — меню сообщения и выбор реакций Windows/Web

Контекстное меню правой кнопки теперь открывается поверх всего интерфейса, а не внутри области прокрутки сообщения. Оно размещается рядом с указателем, ограничивается границами переписки и окна, при нехватке высоты прокручивается. Боковая колонка и сообщения больше не обрезают его. То же работает при нажатии кнопки действий сообщения.

Над списком действий расположены быстрые реакции и круглая кнопка со стрелкой вниз. Она открывает палитру стандартных эмодзи с категориями и русско-английским поиском. Каталог содержит 3948 поддерживаемых сервером эмодзи из Unicode 17 / CLDR 48, загружается отдельным фрагментом при открытии, а сетка отображается порциями. Оттенок кожи, выбранный явно, не заменяется ранее сохранённым тоном.

Реакция применяется/снимается одним нажатием, после выбора меню закрывается. Escape сначала возвращает к действиям, затем закрывает меню. Нажатие снаружи и прокрутка переписки также закрывают его. Доступность редактирования и удаления по правам осталась прежней; неподдерживаемые действия в меню не добавлены.

Нативный Android не изменён и остаётся 0.12.62 с прежним видом. Повторно обновлять телефон для этой функции не требуется. Windows сохраняет существующий профиль, сеансы и механизм установки обновления.

## Обновление Windows и сервера одной командой

Выполните в прежнем каталоге сервера с `compose.yaml`, действующим `.env` и каталогом `artifacts`:

```sh
( set -eu; test -f compose.yaml && test -f .env; volna_update_dir=$(mktemp -d); trap 'rm -rf "$volna_update_dir"' EXIT; git clone --depth 1 --branch v0.12.63 https://github.com/andluk87/volna.git "$volna_update_dir/source"; git -C "$volna_update_dir/source" archive --output="$volna_update_dir/source.tar" HEAD; sh "$volna_update_dir/source/scripts/backup.sh"; if [ -d android-native/app/src ]; then mkdir -p backups; volna_source_backup=$(mktemp -d "$PWD/backups/android-source-0.12.63-XXXXXXXX"); mv android-native/app/src "$volna_source_backup/src"; fi; tar -xf "$volna_update_dir/source.tar" -C .; sh scripts/build-windows.sh )
```

Команда делает резервную копию, обновляет исходники по тегу, собирает и публикует Windows-установщик и ленту автообновления, обновляет сервер/Web. `.env`, данные, ключи и профиль клиента сохраняются. Прежние Android-исходники сохраняются в `backups/android-source-0.12.63-XXXXXXXX/src`, чтобы последующие сборки не подхватили файлы старой версии; Android при этом не пересобирается.

После завершения установите **Windows 0.12.63** из приложения или с `/download/volna-windows.exe`. Web получит изменения после перезагрузки страницы.

## Проверка

Проверяются размещение у границ окна, фотографии и текст, выбор/снятие реакций через настоящий API, поиск дополнительных эмодзи, собственные и чужие сообщения, Escape, выбор сообщения, закрытие снаружи и при прокрутке. Дополнительно проверяются геометрия, каталог и совместимость реакций с сервером, статический рендер React и production-сборка Web. Windows-интерфейс проверяется Chromium с имитацией Electron IPC; сам установщик требует проверки на Windows.

Данные палитры генерируются `node client/scripts/prepare-reaction-emoji.mjs` после подготовки закреплённого Unicode/CLDR-каталога Android. Лицензия данных Unicode включена в `client/public/site/emoji-LICENSE.txt` и попадает в сборку Windows/Web.
