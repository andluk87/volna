# Реализация ТЗ: эмодзи, стикеры, GIF и оформление Android 0.11.40

Реализованы основные блоки панели и оформления P0/P1, а также локальные пользовательские темы и обмен файлами из P2. Это продолжение нативной переработки 0.11.38, с сохранением Android/Web/API/Windows и их сборщиков. Сборка и установка: [UPDATE-0.11.40.md](UPDATE-0.11.40.md).

## Панель

| Требование | Реализация |
| --- | --- |
| Панель под полем ввода, замена IME | Панель после composer, высота с учётом клавиатуры и доступной области, раскрытие/сворачивание и возврат к клавиатуре |
| Полный стандартный набор | Unicode 17, полностью квалифицированные последовательности и aliases; категории, составные ZWJ, флаги, оттенки кожи |
| Одинаковая графика на телефонах | Встроенный Noto Color Emoji 2.051; EmojiCompat замена отключена в компонентах Волны |
| Русский поиск | CLDR 48 и дополнительные ключевые слова; полностью локальный поиск стандартных эмодзи |
| Недавние и оттенки кожи | Локальные история/частота, предпочтительный вариант, выбор удержанием; сохраняются отдельно для аккаунта |
| Редактирование текста | TextFieldValue, курсор и выделение, вставка вместо выделения, удаление целого эмодзи и повтор удаления удержанием |
| Пользовательские эмодзи | Собственные наборы; графика в composer и сообщениях; Unicode fallback и отдельные UTF-16 entities в API |
| Стикеры и GIF | Каталог Волны, установленные/недавние/избранные, поиск с debounce 300 мс, страницы по 60 элементов |
| Предпросмотр | Удержание/перемещение по сетке, действия «Отправить / Избранное / Набор» |
| Управление наборами | Установка/удаление из панели; создание из своих файлов; публичный код набора для обмена |
| Стартовые наборы | 12 статических стикеров и 8 GIF, созданных для Волны; устанавливаются по одному разу на аккаунт |
| Свои файлы | PNG, JPEG, WebP, GIF, MP4, WebM; до 10 МБ на элемент, до 20 выбранных файлов при создании в Android, простая обрезка статических изображений |
| Офлайн | Стандартная графика/поиск в APK; метаданные наборов, недавние/избранные и ранее загруженные файлы на устройстве |
| Производительность | Lazy grids, кэш файлов до 100 МБ на аккаунт, остановка невидимых/фоновых анимаций, работа с системным Reduce Motion |
| Сохранность | Черновик хранит текст, курсор, выделение и entities; ответ сохраняется при переключении вкладок панели в открытом чате; очистка только после успешной отправки |
| Web/Windows совместимость | Графические пользовательские эмодзи и компактное отображение стикеров/GIF; Unicode остаётся читаемым в старом клиенте |

Набор Noto обеспечивает одинаковое отображение внутри Волны на разных устройствах. **Точное совпадение рисунков с официальным Telegram не заявляется**: используется открытый Noto, а не извлечённая графика Telegram. Это остаётся различием относительно требования о совпадении рисунков.

Для GIF подключён собственный каталог, включая стартовый набор. Поиск по всему интернету через внешний провайдер не включён. Наборы можно расширять своими файлами. TGS/Lottie и автоматические рекомендации по набираемому тексту не реализованы. Пользовательские эмодзи в подписях к вложениям передаются обычным Unicode; rich entities в этой версии передаются для текстовых сообщений. Ответ в открытом чате сохраняется при переключении панели; восстановление режима ответа после завершения процесса отдельно не добавлялось.

## Оформление

| Приоритет / требование | Реализация |
| --- | --- |
| P0: светлая/тёмная/системная тема | Есть, с моментальным обновлением и дневным/ночным вариантом |
| P0: акцент и цвет сообщений | Палитра, HSV/HEX, исходящие и входящие, автоматическая коррекция читаемости |
| P0: фон/фотография | Цвет, градиент, фото с обрезкой и масштабированием; затемнение/яркость/размытие |
| P0: форма сообщений | Радиус 6–24 dp, плотность, размер текста/интерфейса, шрифт, аватары и время |
| P0: стеклянные поверхности | Haze 1.5.4, фон под нижней навигацией, карточки, тонкая граница, мягкие тени; режим без эффекта |
| P0: живой предпросмотр | Входящее, исходящее, голосовое с волной, реакция и composer; обновление без кнопки сохранения |
| P1: многоцветные градиенты | 1–4 цвета, добавление/удаление/перестановка, медленная анимация в максимальном качестве |
| P1: паттерны | Точки, волны, сетка, орбиты; цвет и интенсивность, автоматический цвет |
| P1: движущийся фон | Анимированный градиент, небольшой параллакс фото при прокрутке |
| P1: отдельная тема чата | Меню чата/профиль переписки; возврат к общей теме |
| P1: день/ночь | Две части темы и ночное расписание; изменение варианта в предпросмотре |
| P2: свои темы | Создание, название, сохранение до 30 тем на аккаунт, копия, удаление, применение |
| P2: импорт/экспорт/обмен | JSON version 1, вложенные фото, предпросмотр до применения, системное меню обмена |
| P2: параметры glass | Прозрачность, сила/режим blur, качество «Максимум / Баланс / Экономия», отключение |

Темы и настройки хранятся локально отдельно для аккаунта; отдельные темы переписок — по chat ID. Облачная синхронизация тем и новое публичное оформление профиля из P2 пока не реализованы. Существующее редактирование имени, фото и описания профиля сохранено.

Настоящий backdrop blur использует поддерживаемый Android RenderEffect через Haze. На старых Android применяется полупрозрачная поверхность, в экономном режиме — простой фон. Haze по умолчанию включает полный эффект начиная с API 32; на API 31 возможен fallback. Эффекты отключаются при энергосбережении или системном отключении анимаций. Максимальное качество включает анимацию градиента сообщений, баланс ограничивает blur, экономия убирает дорогие эффекты. Это адаптация качества, а не измеренный FPS: производительность на телефоне здесь не тестировалась.

## Данные и API

Сервер добавляет таблицы `expression_packs/items/installs/usage/seeded` и `message_emoji`, а к сообщениям — `expression_id`. Текущая история и вложения сохраняются. Разрешены только уже загруженные в Волну файлы с проверкой владельца, MIME/сигнатуры и размера; удалённые URL сервер каталога не скачивает. Приватный набор доступен владельцу, присланная графика — участникам соответствующей переписки. Публичные наборы доступны авторизованным пользователям.

Повтор отправки с тем же client ID возвращает ранее созданное сообщение. Для набора такой же client ID/содержимое возвращают исходный набор; изменённое содержимое с тем же ID отвергается. Пользовательские эмодзи валидируются по ID, Unicode fallback, UTF-16 позиции, длине и отсутствию пересечения. Редактирование/пересылка сохраняют entities; удаление сообщения не удаляет файлы, используемые наборами или другими сообщениями.

Импорт темы ограничен форматом Волны, размером JSON/фото, диапазоном параметров и размером изображения. Входящие локальные имена файлов сбрасываются; изображения получают новые внутренние имена. Импорт не исполняет код и не загружает внешние URL. Собственные фоны хранятся отдельно от очищаемого медиа-кэша.

## Проверить на устройстве после сборки

1. Вставьте текст, выделите часть, откройте эмодзи и замените выделение. Переключите три вкладки, вернитесь к клавиатуре и проверьте курсор/ответ.
2. Найдите «сердце», «смешно», «машина». Выберите оттенок кожи удержанием. Удалите `👍🏽`, `👨‍👩‍👧`, `🇷🇺`, keycap целиком, в том числе при выделении внутри последовательности.
3. Создайте публичный emoji-набор с PNG/WebP и fallback. Проверьте графику до отправки, получение в Web/Windows, редактирование и пересылку.
4. Отправьте стикер/GIF, добавьте в избранное, уберите/верните набор. Отключите сеть и откройте ранее просмотренные файлы; очистите кэш и повторите загрузку.
5. Выберите светлую/ночную тему, четыре цвета градиента, фото, узор. Проверьте отдельную тему чата и возврат к общей. Импортируйте экспортированную тему с фото на другом устройстве.
6. Проверьте крупный системный шрифт, поворот экрана, нижние кнопки Samsung и режим энергосбережения. В фоне анимации должны остановиться; обычные сообщения, голосовые и звонки должны продолжать прежнюю работу.

Автоматические проверки и ограничения среды: [VALIDATION.md](VALIDATION.md). До фактической Docker-компиляции и проверки на телефоне эти сценарии не считаются пройденными.
