# Обновление Волны до 0.12.50 — временная диагностика значков

Пользователь выбрал временную замену обоих значков Android: приложения и уведомлений. Использованы неизменённые WebP-ресурсы notification.webp и ic_launcher_dr.webp из официальных исходников Telegram Android, commit f32ffeec763f0bdbf4bec25b52d654f77bff733d. Проверено побайтовое совпадение всех девяти файлов с оригиналами. Маленький значок имеет 4 плотности (24/36/48/72 px), значок приложения 5 плотностей (48/72/96/144/192 px), как в исходнике.

Application icon, roundIcon и icon MainActivity указывают на диагностический ресурс Telegram; так проверяются оба пути получения иконки приложением-компаньоном. SmallIcon уведомлений и значок действия ответа заменены на официальный монохромный ресурс. Цветная картинка, где она применяется в звонках/фоновой службе/обновлениях, также использует временный Android-рисунок. Уведомления сообщений сохраняют отсутствие большого дублирующего логотипа.

Название приложения, package dev.volna.messenger, API, аккаунты, подпись и данные сохраняются. Пакет org.telegram.messenger не используется. Изображения Web и Windows не изменены. Оригинальные Android-изображения остаются в ресурсах для последующего возврата. Генератор Web/Windows их не перезаписывает. Этот выпуск не утверждает, что приложение связано с Telegram; это явно обозначенный временный эксперимент по просьбе пользователя.

Источник, SHA-256 ресурсов и исходная GPLv2-лицензия находятся в android-native/third-party/telegram-diagnostic-icons; уведомление об источнике и копия лицензии включены в APK assets/third-party.

## Проверка

1. Установите производственную Android-сборку 0.12.50. На телефоне значок приложения теперь должен показывать самолётик Telegram, подпись приложения — «Волна».
2. Удалите прежний тест из шторки. Android → Настройки → Уведомления → «Проверить уведомление на часах», затем заблокируйте телефон.
3. Через 10 секунд придёт локальный тест «Проверка значков Telegram в Волне». Проверьте значок на часах и новое обычное сообщение Волны.
4. Если значка нет, оставьте уведомления и выполните `adb shell dumpsys notification > notification-telegram-icons.txt`. Если значок приложения на телефоне не сменился, приложите также `adb shell dumpsys package dev.volna.messenger > volna-package.txt`.

MessagingStyle/Person, WearableExtender и локальный ответ теста сохранены. Результат на Huawei не подтверждён. После диагностики требуется отдельный выпуск для возврата родных значков; текущий выпуск автоматически их не переключает.

Выполните в прежнем каталоге сервера с compose.yaml и .env; данные и подпись сохраняются. Облачный Debug APK с тестовым адресом API не устанавливайте.

```sh
(
  set -eu
  test -f compose.yaml && test -f .env
  volna_update_dir=$(mktemp -d)
  trap 'rm -rf "$volna_update_dir"' EXIT
  git clone --depth 1 --branch v0.12.50 \
    https://github.com/andluk87/volna.git "$volna_update_dir/source"
  git -C "$volna_update_dir/source" archive \
    --output="$volna_update_dir/source.tar" HEAD
  sh "$volna_update_dir/source/scripts/backup.sh"
  tar -xf "$volna_update_dir/source.tar" -C .
  VOLNA_BUILD_NETWORK=host sh scripts/build-clients.sh
)
```

Это публикация исходников. Производственные установщики и сервер обновляет указанная команда.

Проверки: 164 Node-теста, 90 Android/JVM-тестов, сборки Web и Android Debug прошли. AAPT2 подтверждает упаковку обеих групп диагностических ресурсов по плотностям, лицензия присутствует в APK. Проверка изображения на Huawei Watch Ultimate остаётся аппаратной.
