# Волна 0.12.112 — вход и настройки Windows

Для Windows добавлен экран входа по образцу Telegram Desktop, с оформлением Волны:

- Стартовый экран «Начать общение».
- Вход по QR с инструкцией для телефона, сроком действия и обновлением кода.
- Вход по номеру: выбор страны, код страны, номер, затем шесть цифр из служебного сообщения.
- Настройки доступны до авторизации. Язык экрана входа — русский или английский.

Сохранённые аккаунты восстанавливаются через прежнее защищённое хранилище Windows. Установленный клиент с действующим сеансом продолжает открывать переписку. Приглашение сохраняется при переходах по экранам входа и предлагается после авторизации.

## Куда приходит код

Код приходит в личный чат **«Волна — служебные уведомления»** на устройствах, где этот аккаунт уже вошёл в Волну. Он не отправляется через Telegram и не требует SMS для входа Windows. Для первого создания аккаунта или восстановления доступа сначала войдите в Волну на телефоне.

Код действует пять минут, запрашивается повторно не чаще минуты и блокируется после пяти неверных вводов. Новый код заменяет прежний. После использования, отмены или истечения срока текст кода скрывается, а зашифрованное значение удаляется. Пересылка служебного сообщения не переносит действующий код в другой чат.

Попытка привязана к случайному секрету окна Windows и устройствам, существовавшим при доставке. Обычное обновление сеанса на телефоне не ломает код; отзыв всех прежних устройств делает его недействительным, даже если позже был создан новый сеанс. Сам запрос кода не выдаёт данные аккаунта и не регистрирует неизвестный номер. Повтор запроса после потери ответа использует ту же попытку и не создаёт ещё один код.

После успешного входа Windows по коду или QR в этот же чат приходит уведомление о новом устройстве: время UTC, сведения клиента, IP-адрес и инструкция проверки устройств. Страна по IP не угадывается. Коды, секреты окна и токены не записываются в журнал запросов и не сохраняются открытым текстом в сообщениях. Токены Windows сохраняются существующим механизмом защищённого хранилища.

## Настройки до входа

Работают автоматическая проверка обновлений, разрешение бета-версий и ручная проверка; иконка трея и монохромный вариант; отображение на панели задач; системная рамка окна; системный или ручной масштаб 75–200%; четыре темы, цвета акцента и системный акцент Windows. Приложение сохраняет хотя бы один способ доступа — трей или панель задач.

Изменение рамки применяется после перезапуска; кнопка перезапуска защищена от прерывания звонка, передачи файлов и сохранения сеанса. «Тип подключения» открывает системные настройки прокси Windows. Язык относится к экрану входа. Цветовые настройки используют существующее оформление приложения; после входа также загружается сохранённое оформление аккаунта.

## Обновление

Из `/root/volna-messenger`, где находятся `.env` и `compose.yaml`:

```sh
( set -eu; test -f compose.yaml && test -f .env; volna_update_dir=$(mktemp -d); trap 'rm -rf "$volna_update_dir"' EXIT; git clone --depth 1 --branch v0.12.112 https://github.com/andluk87/volna.git "$volna_update_dir/source"; git -C "$volna_update_dir/source" archive --output="$volna_update_dir/source.tar" HEAD; sh "$volna_update_dir/source/scripts/backup.sh"; if [ -d android-native/app/src ]; then mkdir -p backups; volna_source_backup=$(mktemp -d "$PWD/backups/android-source-0.12.112-XXXXXXXX"); mv android-native/app/src "$volna_source_backup/src"; fi; tar -xf "$volna_update_dir/source.tar" -C .; VOLNA_BUILD_NETWORK=host sh scripts/build-windows.sh )
```

Команда собирает и публикует установщик Windows, затем обновляет сервер и Web. Требуется не менее 4 ГБ свободного места. Настройки, данные и артефакты сохраняются; перед обновлением создаётся резервная копия.

Обновите приложение **Windows до 0.12.112**. Для доставки кода нужен обновлённый сервер. Уже установленная Волна Android 0.12.111 совместима с этими служебными сообщениями; обновление Android для входа Windows не требуется. Для общей сборки обоих клиентов можно заменить `sh scripts/build-windows.sh` на `sh scripts/build-clients.sh`.

## Проверки

Прошли 299 Node-тестов и 254 Android-теста. Собраны Web, Windows renderer и проверочный APK 0.12.112 (12112). Windows-установщик собирается приведённой выше командой на сервере публикации.

В Chromium с настоящим тестовым сервером проверены старт, настройки, вход по номеру, повтор после потерянного ответа с тем же секретом, неверный код, успешный сеанс Windows и подтверждение QR на телефоне. Проверены отсутствие дополнительного SMS, шифрование и скрытие кода, доступ только своему аккаунту, разделение кодов Windows/Android, запрет регистрации с компьютера, ограничения попыток и отзыв устройств. Дополнительно прошли восстановление защищённых сеансов, приглашения и существующий интерфейс Windows/Web. Изменения настроек, связанные с ОС, используют Electron API; браузерные проверки выполнялись с имитацией этого моста, а не на физической Windows.
