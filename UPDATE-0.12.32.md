# Обновление Волны до 0.12.32

Обновляются API, Android, Web и Windows: темы по предоставленному описанию, общая история, вкладки, лента и поиск, закрепление, уведомления и ссылки. [Подробности и границы проверки](TOPICS-0.12.32.md).

Запустите блок в прежнем каталоге Волны с `compose.yaml` и `.env`. Перед заменой исходников создаётся резервная копия данных. `.env`, данные и подпись Android сохраняются; не удаляйте `artifacts/android-home`. `VITE_API_URL` должен указывать на ваш настоящий HTTPS API. Облачные тестовые сборки с `example.invalid` устанавливать не нужно.

```sh
(
  set -eu
  test -f compose.yaml && test -f .env
  volna_update_dir=$(mktemp -d)
  trap 'rm -rf "$volna_update_dir"' EXIT
  git clone --depth 1 --branch v0.12.32 \
    https://github.com/andluk87/volna.git "$volna_update_dir/source"
  git -C "$volna_update_dir/source" archive \
    --output="$volna_update_dir/source.tar" HEAD
  sh "$volna_update_dir/source/scripts/backup.sh"
  tar -xf "$volna_update_dir/source.tar" -C .
  VOLNA_BUILD_NETWORK=host sh scripts/build-clients.sh
)
```

После сборки установщик Windows доступен на `/download`; установленный Windows-клиент получает версию 0.12.32 через штатную проверку обновлений. Web обновляется на сервере вместе с сервисами. Если открыта старая вкладка, перезагрузите её. Настройки, аккаунты и переписки сохраняются. Android пересобирается с прежней подписью, поэтому устанавливается поверх существующего приложения. Канал новостей создаётся после запуска обновлённого API.

Проверьте на Android/Web/Windows: включение тем в группе, общую старую историю, скрытие/переименование общей темы, закрепление и порядок, публикацию администратором в закрытой теме, режимы уведомлений и ответы. Откройте «Все сообщения», найдите текст и перейдите к его сообщению. После выключения режима и перезапуска убедитесь, что выбранное состояние и истории сохранены.

Облачный проверочный APK использует `example.invalid` и не предназначен для установки. Соберите приложение приведённым блоком с вашим API и прежней подписью. На Android подтвердите системную установку.
