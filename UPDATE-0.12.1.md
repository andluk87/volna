# Волна 0.12.1 — публичные username и подтемы

Полный исходный проект: API, Web, нативный Android, Windows/Electron, Docker-сборщики и встроенные обновления. Версии согласованы: 0.12.1; Android versionCode 12001.

## Обновление с 0.12.0

Распакуйте архив поверх существующего проекта, сохранив `.env`, `artifacts`, ключ подписи Android, Docker volumes и кэши. Затем из каталога проекта:

```sh
VOLNA_BUILD_NETWORK=host sh scripts/build-clients.sh
```

Если обычная Docker-сеть работает, используйте `sh scripts/build-clients.sh`. Общий сборщик собирает Android и Windows и один раз обновляет сервер/Web. Существующие телефонные аккаунты, user_id, номера, переписки и сеансы сохраняются. Повторный сброс базы не нужен. `update.sh` выполняет резервную копию перед запуском новой версии.

Старые автоматически сгенерированные ники 0.12.0 (`u` + 16 шестнадцатеричных символов) заменяются на телефонные ники один раз, без изменения аккаунта. После этой миграции выбранный пользователем ник не меняется при перезапуске.

Если у вас ещё 0.11.x с Telegram/паролями, сначала настройте SMS и выполните переход из [UPDATE-0.12.0.md](UPDATE-0.12.0.md): он создаёт новую базу аккаунтов и сохраняет старые данные в административной резервной копии. Для версии 0.12.0 этот шаг не требуется.

Проверьте в существующем `.env`:

```dotenv
PUBLIC_BASE_URL=https://volna.lknet.ru
VITE_API_URL=https://volna.lknet.ru
```

Домен должен быть вашим настоящим HTTPS-доменом. Сохраните настройки Notificore, TURN и Whisper. Новые ключи API для username и подтем не нужны. Новых зависимостей относительно 0.12.0 не добавлено; кэши обоих сборщиков продолжают использоваться.

## Username и поиск

Новый SMS-профиль получает `@` + нормализованный номер без плюса. Например, `+7 (968) 141-12-41` → `@79681411241`. Если такой ник уже занят, сервер подбирает свободный суффикс.

Этот первоначальный ник **публично раскрывает номер телефона**. После SMS-входа Android открывает профиль и предлагает сменить ник. В редакторе Android/Web/Windows есть поле «Изменить username», проверка доступности и 3–5 свободных предложений при конфликте.

Для собственного ника: 4–32 латинские буквы, цифры и `_`; можно вводить с `@` или без него. Регистр не влияет на уникальность. Полностью цифровой ник остаётся исключением для автоматической выдачи; при ручной смене добавьте букву или `_`. Системные имена зарезервированы. Уникальность защищена индексом `username_normalized`, включая одновременные запросы.

Смена ника не меняет номер телефона, user_id, SMS-вход или сеансы. Username не используется для авторизации.

Искать можно в общей строке поиска:

- имя или `nick` / `@nick` — поиск по имени и началу ника, точное совпадение выше;
- `+7 (968) 141-12-41` или `79681411241` — точный поиск подтверждённого телефона;
- `@79681411241` — поиск первоначального публичного ника.

Поиск телефона требует входа. Частичный телефон без `@` не выдаёт каталог номеров. В результатах показываются публичные имя, аватар, ник и ссылка, без отдельного поля телефона.

Ссылка `https://volna.lknet.ru/nick` открывает публичную страницу без авторизации: имя, аватар, ник и описание. Username в профиле кликабелен. После смены ника старая ссылка не перенаправляется на прежний профиль. На странице есть переход в Web и кнопка открытия Android через `volna://profile/nick`.

## Подтемы групп

Откройте группу:

- Android: меню `⋯` → «Подтемы»;
- Web/Windows: кнопка «Подтемы» в заголовке группы.

«Общий чат» сохраняет прежнюю историю. У каждой подтемы отдельная история, счётчик непрочитанных, описание и необязательная иконка/эмодзи. Поддерживаются обычные сообщения, голосовые, вложения, альбомы, ответы, реакции, редактирование, закрепление и поиск через существующий механизм сообщений.

По умолчанию создавать подтемы могут владелец и администраторы. В настройках списка подтем доступны варианты «Только владелец», «Владелец и администраторы», «Все участники». До 100 подтем на группу.

Создатель подтемы и администраторы могут менять название/описание/иконку, закрывать и открывать подтему, удалять её с подтверждением. Закрытая подтема доступна для чтения; новые сообщения запрещаются сервером, даже если отправить запрос напрямую.

Уведомления настраиваются для каждого пользователя и каждой подтемы: все сообщения, только `@упоминания`, без уведомлений. Отключение уведомлений не отключает доставку данных и обновление истории. Режим сохраняется между устройствами и перезапусками. Упоминание должно совпадать с полным ником: `@alexander` не считается упоминанием `@alex`.

В общем списке чатов подтемы не дублируют группу; непрочитанные суммируются в её значок. Новая активность в подтеме обновляет превью и положение группы. Исключение/выход из группы снимает доступ ко всем её подтемам сразу. Новые участники получают доступ к уже существующим подтемам; роли синхронизируются.

## API

- `GET /api/users/username/check?username=nick` — проверка и предложения;
- `PATCH /api/users/me/username` с `{"username":"nick"}` — изменение;
- `GET /api/users/search?q=...` — объект `{users:[...]}`; прежний `GET /api/users?q=...` возвращает массив для существующих клиентов;
- `GET /api/public/users/nick` — публичные данные; `/avatar` — публичное фото;
- `GET/POST /api/groups/{group_id}/topics` — список/создание;
- `POST /api/groups/{group_id}/topics/settings` с `{"create_policy":"admins"}`;
- `GET/PATCH/DELETE /api/groups/{group_id}/topics/{topic_id}` — просмотр/изменение/удаление;
- `GET/POST /api/groups/{group_id}/topics/{topic_id}/messages` — история/отправка;
- `POST /api/groups/{group_id}/topics/{topic_id}/notifications` с `{"mode":"mentions"}`.

Внутри базы подтема представлена отдельным потоком чата с `chats.parent_id`, поэтому ответы, медиа и права не смешиваются с общим обсуждением. В API сообщения дополнительно содержат `group_id` и `topic_id`. Для общего чата `topic_id=null`. Удаление подтемы снимает доступ к её истории; применяется мягкое удаление, как для обычных сообщений.

## Проверки и скачивание

```sh
sh scripts/check-downloads.sh all
docker compose logs --tail=80 server
curl -sS https://volna.lknet.ru/api/auth/config
```

После успешной Docker-сборки доступны:

- `https://volna.lknet.ru/download/volna-android.apk`;
- `https://volna.lknet.ru/download/volna-windows.exe`;
- `https://volna.lknet.ru/app`.

Архив содержит исходники и сборщики, не готовые APK/EXE. Локально выполнены серверные и функциональные тесты, проверка React-компонентов, сборка Web и Windows renderer, проверки XML/JSON/shell и структуры Kotlin. Полноценная компиляция Android и упаковка Windows EXE здесь невозможны: Docker, Android SDK и Gradle отсутствуют. Сборку установщиков выполняет приведённый скрипт на VPS.
