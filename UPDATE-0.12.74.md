# VLN 0.12.74 — понятная подпись голосового закрепа Android

В шапке закреплённого голосового сообщения теперь отображается «Голосовое сообщение», как на примере Telegram. Техническое имя вроде `Голосовое-1791466172348.m4a` больше не показывается в закрепе. Поддержаны записи Android (`.m4a`), Web/Windows (`.webm`) и прежние записи из кэша.

Фото, видео, GIF, стикеры и эмодзи также имеют понятные подписи. Текстовые сообщения и подписи к вложениям сохраняются в предпросмотре; читаемые имена документов и аудиофайлов остаются. Проверены переход к сообщению по нажатию и отдельное открытие списка закреплённых.

Сохранены исправления 0.12.73: альбомы 1+3, время поверх фото и сжатие APK для обновления в установленном приложении с прежним лимитом 120 МиБ.

Из прежней папки сервера с `compose.yaml` и существующим `.env`, одной вставкой:

```sh
( set -eu; test -f compose.yaml && test -f .env; volna_update_dir=$(mktemp -d); trap 'rm -rf "$volna_update_dir"' EXIT; git clone --depth 1 --branch v0.12.74 https://github.com/andluk87/volna.git "$volna_update_dir/source"; git -C "$volna_update_dir/source" archive --output="$volna_update_dir/source.tar" HEAD; sh "$volna_update_dir/source/scripts/backup.sh"; if [ -d android-native/app/src ]; then mkdir -p backups; volna_source_backup=$(mktemp -d "$PWD/backups/android-source-0.12.74-XXXXXXXX"); mv android-native/app/src "$volna_source_backup/src"; fi; tar -xf "$volna_update_dir/source.tar" -C .; sh scripts/build-clients.sh )
```

Команда создаёт резервную копию, сохраняет прежние исходники Android в `backups/`, загружает тег `v0.12.74` и запускает общий сборщик. `.env`, база, аккаунты, переписки и ключ подписи Android сохраняются.

После сборки откройте в VLN `Настройки → Обновления → Проверить обновления` и подтвердите установку поверх прежней версии. Обновите Windows поверх прежней версии и перезагрузите Web через `Ctrl+F5`.

Проверка на телефоне: закрепите голосовое сообщение и посмотрите на шапку — под «Закреплённое сообщение» должно быть «Голосовое сообщение». Нажатие на шапку переводит к записи, кнопка булавки открывает список закреплённых.

Проверено: 161 Android unit/UI-тест в Robolectric, сборка APK (~103 МиБ), совместимость размера со старым лимитом, 194 общих Node-теста и production-сборка Web. Установка на физическом телефоне в этой среде не выполнялась.
