# Папки, звонки и уведомления 0.12.26

Папки используют правила, описанные в [Telegram API](https://core.telegram.org/api/folders) и [обзоре папок](https://telegram.org/tour/chat-folders/ru): автоматический отбор, отдельные включения/исключения, закрепления и порядок. Реализован согласованный объём личных папок аккаунта в Android, Web и Windows.

## Папки

- До 20 папок; имя до 32 символов, значок, создание, переименование, копирование, удаление, перестановка. Стандартные папки редактируются и удаляются так же, как созданные пользователем.
- Правила: личные чаты, контакты из личной адресной книги, остальные собеседники, группы, каналы, архив. Можно исключить прочитанные, чаты без звука и архив.
- Явно добавленные/закреплённые чаты обходят автоматические фильтры. Явные исключения имеют приоритет. Темы групп не появляются как самостоятельные чаты папки.
- Закрепления и их порядок действуют внутри папки. Удаление папки сохраняет все сообщения.
- Сервер хранит настройки отдельно для каждого аккаунта. Web/Windows получают изменения через события и резервный опрос раз в 5 секунд; Android опрашивает сервер раз в 5 секунд, пока открыт список чатов. Без сети доступен сохранённый список; для сохранения изменений нужно соединение.
- Одновременное сохранение проверяет версию. При конфликте загружается новая версия и сохраняется открытый черновик редактора: сверяйте изменения перед повторным сохранением.
- Первый Android-клиент переносит локальные папки, если сервер ещё не сохранял настройки. Если сервер уже содержит настройки, применяются они; прежний локальный список остаётся в резервной записи и доступен через «Импортировать прежние локальные папки».
- Web/Windows: «Импортировать локальные папки этого устройства» переносит старые папки по явной команде. Автоматического переноса общего локального списка в другой аккаунт нет. Удалённые стандартные папки возвращаются только по кнопке «Добавить стандартные папки».

## Запрос уведомлений при запуске

Android сразу после входа/восстановления аккаунта проверяет разрешение уведомлений, полноэкранный показ Android 14+ и важность каналов сообщений/звонков. Если что-то отключено, открывается окно с кнопками включения. В Android 13+ первый запрос открывает системный диалог; после окончательного отказа — настройки приложения. После возвращения состояние проверяется повторно. «Готово» закрывает окно до следующего открытия основного экрана; постоянного признака «больше не спрашивать» нет.

Полноэкранный показ разрешает пользователь в системных настройках. ОС, энергосбережение и режим «Не беспокоить» определяют фактическое появление поверх блокировки. На прошивках без нужного раздела открываются общие настройки приложения.

Web проверяет браузерное разрешение и регистрацию Push-подписки текущего аккаунта. Если они отсутствуют, окно предлагает включить уведомления. Браузерный запрос запускается кнопкой пользователя; при блокировке разрешение меняется в настройках сайта. Для фоновых уведомлений необходимы HTTPS, поддержка Web Push и настроенные серверные ключи.

Windows проверяет настройку Волны и доступные пользовательские настройки Toast в реестре. При обнаруженном отключении показывает запрос; из окна уведомлений можно открыть системный раздел Windows. Если ключей нет или доступ запрещён, системный статус считается неизвестным. Фокусировка внимания, политики организации и баннеры отдельных приложений требуют проверки в Windows: приложение не меняет эти настройки самостоятельно. Сообщения показываются системными уведомлениями при работе в другом окне; нажатие открывает нужный чат. Входящий звонок имеет отдельное уведомление.

## Звонки Web и Windows

Фон, текст, нейтральные кнопки, свёрнутая панель и выбор аудиовыхода используют текущую тему и обновляются вместе с ней. Кнопки ответа и завершения сохраняют зелёный/красный цвет. Windows теперь запрашивает камеру для видеозвонков через диалог приложения, отдельно учитывая доступ к микрофону. Два видео, перестановка и перемещение малого окна используют общий Web-клиент.

## Проверка на устройствах

После установки поверх предыдущей версии отключите уведомления/полноэкранный показ и запустите приложение заново: окно должно появиться без перехода в настройки. Разрешите всё, вернитесь и повторно запустите: окно исчезает. Проверьте отказ, канал с низкой важностью, заблокированный экран и «Не беспокоить». В Windows проверьте отключённые баннеры и фокусировку внимания; в браузере — запрет, выдачу разрешения, выход/повторный вход и нажатие фонового уведомления.

Облачные сборки проверяют код и тесты; физического Android-телефона и интерактивной Windows 10 в этой среде нет. Двусторонний видеотест использует реальные тестовые камеры Chromium с имитацией ICE-соединения, поскольку политика среды блокирует UDP.
