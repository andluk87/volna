# Волна Native Desktop 0.1.0 — первая сборка Windows

Отдельный установщик **Volna Desktop Native** с нативным интерфейсом Qt/C++. Вход по QR или коду из служебного чата Волны, личные чаты и существующие группы/каналы/темы, история, сообщения, файлы, голосовые, аудио- и видеозвонки. Использованы оригинальные палитры Telegram Desktop v6.3.3 и QR-генератор из его зависимостей; точный состав и контрольные суммы находятся в [desktop-native/third_party/sources.json](desktop-native/third_party/sources.json).

Это самостоятельный клиент для протокола Волны, а не полный перенос Telegram Desktop: Telegram MTProto не используется, звонки и голосовые работают через общий WebRTC-модуль Волны в Qt WebEngine. Перенос полного набора функций ещё не закончен: отсутствуют управление группами, несколько аккаунтов, реакции/стикеры, расписание отправки, автообновление нативного установщика и выбор экрана для демонстрации. Программа устанавливается рядом с текущей Волной, использует отдельное защищённое хранилище Windows и не подменяет её обновления.

## Скачать

[Предварительный выпуск native-v0.1.0](https://github.com/andluk87/volna/releases/tag/native-v0.1.0): установщик x64, portable ZIP, соответствующий исходный код и SHA-256. Установщик пока без цифровой подписи. Поддерживаются Windows 10/11 x64.

## Подготовить сервер

Авторизация требует сервер Волны 0.12.112. Звонкам и голосовым нужна новая страница `native-call.html` в Web-сборке. Она создаётся обычным Vite build; обновить сервер и Web можно из `/root/volna-messenger`, где находятся существующие `.env` и `compose.yaml`:

```sh
( set -eu; test -f compose.yaml && test -f .env; volna_native_update=$(mktemp -d); trap 'rm -rf "$volna_native_update"' EXIT; git clone --depth 1 --branch native-v0.1.0 https://github.com/andluk87/volna.git "$volna_native_update/source"; git -C "$volna_native_update/source" archive --output="$volna_native_update/source.tar" HEAD; sh "$volna_native_update/source/scripts/backup.sh"; tar -xf "$volna_native_update/source.tar" -C .; VOLNA_BUILD_NETWORK=host sh scripts/update.sh )
```

Команда сохраняет `.env`, артефакты и Docker volumes. Действующий установщик Electron и Android не пересобираются. Сервер и Web пересобираются штатным скриптом с резервной копией. Затем установите нативный клиент из предварительного выпуска и войдите по QR или номеру. Код приходит в **«Волна — служебные уведомления»** на уже подключённые устройства. Если модуль звонков не загружается, сначала обновите Web и нажмите «Перезагрузить модуль звонков».

## Проверки и исходный код

Пройдены 299 Node-тестов проекта и C++-проверки протокола, SSE, QR, палитр и хранилища. На настоящем локальном API проверяются вход по служебному коду и QR, обновление сеанса, отправка без дубликатов, получение событий, файлы и нативные экраны. На Linux проверены реальные аудио- и видеозвонки между двумя экземплярами Qt WebEngine через coturn: подключение, получение RTP-пакетов, кадры видео, обновление токена без разрыва разговора, завершение и запись голосового. В этих проверках используются тестовые микрофон и камера Chromium; переключение физических устройств и сетей требует проверки на реальном компьютере Windows.

Сборка Windows и DPAPI-тесты выполняются workflow [Volna Native Desktop](https://github.com/andluk87/volna/actions/workflows/native-desktop.yml). Инструкции для самостоятельной сборки и ограничения — [desktop-native/README.md](desktop-native/README.md).
