# VLN 0.12.58 — размеры папок и нижней навигации Android

## Где настроить

**Настройки → Настройки чатов → Оформление папок / Нижняя навигация.**

- Высота элементов: **24–160 dp** (раньше 36–80).
- Скругление и отступ по краям: **0–80 dp** (раньше 0–40).
- Иконки нижней навигации: **12–64 dp** (раньше 18–32).
- Текст и значки папок / подписи нижней панели: **8–32 sp** (раньше 10–20).

Высота нижней навигации применяется к самим пунктам, включая выделение и область нажатия. Содержимое центрируется по вертикали. Указанная высота — минимальная: при крупном тексте, значках или счётчиках элемент может вырасти, чтобы вместить содержимое.

Настройки сохраняются отдельно для каждого аккаунта; старые значения и кнопки сброса сохранены. Размер текста задаётся в sp с учётом системного масштаба шрифта, геометрия — в dp.

## Обновление на сервере

Выполните в **прежнем каталоге сервера**, где находятся `compose.yaml` и действующий `.env`. Используется существующий Android-ключ из `artifacts/android-home`, чтобы APK устанавливался поверх предыдущей версии. Сохраните весь каталог `artifacts`.

```sh
(
  set -eu
  test -f compose.yaml && test -f .env
  volna_update_dir=$(mktemp -d)
  trap 'rm -rf "$volna_update_dir"' EXIT
  git clone --depth 1 --branch v0.12.58 \
    https://github.com/andluk87/volna.git "$volna_update_dir/source"
  git -C "$volna_update_dir/source" archive \
    --output="$volna_update_dir/source.tar" HEAD
  sh "$volna_update_dir/source/scripts/backup.sh"
  tar -xf "$volna_update_dir/source.tar" -C .
  sh scripts/build-android.sh
)
```

Скрипт собирает Android, запускает штатные проверки, публикует APK и метаданные обновления, затем обновляет сервер/Web. После успешной сборки установите обновление из приложения или скачайте `https://<ваш-домен>/download/volna-android.apk`. Системное подтверждение установки обязательно. Версия APK: **0.12.58 (12058)**.

## Проверка

Откройте оба раздела оформления, измените высоту и другие размеры до новых пределов. Проверьте предпросмотр, сохранение после перезапуска и индивидуальный сброс. При крупном системном шрифте проверьте видимость текста и счётчиков.

В исходники добавлен тест сохранения новых минимальных и максимальных значений для обеих панелей. Локальный запуск JVM-тестов остановился до компиляции: в используемом offline-кэше отсутствует Android Gradle Plugin 8.10.1. APK этого выпуска в рабочей среде не собран; сборка и проверки выполняются приведённым выше скриптом на сервере.
