# VLN 0.12.73 — Android: фотоальбомы и размер обновления

## Фото и альбомы

Для четырёх фото: один крупный кадр сверху и три миниатюры снизу, как на присланном примере Telegram. Порядок фотографий сохраняется. Между кадрами тонкие белые разделители; скругление применяется к внешнему контуру альбома. Для остальных наборов от 2 до 10 фото/видео используется раскладка по строкам.

У альбома без подписи — одна общая метка времени и доставки поверх нижнего правого снимка. У одиночного фото/видео метка тоже располагается поверх изображения; отдельная цветная полоса под фотографией убрана. Подписи и реакции остаются под медиа; время не дублируется. Нажатие открывает нужный снимок, долгое нажатие открывает его действия. Настройка показа времени по нажатию сохранена.

## Обновление через приложение

Причина отказа: прежний клиент ограничивал APK 120 МиБ, а универсальная сборка с анимациями выросла примерно до 137 МиБ. Нативные библиотеки теперь упаковываются со сжатием: проверенный APK — около 103 МиБ. Все четыре архитектуры (`arm64-v8a`, `armeabi-v7a`, `x86`, `x86_64`), звонки, камера, шрифт и 580 анимаций сохранены. Размер укладывается в ограничение уже установленного приложения.

Сборщик прекращает публикацию, если APK превышает старый лимит 120 МиБ; предыдущие APK и описание обновления сохраняются. В новом загрузчике лимит повышен до 256 МиБ с проверкой заголовка и фактического числа байтов. APK скачивается потоком; SHA-256 и проверка адреса сервера сохранены. Частично скачанный или повреждённый файл удаляется.

## Обновление сервера

Из прежней папки с `compose.yaml` и существующим `.env`, одной вставкой:

```sh
( set -eu; test -f compose.yaml && test -f .env; volna_update_dir=$(mktemp -d); trap 'rm -rf "$volna_update_dir"' EXIT; git clone --depth 1 --branch v0.12.73 https://github.com/andluk87/volna.git "$volna_update_dir/source"; git -C "$volna_update_dir/source" archive --output="$volna_update_dir/source.tar" HEAD; sh "$volna_update_dir/source/scripts/backup.sh"; if [ -d android-native/app/src ]; then mkdir -p backups; volna_source_backup=$(mktemp -d "$PWD/backups/android-source-0.12.73-XXXXXXXX"); mv android-native/app/src "$volna_source_backup/src"; fi; tar -xf "$volna_update_dir/source.tar" -C .; sh scripts/build-clients.sh )
```

Команда создаёт резервную копию, сохраняет прежние исходники Android в `backups/`, загружает тег `v0.12.73` и запускает общий сборщик. `.env`, база, аккаунты, переписки и ключ подписи Android сохраняются.

После завершения откройте в установленном VLN `Настройки → Обновления → Проверить обновления` и подтвердите обновление Android. Новый APK меньше прежнего лимита загрузки. При установке через браузер используйте свежий `/download/volna-android.apk` с вашего сервера и устанавливайте поверх старой версии. Windows обновите поверх прежней версии, Web перезагрузите через `Ctrl+F5`.

Проверка на телефоне: отправьте альбом из четырёх фото без подписи, откройте разные снимки и меню по долгому нажатию; отправьте одиночное фото и альбом с подписью. Время и галочки должны быть общими и не перекрывать подпись.

Проверено: сборка APK, 155 Android unit/UI-тестов в Robolectric, 194 общих Node-теста, production-сборка Web; контроль размера APK, сжатия библиотек всех четырёх ABI и SHA-256 анимаций. На физическом устройстве установка обновления в этой среде не выполнялась.
