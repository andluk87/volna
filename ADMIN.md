# Панель администратора Волны

Адрес: **https://ВАШ_CHAT_DOMAIN:8998**. Вход по SMS на **89681411241** (+79681411241). Используется выбранный SMS-провайдер: Notificore или HTTP SMS-шлюз; его настройки берутся из `.env`. Регистрация администратора в мессенджере для входа в панель не требуется.

После [обновления до 0.12.12](UPDATE-0.12.12.md) Caddy открывает HTTPS на порту 8998 с сертификатом вашего домена. Серверный порт панели находится внутри Docker; наружу выходит только Caddy. Разрешите **8998/tcp** в сетевом экране VPS и, если включён UFW, выполните:

```sh
sudo ufw allow 8998/tcp
```

В браузере введите номер, запросите SMS, введите шесть цифр. Код действует 5 минут, повторный запрос — через 60 секунд, максимум 5 SMS в час с учётом запросов этого номера в мессенджере. Сеанс панели действует 8 часов. Статус `sent` означает принятие SMS провайдером; он не подтверждает доставку оператором.

## Возможности

| Раздел | Действия |
| --- | --- |
| Обзор | Пользователи, сообщения, чаты, хранилище, свободное место, сеансы, звонки и состояние Whisper |
| Пользователи | Поиск по имени/номеру/ID, изменение профиля, скрытие аватара, блокировка/разблокировка, завершение сеансов, обезличивание |
| Чаты | Создание группы/канала с зарегистрированным владельцем, настройки публикации, участники и роли, передача владения, отзыв приглашения |
| Заморозка и удаление | Запрет отправки в чате и подтемах; скрытие чата для участников и восстановление без потери истории |
| Сообщения | Поиск, просмотр сообщений чата, удаление для всех, закрепление и открепление |
| Файлы | Размеры, владельцы, скачивание, блокировка доступа и повторной отправки; очистка старых неиспользуемых файлов |
| Эмодзи и стикеры | Поиск наборов, блокировка и публикация |
| SMS | Маскированные номера, reference, статусы, попытки, признак принятия провайдером; сброс лимита номера с истечением старых кодов |
| Устройства | Активные сеансы, платформа, последняя активность, отключение устройства |
| Звонки | История и принудительное завершение активного звонка |
| Настройки | Регистрация, обслуживание, сообщение обслуживания, размер файла, квота пользователя, лимиты SMS |
| Объявление | Публикация в канале «Новости Волны» для всех активных зарегистрированных пользователей, до 20 000 получателей |
| Резервные копии | Создание архива SQLite + uploads, скачивание и удаление копий |
| Журнал | Действия, объект, причина, дата и администратор |
| Сеансы администратора | Просмотр и отзыв входов в панель |

Изменения подтверждаются собственным диалогом панели и требуют указать причину. Основного администратора нельзя заблокировать или обезличить. Обезличивание удаляет из активного профиля настоящий телефон и личные данные, сохраняет техническую запись пользователя и сообщения; действие необратимо. Старые резервные копии могут содержать прежние данные.

Удаление чата обратимо, но отозванное приглашение нужно создать заново в мессенджере. Удаление текста сообщения необратимо. Файлы с действующими ссылками не удаляются очисткой. Размер файла настраивается от 1 до 20 МБ в пределах поддержки текущих клиентов. Закрытие регистрации не мешает входу существующих пользователей. Обслуживание запрещает изменения содержимого мессенджера, сохраняя чтение и выход из аккаунта; панель доступна.

## Выбор SMS-провайдера (0.12.13)

В разделе **Настройки → Отправлять SMS через** выберите **Notificore** или **SMS-шлюз · линия 4**, затем сохраните с указанием причины. Выбор применяется сразу к входу в Android/мессенджер и панель, сохраняется после перезапуска. Уже отправленные коды продолжают действовать; следующие SMS отправляет выбранный провайдер. Первоначально выбран Notificore. `SMS_PROVIDER` в `.env` задаёт начальный выбор, пока он не сохранён в панели.

Для HTTP-шлюза задайте в `.env`:

```dotenv
SMS_GATEWAY_URL=http://188.128.67.14:3825/default/en_US/send.html
SMS_GATEWAY_USER=логин_шлюза
SMS_GATEWAY_PASSWORD=пароль_шлюза
SMS_GATEWAY_LINE=4
```

Используйте свои фактические логин и пароль. После изменения `.env` пересоздайте сервер, чтобы Docker передал новые переменные:

```sh
docker compose -f compose.yaml -f compose.https.yaml up -d --no-deps --force-recreate server
```

Ненастроенный провайдер нельзя выбрать в панели. Если SMS для входа администратора не приходит, переключите провайдера из каталога установки без отправки нового SMS:

```sh
sh scripts/select-sms-provider.sh gateway
# Вернуть Notificore:
# sh scripts/select-sms-provider.sh notificore
```

После этого запросите новый код входа. `sh scripts/check-sms.sh` показывает выбранного провайдера, наличие настроек, ID и статусы без секретов и номеров.

Шлюз принимает только российские номера: `+79997776655` преобразуется в `89997776655`. Текст — шесть цифр кода, дефис после третьей цифры и `твоя волна`. Запрос GET соответствует предоставленному API; при HTTP логин, пароль, номер и текст передаются шлюзу без TLS. Реквизиты остаются на сервере, браузер их не получает.

Ответ `Sending,L4 ... ID:...` означает принятие сообщения, а не доставку оператором. Неизвестный ответ, ошибка HTTP, `ERROR` или `FAILED` дают ошибку отправки; код не становится действующим. Автоматических повторов или отправки через запасного провайдера нет, чтобы не создавать дубли.

## Резервная копия и восстановление

Копии панели находятся в `/data/admin-backups` внутри тома сервера. Снимок SQLite и неизменяемых файлов создаётся перед архивацией: удаление файлов во время сжатия не нарушает копию. Архив содержит только `volna.db` и `uploads/`, без `.env`. Скачайте копию на другую машину. Сохраняйте `.env`, ключи подписания Android и остальные данные установки отдельно; `sh scripts/backup.sh` делает полный архив тома сервера перед обновлением.

Восстановление выполняется **при остановленном сервере**. Оно заменяет текущую базу и uploads. Сначала создайте свежую копию `sh scripts/backup.sh`; затем используйте только архив, скачанный из этой панели, а не полный архив `scripts/backup.sh`.

В каталоге установленной Волны сохраните архив панели как `restore-admin.tar.gz`, проверьте его содержимое (`tar -tzf restore-admin.tar.gz`: только `volna.db`, каталог `uploads/` и его файлы). Для стандартной HTTPS-установки:

```sh
(
  set -eu
  test -f restore-admin.tar.gz && test -f .env
  sh scripts/backup.sh
  docker compose -f compose.yaml -f compose.https.yaml stop server
  docker compose -f compose.yaml -f compose.https.yaml run --rm --no-deps -T \
    -v "$PWD/restore-admin.tar.gz:/restore-admin.tar.gz:ro" --user 0:0 --entrypoint sh server -ec '
      volna_restore_stage=$(mktemp -d /data/.admin-restore.XXXXXX)
      trap '\''rm -rf "$volna_restore_stage"'\'' EXIT
      tar -xzf /restore-admin.tar.gz -C "$volna_restore_stage"
      test -s "$volna_restore_stage/volna.db" && test -d "$volna_restore_stage/uploads"
      VOLNA_RESTORE_DB="$volna_restore_stage/volna.db" node --input-type=module -e '\''
        import {DatabaseSync} from "node:sqlite";
        const db=new DatabaseSync(process.env.VOLNA_RESTORE_DB);
        if(db.prepare("PRAGMA quick_check").get().quick_check!=="ok")throw Error("Backup database is damaged");
        db.exec("PRAGMA foreign_keys=ON; DELETE FROM sessions; DELETE FROM qr_challenges; DELETE FROM admin_sessions;");
        db.prepare("UPDATE sms_challenges SET status=?").run("expired");
        db.prepare("UPDATE admin_sms SET status=?").run("expired");
        db.close();
      '\''
      chown -R node:node "$volna_restore_stage"
      rm -f /data/volna.db /data/volna.db-wal /data/volna.db-shm
      rm -rf /data/uploads
      mv "$volna_restore_stage/volna.db" /data/volna.db
      mv "$volna_restore_stage/uploads" /data/uploads
    '
  docker compose -f compose.yaml -f compose.https.yaml up -d --wait server web gateway
)
```

Все устройства, включая администратора, должны войти заново. Если восстановление завершилось ошибкой, не запускайте сервер с частично восстановленными данными; исходный полный архив находится в `backups/`. Для установки без HTTPS уберите `-f compose.https.yaml` и `gateway`.

## Настройки доступа и локальная разработка

`ADMIN_PHONE` в `.env` задаёт единственный номер администратора; по умолчанию `+79681411241`. Номер нельзя изменить через веб-панель. После смены номера и перезапуска прежние административные сеансы и коды отзываются. `ADMIN_PUBLIC_URL` обычно оставляют пустым: используется `https://CHAT_DOMAIN:8998`. Для другого адреса укажите полный origin со схемой и портом. Обновите контейнер сервера после изменения `.env`.

Для Docker без домена панель можно открыть **только на localhost**:

```sh
docker compose -f compose.yaml -f compose.admin-local.yaml up -d --build server web
```

Открывайте `http://localhost:8998` на сервере либо через SSH-туннель `ssh -L 8998:127.0.0.1:8998 user@server`. Для обычного Node-запуска: Node.js 24+, `npm ci`, `npm start`; панель — `http://localhost:8998`, API — 3000. Без настроенного выбранного SMS-провайдера вход недоступен.

Обычные SMS-коды, QR и токены мессенджера не дают прав администратора. Панель использует отдельные хешированные сеансы и одноразовые коды, HttpOnly cookie, проверку origin и CSRF. Коды, ключ API, access/refresh-токены не показываются. Ключ Notificore и реквизиты шлюза меняются на сервере через `.env`. Панель не выполняет произвольные команды/SQL и не управляет Docker хоста; перезапуск, обновление и восстановление выполняются командами установки.
