# Обновление Волны до 0.12.19

В этом выпуске переделаны главный экран и экран звонка Android; добавлены управление экраном у уха, настройка входящих звонков и окно обновления. **Установите новый APK на телефон**, чтобы получить изменения.

Скопируйте блок целиком в терминал в прежнем каталоге Волны с `compose.yaml` и `.env`. Он загрузит точную версию GitHub, создаст резервную копию данных, соберёт и опубликует APK, обновит контейнеры. Локальные изменения исходников заменяются; данные, `.env` и прежний ключ подписи APK сохраняются. Адрес API берётся из `VITE_API_URL` существующего `.env`.

```sh
(
  set -eu
  test -f compose.yaml && test -f .env
  volna_update_dir=$(mktemp -d)
  trap 'rm -rf "$volna_update_dir"' EXIT
  git clone --depth 1 --branch v0.12.19 \
    https://github.com/andluk87/volna.git "$volna_update_dir/source"
  git -C "$volna_update_dir/source" archive \
    --output="$volna_update_dir/source.tar" HEAD
  sh "$volna_update_dir/source/scripts/backup.sh"
  tar -xf "$volna_update_dir/source.tar" -C .
  VOLNA_BUILD_NETWORK=host VOLNA_BUILD_PUBLISH_ONLY=1 sh scripts/build-android.sh
  VOLNA_BUILD_NETWORK=host sh scripts/update.sh
)
```

После завершения откройте `https://ВАШ_CHAT_DOMAIN/download/volna-android.apk` на телефоне и установите APK поверх текущего приложения. Также можно использовать проверку обновлений в Волне. Не удаляйте `artifacts/android-home`: там сохраняется подпись, необходимая для установки поверх прежнего APK.

Что проверить после установки:

- Главный экран: поиск, папки/вкладки, архив, нижняя навигация, «Избранное», меню аккаунтов.
- Уведомления: при первом запуске разрешите системный запрос Android 13+. Если раньше отказали, откройте «Настройки → Уведомления → Уведомления Android». Все категории уведомлений изначально включены; ранее сохранённые отключения не сбрасываются.
- Экран входящего звонка: на Android 14+ подтвердите предложение включить полноэкранный показ в системных настройках. На заблокированном телефоне позвоните из второй Волны: должен включиться экран с «Ответить / Отклонить». Без разрешения полноэкранного показа Android может ограничить вызов уведомлением. Канал «Входящие звонки» должен иметь высокую важность.
- Приближение: в соединённом аудиозвонке через разговорный динамик приложите телефон к уху и уберите — экран должен гаснуть и загораться. Повторите после сворачивания звонка. На громкой связи/гарнитуре, при видео или показе экрана экран не отключается. После завершения звонка управление экраном освобождается. Нужен поддерживаемый системный датчик приближения.
- Видео: из меню личного чата выберите «Видеозвонок», разрешите камеру и микрофон на обоих телефонах. Камера запускается после соединения; её можно отключить или сменить. Перетащите маленькое собственное видео — оно остаётся внутри области звонка и доступно после смены ориентации. Перемещение относится к окну внутри звонка, не к системной плавающей панели поверх других приложений.
- Обновления: при публикации следующего APK в вашем серверном `/download` приложение покажет «Вышла новая версия». Нажмите «Обновить»: APK скачивается с проверкой SHA-256, затем открывается установщик. Если требуется, разрешите установку APK для Волны и подтвердите установку. Android не разрешает обычному приложению незаметную установку. «Позже» оставляет кнопку обновления в приложении; проверка версии выполняется при запуске и каждые 15 минут. Новая версия GitHub появляется на телефоне после сборки и публикации APK на сервере этим блоком команд.

Проверки выпуска: 40 Android unit-тестов, сборка APK 0.12.19 и проверка версии/подписи, 113 серверных тестов. В облачной среде нет эмулятора и физического телефона; визуальное совпадение, пробуждение экрана, датчик приближения, звук и видео между реальными телефонами требуют проверки по пунктам выше.
