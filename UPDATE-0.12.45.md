# Обновление Волны до 0.12.45

Выполнены доработки по шести голосовым и скрину папок.

Реакции показываются компактными плашками с эмодзи и до трёх перекрывающихся аватарок. Для остальных участников отображается +N, полный список доступен через удержание Android/контекстное меню Web и Windows. Одиночная реакция не имеет цифры 1. В светлой теме плашки светлые, в тёмной следуют теме. API передаёт публичные avatar_url и порядок добавления, изображения загружаются обычным механизмом клиента.

Время и реакции размещены в одной нижней строке, также у голосовых. В Android обычный текст без вложений/дополнительных состояний получает время в конце последней строки; сложные сообщения сохраняют отдельный нижний ряд, чтобы не перекрывать содержимое. Быстрые реакции и палитра Android больше не забирают фокус клавиатуры. В Web/Windows нажатие плашки ставит/убирает свою реакцию, контекстное меню открывает список участников.

Отправка текста/вложений Android больше не устанавливает подсветку найденного сообщения. Поиск и переход к цитате сохраняют подсветку. Волна записи усилена по измеренной амплитуде, без изменения аудиосигнала. Android использует MIC вместо необработанного микрофона; AAC 128 кбит/с, 48 кГц, моно сохранены. Качество записи на конкретном Samsung требует сравнения на телефоне. Собственный Android-аудиофайл декодируется и кэшируется до показа сообщения; Web/Windows берут собственный файл из ограниченного кэша вместо повторного скачивания.

Новые аккаунты получают пустой список папок. Если папок нет или осталась только системная «Все чаты», полосы нет. При первой папке «Все чаты» добавляется в интерфейс, а не сохраняется на сервер как новая папка. Существующие сохранённые папки не удаляются; при необходимости удалите ненужные в настройках. Полоса Android продолжает занимать всю ширину и прокручиваться при переполнении.

Сервер, Web, Android и Windows собираются следующей командой в прежнем каталоге с compose.yaml и .env. Данные и подпись сохраняются. Облачный Debug APK с тестовым адресом API пользователям не устанавливайте.

```sh
(
  set -eu
  test -f compose.yaml && test -f .env
  volna_update_dir=$(mktemp -d)
  trap 'rm -rf "$volna_update_dir"' EXIT
  git clone --depth 1 --branch v0.12.45 \
    https://github.com/andluk87/volna.git "$volna_update_dir/source"
  git -C "$volna_update_dir/source" archive \
    --output="$volna_update_dir/source.tar" HEAD
  sh "$volna_update_dir/source/scripts/backup.sh"
  tar -xf "$volna_update_dir/source.tar" -C .
  VOLNA_BUILD_NETWORK=host sh scripts/build-clients.sh
)
```

Публикация исходников не означает автоматическое обновление производственного сервера. Значок Huawei этим выпуском не объявляется исправленным.

Проверки: 161 ранее существовавший Node-тест и новый интеграционный тест порядка/данных реакций прошли (162 всего). 89 Android/JVM-тестов и итоговая Android Debug сборка прошли. Web собран; браузером проверены отсутствие папок, появление «Все чаты» с первой папкой, фильтрация, аватарки реакций, отсутствие цифры 1, расположение времени и сохранение фокуса ввода.
