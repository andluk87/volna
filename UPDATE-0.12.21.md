# Обновление Волны до 0.12.21

Android: новые экраны звонка, карточки истории в чате, вибрация и выбор звуков. Исправлено согласование двухстороннего видео в Android, Web и Windows. Блок ниже собирает оба приложения и обновляет сервер. Запускайте целиком в прежнем каталоге Волны, где лежат `compose.yaml` и `.env`. Нужны Docker, Git, доступ к сети и свободное место для сборок. `VITE_API_URL` в существующем `.env` должен указывать на ваш HTTPS API.

Локальные исходники заменяются версией GitHub; перед заменой создаётся резервная копия данных. `.env`, данные и подпись Android сохраняются. Не удаляйте `artifacts/android-home`: прежняя подпись нужна для установки APK поверх установленного приложения.

```sh
(
  set -eu
  test -f compose.yaml && test -f .env
  volna_update_dir=$(mktemp -d)
  trap 'rm -rf "$volna_update_dir"' EXIT
  git clone --depth 1 --branch v0.12.21 \
    https://github.com/andluk87/volna.git "$volna_update_dir/source"
  git -C "$volna_update_dir/source" archive \
    --output="$volna_update_dir/source.tar" HEAD
  sh "$volna_update_dir/source/scripts/backup.sh"
  tar -xf "$volna_update_dir/source.tar" -C .
  VOLNA_BUILD_NETWORK=host sh scripts/build-clients.sh
)
```

После завершения установите новый Android APK через предложение обновления в Волне или `https://ВАШ_CHAT_DOMAIN/download/volna-android.apk`. Windows получит новый установщик через свой механизм обновления; файлы доступны на `/download`. Сборки проверяются перед публикацией. Тег GitHub сам по себе не обновляет установленные приложения: этот блок публикует собранные клиенты на вашем сервере.

После установки откройте **Настройки → Уведомления**. Звук и вибрация входящих звонков и сообщений включены по умолчанию; ранее сохранённые отключения не сбрасываются. «Рингтон звонка» и «Звук сообщения» открывают системный список звуков, включая вариант «Без звука». Вибрация задаётся отдельно. Системный беззвучный режим, «Не беспокоить» и запрещённые уведомления имеют приоритет.

Для видео обновите оба клиента. По умолчанию каждый участник видит собеседника на весь экран, себя — в маленьком окне. Касание маленького окна меняет их местами; перетаскивание сохраняет положение. Кнопка «Вкл. видео» в аудиозвонке открывает локальный предпросмотр. Выберите переднюю/заднюю камеру, затем «Включить трансляцию»; до подтверждения этот предпросмотр собеседнику не отправляется.

История в Android-чате появляется карточками по времени рядом с сообщениями: исходящие справа, входящие слева, с состоянием и длительностью. Нажатие повторяет аудио- или видеозвонок. История не выдаётся чужому участнику и сохраняется в локальном кэше. При открытом чате серверная история обновляется примерно каждые 10 секунд, а после завершения текущего звонка запрашивается заново. Более ранние звонки доступны кнопкой загрузки истории.

Проверки выпуска: 126 серверных и 47 Android unit-тестов, APK 0.12.21 (12021), сборка Web и React render, Windows-установщик с проверкой версии и SHA-512, браузерный сценарий контактов/видео.

Проверка на двух телефонах обязательна: видео/звук в обе стороны, вибрация, рингтоны, заблокированный экран, смена камеры и отказ в её разрешении. В облачной среде нет телефона или эмулятора; обмен медиаданными через интернет и аппаратная вибрация здесь не проверены. Браузерный сценарий проверяет SDP sendrecv, одну видеодорожку у каждого участника и поведение интерфейса; состояние ICE имитируется из-за политики облачного Chromium.
