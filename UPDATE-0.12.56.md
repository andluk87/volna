# VLN 0.12.56 — компактные панели и анимация записи голоса

Панель папок и нижняя навигация Android оформлены в одном стиле по присланным примерам.

- Округлая подложка немного светлее основного фона.
- Выбранная папка или раздел выделяется ещё более светлой плашкой с оттенком акцента.
- Текст и иконка выбранного пункта светлее плашки; остальные подписи имеют единый приглушённый цвет.
- Панель папок стала ниже: высота пункта 40 dp вместо 48 dp, уменьшены внутренние и внешние отступы.
- Нижняя навигация стала компактнее. Сохранены счётчик чатов, аватар профиля и действия всех четырёх разделов.
- Цвета берутся из оформления аккаунта. В светлой теме выделение остаётся контрастным, выбранная плашка — светлее общей подложки.

## Запись голосовых сообщений

Android, Windows и веб-клиент: более заметные анимации при записи. Плавно меняется высота звуковой волны по реальному сигналу микрофона; добавлена полупрозрачная огибающая, яркость отражает амплитуду. У кнопки микрофона расходятся два кольца и пульсирует значок, у времени записи — индикатор. Новые декоративные эффекты отключаются настройками анимаций/энергосбережения; веб-интерфейс также соблюдает `prefers-reduced-motion`. Показ реального уровня звука остаётся доступен. Волны на экране звонка не возвращены.

Сценарий записи, отмены, закрепления и отправки не изменялся.

## Проверки

Проверены 106 Android/JVM-тестов и сборка Debug APK 0.12.56 (`12056`, `dev.volna.messenger`, VLN). В Compose/Robolectric отрисованы настоящие компоненты обеих панелей вместе, включая счётчик 73: [снимок проверки](design/checks/0.12.56/android-navigation.png).

В браузере проверены реакция звуковой волны на изменение входного сигнала, изменение огибающей, анимация кнопки, отключение эффектов и очистка аудиоанализатора при отмене. Сборки Web и Windows NSIS прошли; проверены SHA-512, размер и blockmap установщика.

[Снимок записи в браузере](design/checks/0.12.56/recording-wave.png). Проверка использует управляемый аудиосигнал, а не аппаратный микрофон.

Изменения панелей относятся к Android; анимации записи — к Android, Windows и веб-клиенту. Приложения по-прежнему называются **VLN**, сайт — **Volna**. Настоящий телефон в этой среде не использовался; проверочный APK с адресом `https://example.invalid` не публикуется для установки.

## Обновление сервера и установщиков

Это публикация исходников в теге `v0.12.56`. В рабочей среде нет производственного `.env` и доступа к установленному серверу. Проверочные APK/EXE используют `https://example.invalid` и не публикуются для установки.

Выполните в прежнем каталоге сервера с `compose.yaml` и `.env`. Блок создаёт резервную копию и собирает оба клиента с существующими адресами и Android-ключом, затем публикует их штатным процессом проекта.

```sh
(
  set -eu
  test -f compose.yaml && test -f .env
  volna_update_dir=$(mktemp -d)
  trap 'rm -rf "$volna_update_dir"' EXIT
  git clone --depth 1 --branch v0.12.56 \
    https://github.com/andluk87/volna.git "$volna_update_dir/source"
  git -C "$volna_update_dir/source" archive \
    --output="$volna_update_dir/source.tar" HEAD
  sh "$volna_update_dir/source/scripts/backup.sh"
  tar -xf "$volna_update_dir/source.tar" -C .
  VOLNA_BUILD_NETWORK=host sh scripts/build-clients.sh
)
```

Для первого запуска новых Compose/JVM-тестов потребуется сеть: Robolectric загружает Android runtime; последующие контейнерные сборки используют постоянный Gradle-кэш. Для ручного Gradle-прогона предварительно выполните штатный `python3 android-native/scripts/prepare-expressions.py --cache <каталог-кэша>`; Docker-сборщик делает это сам.

## Проверка после установки

1. Откройте список чатов с несколькими папками: проверьте три уровня светлоты, компактную высоту и переключение папок.
2. Переключите «Чаты», «Контакты», «Настройки», откройте «Профиль»; проверьте выбранный пункт, счётчик и аватар.
3. Повторите в светлой теме и с увеличенным системным шрифтом: подписи и счётчики должны оставаться доступными.

4. Начните запись голосового, изменяйте громкость речи: волна должна плавно реагировать. Проверьте отмену, закрепление и отправку, затем повторите с отключёнными анимациями.
