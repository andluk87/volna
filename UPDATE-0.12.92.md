# VLN 0.12.92 — Волна в контактах Android

У зарегистрированных пользователей из телефонной книги автоматически появляется действие **«Волна / Написать в Волне»** в системной карточке контакта. Нажатие открывает переписку в том аккаунте, который обнаружил контакт. Отдельного переключателя нет: используется существующая синхронизация контактов, доступ Android к чтению и изменению телефонной книги и действующий вход в аккаунт. Если синхронизация уже включена, при первом открытии обновлённой Волны Android запросит недостающее разрешение.

Волна добавляет собственные связанные записи через Contacts Provider и отдельный аккаунт Android. Исходные записи, номера, фотографии и имена не изменяются. Повторная синхронизация не создаёт дубликаты; учитывается объединение Google/Samsung/телефонных записей. Удалённые/больше не найденные контакты теряют отметку. При выключении синхронизации или выходе удаляются только записи соответствующего аккаунта Волны. Обновление выполняется при открытой Волне; без разрешения Android запись в системные контакты невозможна. Если разрешение было отозвано, удаление собственных записей через Contacts Provider откладывается до возвращения доступа; при выходе дополнительно удаляется собственный аккаунт Android.

Внешний вид, группировка и наличие действия в системной карточке зависят от приложения «Контакты» производителя. Нужно проверить на физическом телефоне: открыть существующую карточку зарегистрированного пользователя, найти Волну и нажать «Написать в Волне». Если контакты скрыты фильтром источников, включите источник «Волна» в приложении «Контакты». Автотесты не заменяют проверку интерфейса Samsung/Google Contacts.

Также включено исправление TURN: явный relay-IP вместо wildcard 0.0.0.0. По умолчанию используется TURN_EXTERNAL_IP, назначенный серверу; при другой топологии есть TURN_RELAY_IP. Подробности — docs/CALLS-1TO1.md.

## Обновление одной вставкой

Из существующего каталога проекта с `.env`:

```sh
( set -eu; test -f compose.yaml && test -f .env; volna_update_dir=$(mktemp -d); trap 'rm -rf "$volna_update_dir"' EXIT; git clone --depth 1 --branch v0.12.92 https://github.com/andluk87/volna.git "$volna_update_dir/source"; git -C "$volna_update_dir/source" archive --output="$volna_update_dir/source.tar" HEAD; sh "$volna_update_dir/source/scripts/backup.sh"; if [ -d android-native/app/src ]; then mkdir -p backups; volna_source_backup=$(mktemp -d "$PWD/backups/android-source-0.12.92-XXXXXXXX"); mv android-native/app/src "$volna_source_backup/src"; fi; tar -xf "$volna_update_dir/source.tar" -C .; VOLNA_BUILD_NETWORK=host sh scripts/build-clients.sh )
```

После сборки установите Android 0.12.92 и разрешите изменение контактов в системном запросе. Если запрос ранее отклонён: Волна → Контакты → Контакты и синхронизация → Настройки доступа Android. Серверные секреты и ключи подписи сохраняются; источники контактов и аккаунтов других приложений не удаляются.

Проверки: полный Android unit/UI suite, затем 5 целевых тестов новой интеграции с итоговыми ресурсами Contacts; сборка APK 103,3 МиБ и проверка версии 12092; 230 Node-тестов; production-сборки Web и Windows renderer. Физический Samsung/Google Contacts и установщик Windows в этой среде не проверялись.
