# Волна 0.12.0 — SMS и QR

Это изменение системы аккаунтов по новому ТЗ. Старые пользователи, пароли, Telegram-привязки, сеансы, переписки и вложения не переносятся в новую активную базу. Перед удалением создаются административные резервные копии. Первый SMS-вход создаёт новый профиль; повторный вход с тем же номером открывает его же.

## Подготовка

Распакуйте полный исходный архив поверх проекта, сохранив `.env`, `artifacts`, Docker volumes и кэши сборок. Не выполняйте `docker compose down -v`. Сохраните ключ подписи Android: без него установленные приложения не обновятся поверх старой версии.

Добавьте в существующий `.env` настоящие значения из кабинета Notificore:

```dotenv
NOTIFICORE_API_KEY=ваш_ключ
NOTIFICORE_ORIGINATOR=ваш_согласованный_отправитель
SMS_REFERENCE_START=0
AUTH_TRUST_PROXY=1
```

`SMS_REFERENCE_START` — последний использованный номер reference. Если уже был `ext_id_004`, укажите `4`, чтобы следующая SMS получила `ext_id_005`. После первого запуска счётчик хранится в SQLite и не сбрасывается изменением `.env`. Старые `TELEGRAM_*` больше не используются, их можно удалить. Сохраните реальные `CHAT_DOMAIN`, `VITE_API_URL`, `ALLOWED_ORIGINS`, TURN и настройки Whisper. Ключ Notificore не помещается в APK, EXE или Web.

## Один переход с 0.11.x

Из каталога проекта:

```sh
VOLNA_BUILD_NETWORK=host sh scripts/upgrade-phone-auth.sh
```

Скрипт проверяет наличие SMS-настроек, собирает и публикует Android и Windows, затем создаёт внешний `backups/volna-*.tar.gz`, останавливает API, делает проверенную SQLite-копию старой базы, выводит старые данные из активного каталога и обновляет сервисы. Если сборка одного из клиентов не удалась, сброс аккаунтов ещё не запускается. Копия старой базы и медиа остаётся внутри volume в `/data/legacy-auth-backups/`, с доступом только для администратора. Новая база создаётся пустой. Не восстанавливайте старую копию в новую систему входа.

Если на сервере сборка Docker работает с обычной сетью, запускайте ту же команду без `VOLNA_BUILD_NETWORK=host`.

## Дальнейшие обновления

После завершённого перехода используется обычный общий сборщик:

```sh
VOLNA_BUILD_NETWORK=host sh scripts/build-clients.sh
```

Отдельно: `sh scripts/build-android.sh` или `sh scripts/build-windows.sh`. Повторный запуск миграции на базе с телефонными аккаунтами пропускает сброс. Скрипты не заменяют `.env`.

## Проверка

```sh
curl -sS https://volna.lknet.ru/api/auth/config
docker compose logs --tail=80 server
sh scripts/check-downloads.sh all
```

Ожидаемый config: `mode: phone-qr-v1`, `sms_enabled: true`. Это подтверждает наличие конфигурации, а не баланс или готовность имени отправителя у провайдера. Если SMS не приходит, проверьте кабинет Notificore: API-ключ, отправителя, баланс и доступ сервера к HTTPS `api.notificore.ru`.

Установите Android 0.12.0 (versionCode 12000). Введите международный номер и код из SMS. Код действует пять минут, повторная отправка доступна через минуту; новый код заменяет предыдущий, после пяти ошибок требуется новый. Текст SMS: `123-456 твоя волна`. Имя, фото и описание меняются в профиле. Телефон виден только владельцу.

Откройте Web `/app` или Windows. На телефоне: Настройки → Безопасность → Сканировать QR. Проверьте тип устройства и адрес подключения, затем подтвердите вход. QR действует три минуты и используется один раз. В разделе активных сеансов можно завершить другие подключения.

Главная `/` содержит ссылки на Android, Windows и Web. После успешной сборки:

- Android: `https://volna.lknet.ru/download/volna-android.apk`;
- Windows: `https://volna.lknet.ru/download/volna-windows.exe`;
- Web: `https://volna.lknet.ru/app`.

## Что реализовано и проверено

Сервер: Notificore HTTPS, случайные шестизначные коды, HMAC вместо открытого кода в базе, TTL, одноразовость, лимиты номера/IP, атомарный reference, уникальный телефон, независимые сеансы устройств, обновление токенов и отзыв доступа. QR имеет отдельные секреты сканирования и опроса; вход выдаётся только после явного подтверждения в Android. Старые способы входа возвращают 404.

Android: нативный SMS-экран, CameraX/ML Kit QR-сканер, подтверждение устройства, Android Keystore/AES-GCM для сеансов, обновление токена в API и фоновом соединении, очищение старых аккаунтов и локальной базы при первом запуске новой версии. Функции переписок, звонков, вложений, эмодзи, тем и обновления APK сохранены.

Web: QR вместо форм пароля/Telegram; access-токен в памяти, refresh в HttpOnly/Secure-cookie. Windows: QR и зашифрованный refresh через Electron safeStorage; обновления и Docker-сборщик сохранены.

Локально прошли серверные/функциональные тесты, проверка React-компонентов и сборка Web/Windows renderer. QR проверен на восстановление исходных байтов и корректность Reed–Solomon. Android проверен статически, но Kotlin/APK, сканирование камерой и Windows EXE здесь не собирались: Docker, Android SDK и Gradle в среде отсутствуют. Отправка реальной SMS требует вашего ключа и не проверялась. Архив содержит исходники и сборщики, а не готовые APK/EXE.
