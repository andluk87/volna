# Волна 0.12.99 — полноценная отложенная отправка в Web и Windows

Правой кнопкой на отправке открывается меню с эффектами, тихой отправкой, выбором времени и ожиданием появления контакта в сети. «Отправить позже» теперь открывает окно «Время отправки» с календарём, отдельным 24-часовым полем времени, кнопкой звука и выбором повторения.

Повторы: никогда, ежедневно, еженедельно, раз в две недели, ежемесячно, раз в три месяца, раз в шесть месяцев и ежегодно. Они работают на сервере при закрытом клиенте. Используется часовой пояс устройства, выбранный при настройке серии. При переходе на летнее/зимнее время сохраняется местное время. День 31 в коротком месяце переносится на последний день, а в следующем длинном месяце возвращается к 31-му. Ежегодный повтор 29 февраля использует 28 февраля в невисокосные годы.

После планирования открывается отдельный экран «Отложенные сообщения»: пузырьки сообщений, разделители с датой или надписью «Отправка при появлении в сети», время, значок звука и период повторения. Обычное поле ввода остаётся внизу; отправка из этого экрана предлагает выбрать время, включая вложения и голосовые. Правой кнопкой по сообщению можно изменить текст/время/повторение, отправить сейчас, выделить или удалить. В меню экрана есть групповые действия с подтверждением.

Удаление серии отменяет будущие повторы; уже отправленные сообщения сохраняются. «Отправить сейчас» отправляет очередной экземпляр и оставляет будущие повторы. При редактировании серии новая выбранная дата становится её начальной датой. После длительной остановки сервера отправляется один просроченный экземпляр, затем очередь переходит к ближайшему будущему времени без потока всех пропущенных повторов.

Старые отложенные сообщения 0.12.98 сохраняются как однократные. Повторные отправки и перенос следующей даты выполняются одной транзакцией. Вложения серии сохраняются до её отмены; файл, зарезервированный очередью, нельзя случайно удалить или отправить как новое независимое вложение. Опросы, списки задач, стикеры и GIF отправляются из обычной переписки; из очереди их мгновенная отправка отключена. Сохраняются проверки прав отправки и приватность статуса «в сети»; повторение вместе с ожиданием появления в сети не поддерживается.

## Обновление одной вставкой

Из существующей папки проекта с `.env`:

```sh
( set -eu; test -f compose.yaml && test -f .env; volna_update_dir=$(mktemp -d); trap 'rm -rf "$volna_update_dir"' EXIT; git clone --depth 1 --branch v0.12.99 https://github.com/andluk87/volna.git "$volna_update_dir/source"; git -C "$volna_update_dir/source" archive --output="$volna_update_dir/source.tar" HEAD; sh "$volna_update_dir/source/scripts/backup.sh"; if [ -d android-native/app/src ]; then mkdir -p backups; volna_source_backup=$(mktemp -d "$PWD/backups/android-source-0.12.99-XXXXXXXX"); mv android-native/app/src "$volna_source_backup/src"; fi; tar -xf "$volna_update_dir/source.tar" -C .; python3 scripts/improve-transcription.py; VOLNA_BUILD_NETWORK=host sh scripts/build-clients.sh )
```

Обновите сервер и Windows до 0.12.99, Web перезагрузите. Android собирается с общей версией 0.12.99; новый интерфейс планирования относится к Web и Windows. Модель распознавания, TURN и существующие настройки не меняются. Локальная модель без интернета импортируется по [инструкции 0.12.97](UPDATE-0.12.97.md).

## Проверки

Прошли 251 Node-тест и 227 Android-тестов; собраны Web, Windows renderer и Android APK 12099. Проверены API повторов, перезапуск, миграция старой очереди, пропущенные даты, часовые пояса и переходы DST, месяцы/високосные годы, повторная отправка вложений, редактирование и отмена серии. В Chromium для Web/Windows проверены календарь, время, все пункты повторения, звук/эффект, отдельный экран очереди, ввод нового сообщения из очереди, изменение текста/даты, отмена, ожидание активности и отправка сейчас. Также проверен предыдущий сценарий тем, календаря истории и меню отправки. Физический Windows в этой среде недоступен; обновление на вашем сервере автоматически не выполняется.
