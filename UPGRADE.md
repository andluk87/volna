# Волна 0.11.41 — обновление Android, Windows и сайта

Полная инструкция нового Android и сборки обоих клиентов: [UPDATE-0.11.41.md](UPDATE-0.11.41.md).

В 0.11.41 добавлены панель эмодзи/стикеров/GIF, серверный каталог и расширенное оформление. Для этих функций обновите API/Web скриптом вместе с Android и установите APK 0.11.41. Первая сборка загружает Noto/Unicode/CLDR и Haze в существующие кэши; `ANDROID_BUILD_OFFLINE=0 VOLNA_BUILD_NETWORK=host sh scripts/build-android.sh` разрешает эту загрузку. Файлы `.env`, данные и весь `artifacts` сохраняйте. Список реализации: [ANDROID-EXPRESSIONS-THEMES-0.11.40.md](ANDROID-EXPRESSIONS-THEMES-0.11.40.md).

1. Распакуйте архив **в папку над действующим проектом** (обычно `~/`). В архиве уже есть папка `volna-messenger`, её файлы заменят соответствующие файлы проекта. `.env` в архив не входит и останется на месте.
2. Перед запуском проверьте в корне проекта:

```sh
grep '"version"' package.json
```

Команда должна показать `0.11.41`. Для обновления сервера и Web выполните:

```sh
sh scripts/update.sh
```

Для **обоих клиентов** и одного обновления сервера/Web:

```sh
sh scripts/build-clients.sh
```

После успеха установите предложенное обновление Android 0.11.41. При наличии кнопки «Включить экран входящего звонка» разрешите уведомления и полноэкранный показ, затем проверьте вызов с погашенным экраном. Enter теперь вставляет перенос строки.

Windows устанавливается один раз по `/download/volna-windows.exe`, следующие версии предлагает обновить внутри приложения. Отдельная сборка Windows: `sh scripts/build-windows.sh`. Подробности: [WINDOWS-BUILD.md](WINDOWS-BUILD.md).

Для сборки и публикации Android вместе с сервером и Web выполните:

```sh
sh scripts/build-android.sh
```

Если Web пишет «TURN не настроен», используйте вместо обычной Android-команды:

```sh
sh scripts/build-android.sh --enable-calls
```

Она сохранит существующий TURN-секрет (либо создаст новый при его отсутствии), определит домен/IPv4 и выполнит одну сборку APK с обновлением сервера/Web/TURN. Остальные значения `.env`, включая Telegram и прокси, сохраняются. В firewall провайдера VPS разрешите TCP/UDP 3478 и UDP 49160–49200. Повторно запускать этот флаг при каждой сборке не требуется. Проверить настройки работающего контейнера и TCP: `sh scripts/check-calls.sh`.

3. Дождитесь `Verified web assets: Volna 0.11.41.` При сборке Android дополнительно появятся `Verified Android network permissions in compiled APK.` и `Verified Android download and update manifest.` Android-скрипт публикует APK и JSON-манифест обновления. Если установленный APK ещё не поддерживает проверку обновлений, установите APK по `/download/volna-android.apk` один раз; следующие версии приложение предложит скачать и установить само.

Для новых функций требуется **установить APK 0.11.41 на телефон**; обновление только сервера не меняет разрешения установленного приложения. Сборщик выполняет `:app:testDebugUnitTest`, затем проверяет разрешения в готовом APK перед экспортом. Новые зависимости в 0.11.34 не добавлены; режим `auto` сохраняется. Если вылет повторится, снова откройте приложение, дождитесь дополнения отчёта и нажмите «Диагностика звонка» → «Копировать». Указывается точная операция, причина Android и нативный стек при его наличии. Отчёт 0.11.33 подтвердил SIGABRT в сетевом потоке; точное Java-исключение в нём отсутствует.

В 0.11.31 исправлена первая сборка с отсутствующим плагином Gradle. Теперь `auto` повторяет её онлайн один раз и сохраняет скачанные зависимости. Если сборка 0.11.30 уже остановилась на `com.android.application`, можно временно запустить `ANDROID_BUILD_OFFLINE=0 sh scripts/build-android.sh` с имеющимися файлами.

Для новых Android-функций выполните `sh scripts/build-android.sh` и установите предложенное обновление APK. Полный каталог `artifacts` сохраняйте: там кеш и ключ подписи. В `.env` можно добавить `ANDROID_BUILD_OFFLINE=auto`; это режим по умолчанию. Новые библиотеки впервые потребуют загрузки. См. [ANDROID-BUILD.md](ANDROID-BUILD.md).

Для исправления `jwks_invalid_json` достаточно серверного обновления; установленный Android-клиент использует тот же сервер и не требует переустановки. После обновления проверьте ответ JWKS:

```sh
docker compose exec -T server node server/check-telegram-jwks.mjs
```

Ожидается `"ok":true`, `"status":200`, `"body":"json"` и ненулевое число `rsaKeys`. Если `"body":"html"` или `"body":"empty"`, с сервера приходит страница либо пустой ответ; это требует проверки выхода через прокси. Сжатые ответы поддерживаются. Вывод команды можно прислать целиком: в нём нет секретов, токенов или тела ответа.

Начните новый Telegram-вход с главной страницы. Старый callback-код уже использован и повторно не сработает.

При первом автообновлении Android может попросить разрешить установку приложений для Волны, затем показать системное подтверждение замены. Это обязательное подтверждение Android. Не удаляйте `artifacts/android-home`: каталог хранит ключ подписи, который позволяет ставить новые APK поверх предыдущих.

Текущий адрес остаётся https://volna.lknet.ru, без :8090. Настройки HTTPS и TURN повторно задавать не требуется. Скрипт делает резервную копию базы и вложений. При старте сервер добавляет таблицу профилей Telegram; старые сообщения и аккаунты сохраняются.

Telegram username используется как логин, если он не занят. При первом входе пароль предлагается задать автоматически; для восстановления нажмите «Забыли пароль?» и подтвердите вход через Telegram. `.env` сохраняется скриптом. Если Telegram-вход выключен, проверьте наличие Client ID, Client Secret и точного callback URL по инструкции [TELEGRAM-LOGIN.md](TELEGRAM-LOGIN.md); секрет не передавайте в чат и не добавляйте в архив.

## Где находятся новые функции

- **⋯ в шапке списка чатов → Внешний вид**: тема, плотность, шрифт, акцент, форма сообщений и предпросмотр.
- **Скрепка → Фото и видео**: выбрать несколько файлов; можно перетащить файлы в чат.
- **⋯ у сообщения / правая кнопка / долгое нажатие**: действия и реакции.
- **Нажатие на реакцию**: список участников и изменение своей реакции.
- **Кнопка Aa рядом с полем сообщения**: форматирование жирным, курсивом, зачёркиванием, цитатой и кодом. Кодовый блок можно скопировать одной кнопкой.
- **Голосовое**: нажмите микрофон для начала записи, нажмите ещё раз для отправки. Рядом с плеером нажмите «А»: сервер распознаёт речь локальной бесплатной моделью Whisper, а результат сохраняется в сообщении. Ключ или оплата API не нужны.
- **Экран входа → Продолжить через Telegram**: появится после настройки ключей бота на VPS. Войдите повторно после обновления, чтобы импортировать доступные данные профиля.
- **Аватар → Мой профиль**: данные Telegram, включая телефон только для владельца.
- **Android → значок профиля внизу или человек в шапке личного чата**: просмотр профиля; свой профиль позволяет изменить имя и описание и показывает полученные данные Telegram.


Для ускорения распознавания замените существующие параметры Whisper в `.env` на эти (если параметров нет — добавьте):

```dotenv
WHISPER_MODEL=base
WHISPER_CPU_THREADS=4
WHISPER_BEAM_SIZE=1
WHISPER_LANGUAGE=ru
WHISPER_COMPUTE_TYPE=int8
```

`base` и один луч поиска ускоряют работу ценой небольшой части точности. Если приоритет — точность, верните `WHISPER_MODEL=small` и `WHISPER_BEAM_SIZE=5`. `WHISPER_LANGUAGE=ru` пропускает автоопределение языка; для многоязычных голосовых укажите `WHISPER_LANGUAGE=auto`. На первом запуске после смены модели Compose скачает её веса в постоянный Docker volume. Само распознавание происходит на CPU вашего VPS и не тарифицируется.


## Проверка после установки

- Откройте настройки и измените тему, размер текста и плотность. Перезагрузите страницу: настройки должны сохраниться.
- Отправьте два фото одним альбомом. Проверьте сетку и открытие фото.
- Поставьте реакцию со второго аккаунта и откройте список участников.
- Проверьте ответ, редактирование, удаление и прежние голосовые сообщения.
- Проверьте микрофон и звонок между двумя устройствами.

Отдельные APK/EXE нужно пересобрать, чтобы они получили новый интерфейс. Установленная PWA обновляется с сервера.

В случае ошибки пришлите её текст и вывод:

```sh
docker compose ps -a
docker compose logs --tail=80 server web
```

Для ошибки входа важна строка `[telegram-login] ID token verification: ...`. Она различает недоступность JWKS, неверную подпись и конкретную группу несовпавших OIDC-полей. Перед отправкой проверьте, что в выводе нет секретов из других строк.

Не отправляйте секреты, `.env` или копию базы. Не используйте `docker compose down -v`: команда удаляет данные. Автоматического отката нет; перед восстановлением старой копии сохраните актуальную базу.

## Звонки в 0.11.16

Веб-версия получает полноэкранный интерфейс звонка и выбор доступного аудиовыхода браузера. Для поддержки звонка при выключенном экране на Android пересоберите и установите новый APK через Android builder: в APK добавлен foreground service с уведомлением, частичным wake lock и фоновым heartbeat сервера. Браузер/PWA на телефоне не может гарантировать выполнение аудио в фоне; для этой функции используйте Android APK.


## Звонки и голосовые в 0.11.17

Во время разговора нажмите «Свернуть», чтобы открыть переписку и оставить звонок активным в Web-клиенте. Демонстрация экрана использует Screen Capture API браузера. В нативном Kotlin APK звонки и демонстрация экрана добавлены в 0.11.30.

Для голосового один раз нажмите микрофон, чтобы начать запись, и нажмите его ещё раз для отправки. Кнопка записи пульсирует; waveform и таймер отображаются внутри строки ввода. Кодек выбирается так: Opus mono, 48 kHz, целевые 64 kbit/s; при отсутствии Opus MediaRecorder используется AAC. Для сайта достаточно обновления веб-контейнера. Для установленного Android приложения пересоберите и установите APK, чтобы получить новый интерфейс.


## Android APK и ссылка на скачивание в 0.11.18

В `.env` укажите `VITE_API_URL=https://ваш-домен`, затем из корня проекта выполните `sh scripts/build-android.sh`. Скрипт соберёт APK в Docker, добавит его в веб-ресурсы и запустит `scripts/update.sh`. После успешной проверки файл доступен на странице входа по кнопке «Волна для Android» и по адресу `/download/volna-android.apk`. Для Android используется debug-подпись; для постоянного обновления уже установленного APK нужен собственный release keystore.


## Android в 0.11.25

В 0.11.25 Android собирается как отдельное Kotlin/Jetpack Compose приложение. Добавлены null-safe разбор истории, системные нижние отступы, Material-иконки, emoji-панель, реакции, ответы, редактирование/удаление/закрепление, вложения и аудиосообщения AAC с воспроизведением и серверным распознаванием. Foreground service держит SSE-соединение и показывает Android-уведомления, когда приложение свёрнуто. Web Push всё ещё настраивается отдельно в браузерной версии; звонки и управление группами пока не перенесены.
