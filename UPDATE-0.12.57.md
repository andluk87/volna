# VLN 0.12.57 — настройка папок и нижней навигации Android

Откройте **Настройки → Настройки чатов → Оформление папок / Нижняя навигация**.

Обе панели настраиваются независимо:

- минимальная высота пунктов, скругление, отступ от краёв;
- размер подписей, для нижней панели — также размер иконок;
- отображение подписей, иконок и счётчиков;
- свои цвета подложки, выбранного пункта, обычного и выбранного текста/иконок;
- «Авто» у каждого цвета возвращает цвет текущей темы;
- закреплённый сверху предпросмотр показывает изменения сразу.

Подписи и иконки нельзя одновременно скрыть. В режиме без подписей папка без своего значка получает стандартный символ; названия остаются доступны для озвучивания. В нижней панели счётчик чатов доступен и в режиме одних подписей.

**Сброс:** «Сбросить оформление папок», «Сбросить нижнюю навигацию» и общий пункт «Сбросить папки и навигацию». Они возвращают стандартные параметры VLN из 0.12.56 и не меняют остальное оформление, аккаунты или содержимое чатов.

Настройки сохраняются для текущего аккаунта после перезапуска и входят в существующую синхронизацию оформления Android. Старые настройки без новых полей сохраняют стандартный вид. Свои цвета применяются к обеим темам; автоматические цвета адаптируются к светлой/тёмной теме.

- Настоящие Compose-компоненты: изменение скругления, скрытие подписей, установка цвета через HEX, сохранение, индивидуальный сброс и общий сброс. Проверено, что оформление другой панели и радиус пузырьков сохраняются при индивидуальном сбросе.

## Обновление сервера и установщиков

Это публикация исходников в теге `v0.12.57`. В рабочей среде нет производственного `.env` и доступа к установленному серверу. Проверочные APK/EXE используют `https://example.invalid` и не публикуются для установки.

Выполните в прежнем каталоге сервера с `compose.yaml` и `.env`. Блок создаёт резервную копию и собирает оба клиента с существующими адресами и Android-ключом, затем публикует их штатным процессом проекта.

```sh
(
  set -eu
  test -f compose.yaml && test -f .env
  volna_update_dir=$(mktemp -d)
  trap 'rm -rf "$volna_update_dir"' EXIT
  git clone --depth 1 --branch v0.12.57 \
    https://github.com/andluk87/volna.git "$volna_update_dir/source"
  git -C "$volna_update_dir/source" archive \
    --output="$volna_update_dir/source.tar" HEAD
  sh "$volna_update_dir/source/scripts/backup.sh"
  tar -xf "$volna_update_dir/source.tar" -C .
  VOLNA_BUILD_NETWORK=host sh scripts/build-clients.sh
)
```

Для первого запуска новых Compose/JVM-тестов потребуется сеть: Robolectric загружает Android runtime; последующие контейнерные сборки используют постоянный Gradle-кэш. Для ручного Gradle-прогона предварительно выполните штатный `python3 android-native/scripts/prepare-expressions.py --cache <каталог-кэша>`; Docker-сборщик делает это сам.

## Проверка после установки

1. Откройте оба раздела настройки, измените размеры, скругление, отступы, цвета и видимость элементов. Предпросмотр должен оставаться видимым при прокрутке настроек.
2. Перезапустите приложение, проверьте сохранение. Переключите аккаунт — оформление должно относиться к выбранному аккаунту.
3. Сбросьте только папки: нижняя панель и остальная тема должны сохраниться. Повторите для нижней панели и общего сброса.
4. Проверьте светлую/тёмную тему и увеличенный системный шрифт; при необходимости верните цвета «Авто».
