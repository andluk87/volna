# Обновление Волны до 0.12.18

В этом выпуске переработан **Android-интерфейс чата** по предоставленным скриншотам Telegram. Обновление контейнеров само по себе не изменит приложение на телефоне: обязательно установите новый APK.

Скопируйте блок целиком в терминал в прежнем каталоге Волны с `compose.yaml` и `.env`. Он загрузит точную версию GitHub, создаст резервную копию данных, соберёт и опубликует APK, обновит контейнеры. Локальные изменения исходников заменяются; данные, `.env` и прежний ключ подписи APK сохраняются. Адрес API берётся из `VITE_API_URL` существующего `.env`.

```sh
(
  set -eu
  test -f compose.yaml && test -f .env
  volna_update_dir=$(mktemp -d)
  trap 'rm -rf "$volna_update_dir"' EXIT
  git clone --depth 1 --branch v0.12.18 \
    https://github.com/andluk87/volna.git "$volna_update_dir/source"
  git -C "$volna_update_dir/source" archive \
    --output="$volna_update_dir/source.tar" HEAD
  sh "$volna_update_dir/source/scripts/backup.sh"
  tar -xf "$volna_update_dir/source.tar" -C .
  VOLNA_BUILD_NETWORK=host VOLNA_BUILD_PUBLISH_ONLY=1 sh scripts/build-android.sh
  VOLNA_BUILD_NETWORK=host sh scripts/update.sh
)
```

После завершения откройте `https://ВАШ_CHAT_DOMAIN/download/volna-android.apk` на телефоне и установите APK поверх текущего приложения. Также можно использовать проверку обновлений в Волне. Не удаляйте `artifacts/android-home`: там сохраняется подпись, необходимая для установки поверх прежнего APK.

В чате появились округлая шапка с поиском, значок закладки для «Избранного», компактные текстовые и голосовые сообщения, округлая строка ввода и панель закрепа с переходом к сообщению. В панели эмодзи наборы находятся сверху, категории рядом с поиском; доступны недавние, популярные наборы, стикеры, GIF и удержание для выбора оттенка кожи. Скорость воспроизведения доступна у выбранного голосового. Запись, отмена и фиксация записи жестами сохранены.

Для сравнения со скриншотами выберите стандартную тёмную тему и масштаб 100%: свои темы, цвета и масштаб сохраняются. Сравните на одном телефоне и при одинаковом системном размере шрифта. Проверьте короткий и длинный текст, ответ, вложение, голосовое/расшифровку, переход по закрепу, поиск эмодзи и переход обратно к клавиатуре. При увеличенном шрифте длинные сообщения сохраняют отдельную строку времени.

Проверки выпуска: 36 Android unit-тестов, сборка APK 0.12.18, проверка версии и подписи, 113 серверных тестов. Эмулятора и физического телефона в облачной среде нет; визуальное совпадение пиксель в пиксель не подтверждено.
