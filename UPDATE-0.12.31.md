# Обновление Волны до 0.12.31

Обновляются API и Android: первый вход с уникальным ником, меню форматирования и настройки обновлений. Сборка также согласует версии Web и Windows. Предыдущие исправления сайта включены.

Запустите блок в прежнем каталоге Волны с `compose.yaml` и `.env`. Перед заменой исходников создаётся резервная копия данных. `.env`, данные и подпись Android сохраняются; не удаляйте `artifacts/android-home`. `VITE_API_URL` должен указывать на ваш настоящий HTTPS API. Облачные тестовые сборки с `example.invalid` устанавливать не нужно.

```sh
(
  set -eu
  test -f compose.yaml && test -f .env
  volna_update_dir=$(mktemp -d)
  trap 'rm -rf "$volna_update_dir"' EXIT
  git clone --depth 1 --branch v0.12.31 \
    https://github.com/andluk87/volna.git "$volna_update_dir/source"
  git -C "$volna_update_dir/source" archive \
    --output="$volna_update_dir/source.tar" HEAD
  sh "$volna_update_dir/source/scripts/backup.sh"
  tar -xf "$volna_update_dir/source.tar" -C .
  VOLNA_BUILD_NETWORK=host sh scripts/build-clients.sh
)
```

После сборки установщик Windows доступен на `/download`; установленный Windows-клиент получает версию 0.12.31 через штатную проверку обновлений. Web обновляется на сервере вместе с сервисами. Если открыта старая вкладка, перезагрузите её. Настройки, аккаунты и переписки сохраняются. Android пересобирается с прежней подписью, поэтому устанавливается поверх существующего приложения. Канал новостей создаётся после запуска обновлённого API.

Проверьте на Android: первый вход новым номером, одинаковые имя и фамилию у двух аккаунтов, занятый ник и выбор предложенного, продолжение незавершённой регистрации после перезапуска. Выделите текст долгим нажатием → «Форматирование»; проверьте ссылку, спойлер и блок кода. «Настройки → Обновления»: переключатель сохраняется после перезапуска, доступна ручная проверка и выбор установки. Системное подтверждение установки APK остаётся обязательным.

Облачный проверочный APK использует `example.invalid` и не предназначен для установки. Соберите приложение приведённым блоком с вашим API и прежней подписью.
