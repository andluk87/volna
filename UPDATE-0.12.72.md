# VLN 0.12.72 — Android: анимации, «Поделиться», меню и навигация

- **Анимированные эмодзи на Android.** Одиночный стандартный эмодзи в сообщении проигрывается один раз и повторно по нажатию. В APK включены 580 анимаций из общего набора Web/Windows с проверкой SHA-256 и сохранением исправлений сердца и градиентов из 0.12.71. Вне видимой области и при уходе приложения в фон анимация останавливается. Энергосбережение и отключение анимаций убирают автоматическое воспроизведение; нажатие запускает его явно. Unicode и действия по долгому нажатию сохраняются.
- **Приём через Android «Поделиться».** В системном списке появляется «Волна (VLN)». Принимаются текст, ссылки и до 10 вложений по 20 МБ. Перед отправкой нужно выбрать получателя; текст можно изменить, для файлов открывается предпросмотр с подписью. Вложения сначала копируются в кэш приложения. Ничего не отправляется автоматически; при ошибке сети можно повторить отправку.
- **Верхнее меню.** Цвета выбранной темы, скруглённая панель, крупные подписи и контурные значки. Основные пункты: дневной/ночной режим, создание группы, избранное и настройки. Новый чат, канал, приглашение, архив и аккаунты сохранены в «Ещё». Пункта прокси нет: приложение пока не поддерживает настройку прокси.
- **Нижняя навигация.** В `Настройки → Настройки чатов → Нижняя навигация → Третий раздел` можно выбрать «Настройки» или «Звонки»; по умолчанию оставлены «Звонки», как в 0.12.71. Выбор сохраняется для аккаунта и входит в облачное оформление. Настройки всегда доступны через верхнее меню. Прежние размеры, цвета и остальные параметры навигации сохраняются.

Из прежней папки сервера с `compose.yaml` и существующим `.env`, одной вставкой:

```sh
( set -eu; test -f compose.yaml && test -f .env; volna_update_dir=$(mktemp -d); trap 'rm -rf "$volna_update_dir"' EXIT; git clone --depth 1 --branch v0.12.72 https://github.com/andluk87/volna.git "$volna_update_dir/source"; git -C "$volna_update_dir/source" archive --output="$volna_update_dir/source.tar" HEAD; sh "$volna_update_dir/source/scripts/backup.sh"; if [ -d android-native/app/src ]; then mkdir -p backups; volna_source_backup=$(mktemp -d "$PWD/backups/android-source-0.12.72-XXXXXXXX"); mv android-native/app/src "$volna_source_backup/src"; fi; tar -xf "$volna_update_dir/source.tar" -C .; sh scripts/build-clients.sh )
```

Команда создаёт резервную копию, сохраняет прежние исходники Android в `backups/`, загружает тег `v0.12.72` и запускает общий сборщик. `.env`, база, аккаунты, переписки и ключ подписи Android сохраняются.

После сборки установите APK поверх прежней версии. Перезапустите приложение, из которого открываете «Поделиться», если его список получателей ещё закэширован. Установите Windows поверх прежней версии; Web обновите через `Ctrl+F5`.

Проверка на телефоне: отправьте отдельный 😁 и нажмите на него; поделитесь ссылкой из браузера и фото из галереи в «Волна (VLN)»; откройте верхнее меню; выберите «Звонки» в оформлении нижней навигации и перезапустите VLN.

Проверено: сборка APK, 143 Android unit/UI-теста в Robolectric, 194 общих теста (`npm test`), production-сборка Web, контрольные SHA-256 всех 580 TGS и шрифта внутри APK, отдельный тест сохранения прозрачности градиентов. Системный chooser и внешний вид на физическом телефоне нужно проверить после установки. Тестовый APK в этой среде собран с диагностическим доменом; для установки используйте APK, собранный на вашем сервере с существующим `.env`.
