# Волна 0.12.5 — оформление и эмодзи Web

## Что изменено

- Настройки → Внешний вид: шесть готовых тем с миниатюрами, светлый/тёмный/системный режим и мгновенный предпросмотр. Сохраняются прежние параметры текста, плотности, формы пузырей, аватаров, времени и пользовательских обоев. Выбор темы не сбрасывает размер текста или плотность.
- Акцент учитывается в собственных сообщениях; выбранный фон работает и в тёмной теме.
- Панель эмодзи: компактные категории с иконками, поиск, прокручиваемая сетка, нижние вкладки «Эмодзи / Волна / Стикеры / GIF» и удаление предыдущего символа целиком, включая составные эмодзи.
- Добавлены распространённые лица; выбор тона кожи сохраняется. Кнопка настроек в панели включает управление избранным и очистку недавних.
- «Волна → Наборы»: создание, установка и удаление из своих; у собственного небазового набора — редактирование названия и описания через существующий серверный API. Изменение изображений уже опубликованного набора этим выпуском не добавлено.
- Убрана рамка/тень при фокусе редактора сообщения. Клавиатурная подсветка кнопок сохранена.
- Версия исходников Web/API/Android синхронизирована: 0.12.5, Android versionCode 12005. Сборщики Android/Windows и действующая авторизация сохранены.

Сравнение проводилось с открытым авторизованным Telegram Web K: настройки тем, категории, поиск и нижняя панель эмодзи, геометрия левой колонки. Полное совпадение всех экранов Telegram и пиксельная приёмка не заявляются.

## Обновить Web и сервер

Распакуйте `volna-messenger-0.12.5.zip` поверх существующего проекта. Не удаляйте `.env`, volumes, `artifacts`, `backups`, ключ подписи Android и кэши сборщиков. В архиве — полный исходный проект; вашей базы, секретов, APK и EXE нет.

```sh
cd ~/volna-messenger
VOLNA_BUILD_NETWORK=host sh scripts/update.sh
```

Дождитесь `Verified web assets: Volna 0.12.5.` и обновите страницу. Переход с 0.12.x не требует сброса данных.

## Android и Windows

Для сборки обоих клиентов и обновления сервисов:

```sh
VOLNA_BUILD_NETWORK=host sh scripts/build-clients.sh
```

Или отдельно:

```sh
VOLNA_BUILD_NETWORK=host sh scripts/build-android.sh
VOLNA_BUILD_NETWORK=host sh scripts/build-windows.sh
```

Изменения интерфейса относятся к Web и Windows renderer. Нативный Android в этом выпуске получает новую версию, его интерфейс не перерабатывался. APK/EXE необходимо собрать этими скриптами на вашем сервере.

## Проверки

78 автоматических тестов, серверный рендер React и production-сборки Web/Windows renderer прошли. Интерактивная проверка Волны в этой среде заблокирована: Chromium завершается с SIGTRAP до открытия страницы. Поэтому прохождение браузерных сценариев и точное визуальное совпадение не подтверждены. Новый сценарий проверяет темы, отсутствие рамки, вставку/удаление эмодзи и управление недавними.

На машине с рабочим Chromium:

```sh
npm ci
npm ci --prefix client
npm test
npm run test:render
npm run build --prefix client
cd client
npx playwright install chromium
npm run test:visual -- --grep='темы сохраняются'
```

Настройки оформления, недавние Unicode-эмодзи, их избранное и тон кожи сохраняются на этом устройстве. Наборы пользовательских эмодзи управляются сервером.
