# Волна 0.12.2 — новый Web-клиент и исправление запуска nginx

## Обновление с 0.12.0 / 0.12.1

Обновление добавочное. Аккаунты, SMS/QR-вход, переписки, группы, подтемы и настройки уведомлений сохраняются. Сбрасывать данные не нужно.

Распакуйте исходники поверх существующего проекта `~/volna-messenger`, сохранив свой `.env`, Docker volumes, `artifacts`, `backups`, Android signing key и кэши сборщиков. Не выполняйте `docker compose down -v`.

### Обновить сервер и веб-интерфейс

```sh
cd ~/volna-messenger
VOLNA_BUILD_NETWORK=host sh scripts/update.sh
```

Этот вариант не пересобирает APK и установщик Windows. Уже опубликованные скачиваемые приложения остаются на сервере.

### Собрать Android, Windows и обновить сервисы одним скриптом

```sh
cd ~/volna-messenger
VOLNA_BUILD_NETWORK=host sh scripts/build-clients.sh
```

Docker-скрипты Android и Windows и механизмы обновлений сохранены. В этом выпуске изменены Web и общий интерфейс Windows; в нативном Android синхронизирован номер версии.

Если используете 0.11.x, сначала прочитайте `UPDATE-0.12.0.md`: переход на телефонную авторизацию имеет отдельные требования. Приведённая выше гарантия сохранения данных относится к 0.12.0 / 0.12.1.

## Ошибка запуска nginx в 0.12.1

Сообщение `pcre2_compile() failed: missing closing parenthesis in "^/([a-zA-Z0-9_]"` возникает из-за некавыченного регулярного выражения в `docker/nginx.conf`.

В 0.12.2 строка исправлена:

```nginx
location ~ "^/([a-zA-Z0-9_]{4,32})/$" { return 308 /$1; }
```

В `docker/web.Dockerfile` добавлен обязательный `nginx -t` при сборке. На время проверки адрес upstream заменяется на localhost, после проверки возвращается исходный конфиг: сборке не требуется DNS сервиса `server`.

Если нужен только срочный ремонт 0.12.1 без полного обновления, замените указанную строку в текущем конфиге, затем:

```sh
docker compose build web
docker compose run --rm --no-deps web nginx -t
docker compose up -d --no-deps --force-recreate web
```

Для второй команды сервис `server` должен работать и быть доступен в сети Compose. Данные и Android/Windows при этом не затрагиваются.

## Что изменилось по ТЗ

- Две основные панели; справа — информация о чате. От 1200 px она уменьшает переписку, на планшете открывается поверх, на телефоне занимает экран.
- Компактное меню ☰, круглый поиск, вкладки «Все чаты», «Личные», «Группы», «Каналы», «Непрочитанные»; архив через меню и отдельную строку.
- Строки чатов с аватаром, временем, превью, черновиком, счётчиком непрочитанных, закреплением и отключёнными уведомлениями.
- Поиск пользователей, чатов и сообщений по всем перепискам. `Ctrl/Cmd+K` фокусирует общий поиск; `Ctrl/Cmd+F` открывает поиск текущего чата.
- Заголовок с кликабельным именем/аватаром, основными действиями и меню ⋯.
- Правая панель: профиль, описание, username, уведомления, участники сообщества; вкладки медиа, файлов, ссылок и голосовых с дозагрузкой истории и переходом к сообщению.
- Светлая, тёмная и системная темы; выбор узора, однотонного фона или своих обоев JPEG/PNG/WebP до 5 МБ. Изображение хранится локально в IndexedDB. Размер текста, плотность, радиус, акцент, аватары и время сохраняются.
- Группировка сообщений одного автора, даты «Сегодня / Вчера», ограниченная ширина пузырей, более спокойная служебная информация.
- Голосовые в одной строке: play/pause, waveform, перемотка, длительность, скорость, кнопка А для серверной расшифровки.
- Фото открываются в существующем полноэкранном просмотрщике. Видео загружается по нажатию и воспроизводится в переписке. Фото/аудио подгружаются по приближению к видимой области, где браузер поддерживает IntersectionObserver.
- В панели эмодзи — вкладки стикеров и GIF с поиском и каталогом реальных наборов Волны; недавние/избранные — по данным сервера.
- Безопасное форматирование сообщения: жирный, курсив, подчёркивание, зачёркивание, код и цитаты; обычные HTTP/HTTPS-ссылки кликабельны. HTML из сообщений не выполняется.
- Выбор нескольких сообщений, копирование, пересылка и подтверждаемое удаление с учётом прав.
- Состояние «Отправляется», ошибка и повторная отправка с исходным идентификатором для защиты от дубликатов.
- Входящие сообщения не сбрасывают чтение старой истории; появляется кнопка перехода вниз. При загрузке старых сообщений сохраняется позиция. Черновики действуют в текущей вкладке через sessionStorage; старый локальный черновик переносится при входе и удаляется из localStorage.
- Меню закрываются по Escape/внешнему нажатию; стрелки/Home/End перемещают фокус. Учитываются safe-area и высота экранной клавиатуры, Reduce Motion и ручное отключение анимаций.
- Виртуализация списка чатов при более чем 80 строках; история сообщений мемоизирована, чтобы ввод текста не перерисовывал пузырь каждого сообщения.
- Раздел «Данные и хранилище» показывает доступную браузеру оценку занятого места и позволяет очищать кэш вложений без удаления аккаунта/настроек.

## Отдельная локальная демонстрация

Откройте:

https://volna.lknet.ru/app?demo=1

Также доступна ссылка «Посмотреть интерфейс · Демо» на начальной странице и странице QR-входа.

Демо использует тот же интерфейс, но отдельный адаптер данных: 24 чата, более 10 вымышленных пользователей и 288 сообщений, фото, видео, тестовый звук, файл, стикер/GIF, ответы, пересылки и реакции. Работают локальные отправка, редактирование, удаление, поиск, архивирование, закрепление, уведомления чата и просмотр вложений. Сообщения демонстрации не попадают на сервер.

В демо можно открыть пример входа по телефону с вымышленным номером и кодом `123456`. Это не SMS и не код Telegram. Реальный вход Волны остаётся по QR с Android. Настоящие звонки и некоторые административные серверные операции доступны только после входа в действующую Волну.

Демо-переписки и загруженные в него файлы живут в памяти вкладки. После перезагрузки используется исходный набор. Раздел «Данные и хранилище» содержит кнопку сброса демо. Оформление сохраняется отдельно как несекретные настройки.

Это переработка существующего клиента Волны, а не интеграция с реальными аккаунтами Telegram. React/Vite и действующий API сохранены; проект не переводился полностью на TypeScript/Zustand/React Router. Русский язык сохранён; полный английский перевод в этот выпуск не включён.

## Проверка

В рабочем окружении прошли:

- 65 автоматизированных тестов, включая новый демо-адаптер, поиск, группировку, форматирование и регрессию nginx.
- Серверные тесты SMS/QR, аккаунтов, подтем, уведомлений и остальных существующих функций.
- Рендеринг настоящих React-компонентов: переписка, действия, настройки, информационная панель и демонстрационный вход.
- Production-сборки Web и интерфейса Windows.

Docker, Android SDK и браузерный Chromium в этом окружении недоступны. Здесь не собраны APK/EXE, не выполнен настоящий `nginx -t` и не проведена интерактивная проверка в Chrome/Firefox/Safari на устройствах. `nginx -t` включён в Docker-сборку; итоговую работу сервисов проверяет скрипт обновления на сервере.

Адреса после вашей сборки:

- Web: https://volna.lknet.ru/app
- Android: https://volna.lknet.ru/download/volna-android.apk
- Windows: https://volna.lknet.ru/download/volna-windows.exe

Сервер должен публиковать новую версию файлов: не достаточно только заменить ZIP или перезапустить старый образ. После обновления обновите страницу/перезапустите установленную Волну.
