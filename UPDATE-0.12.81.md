# VLN 0.12.81 — записи и уведомления о пропущенных звонках в чатах

Пропущенные звонки теперь видны в списке чатов: значок звонка, подпись, время и счётчик непрочитанного. Внутри чата — отдельные карточки входящих, пропущенных и отменённых вызовов с повторным звонком по нажатию. Завершение звонка обновляет список на подключённых устройствах. Более новое сообщение заменяет превью звонка; прочтение сообщений не скрывает ещё не просмотренные звонки.

Из прежней папки сервера с `compose.yaml` и `.env`, одной вставкой:

```sh
( set -eu; test -f compose.yaml && test -f .env; volna_update_dir=$(mktemp -d); trap 'rm -rf "$volna_update_dir"' EXIT; git clone --depth 1 --branch v0.12.81 https://github.com/andluk87/volna.git "$volna_update_dir/source"; git -C "$volna_update_dir/source" archive --output="$volna_update_dir/source.tar" HEAD; sh "$volna_update_dir/source/scripts/backup.sh"; if [ -d android-native/app/src ]; then mkdir -p backups; volna_source_backup=$(mktemp -d "$PWD/backups/android-source-0.12.81-XXXXXXXX"); mv android-native/app/src "$volna_source_backup/src"; fi; tar -xf "$volna_update_dir/source.tar" -C .; sh scripts/build-clients.sh )
```

После сборки установите Android-обновление через `Настройки → Обновления`, обновите Windows поверх прежней версии и перезагрузите Web. Данные и ключ подписи сохраняются. Для счётчика пропущенных необходимо обновление сервера.

Проверка: позвоните с другого аккаунта и отмените до ответа. У получателя появится «Пропущенный звонок» с непрочитанным, у звонящего — «Отменённый звонок». Откройте чат получателя: должна появиться карточка, счётчик сбрасывается на всех его устройствах. После состоявшегося разговора показывается «Входящий звонок»/«Исходящий звонок» с длительностью. Вибрация приоритетных звонков 0.12.80 сохранена.

Фактический вид на телефоне и Windows нужно проверить после установки. Предупреждение форматирования Caddyfile также исправлено стандартными отступами в исходниках.

Проверено: 212 Node-тестов, React render-тесты карточек и превью звонка, 188 Android unit/UI-тестов и сборка APK; production-сборки Web и интерфейса Windows. Нативный Windows EXE и реальные устройства в этой среде не запускались.
