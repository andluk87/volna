# Волна 0.12.97 — переносы строк, вставка фото и импорт модели без интернета

## Голосовые: восстановление без доступа контейнера к сети

При `URLError [Errno 101] Network is unreachable` загрузка модели в контейнере не может завершиться. Это проблема сетевой доступности. Живой HTTP health не означает готовую модель.

Скачайте [зафиксированную ревизию GigaAM v3](https://huggingface.co/istupakov/gigaam-v3-onnx/tree/322c3b29492673eb7d0b434bfa9dfb8653e34d02): `config.json`, `v3_e2e_rnnt_encoder.onnx`, `v3_e2e_rnnt_decoder.onnx`, `v3_e2e_rnnt_joint.onnx`, `v3_e2e_rnnt_vocab.txt`, `LICENSE.txt`. Нужны файлы **без `.int8`**, основной encoder — около 0,9 ГБ. Сложите их на сервере в `artifacts/gigaam-v3/` внутри проекта, без дополнительного вложенного каталога.

Скрипт совместим с уже установленной 0.12.96. Можно восстановить распознавание, не дожидаясь пересборки клиентов. Из папки проекта:

```sh
curl -fL --connect-timeout 10 --max-time 60 https://raw.githubusercontent.com/andluk87/volna/v0.12.97/scripts/import-asr-model.sh -o scripts/import-asr-model.sh
sh scripts/import-asr-model.sh
```

Скрипт проверяет комплектность, копирует веса в отдельный каталог постоянного volume и проверяет загрузку полной модели на CPU. Только после успешной проверки он сохраняет приватную копию `.env`, задаёт локальный путь и пересоздаёт **только** `transcription`. Существующие модели не удаляются. При неуспешной проверке выбор модели в `.env` не меняется. Готовность подтверждается полем `ready:true`; интернет для локальной модели не требуется. После этого нажмите «Распознать заново» в клиенте.

Если интернет доступен самому хосту, но недоступен Docker bridge, альтернативный `sh scripts/prefetch-asr.sh` скачивает веса во временном контейнере с host network в тот же volume, затем перезапускает `transcription`. Это не переводит сам сервис на host network и не публикует порт 8000. Этот вариант не поможет, если Hugging Face недоступен и хосту.

## Исправления Windows и Web

Редактор, API и отображение сохраняют пустые строки, несколько переносов подряд, повторные пробелы, табуляцию и отступы. Удалены обрезание краёв сообщения на сервере и замена пустых строк отступами CSS. Проверка сообщений из одних пробелов остаётся. Смещения пользовательских эмодзи больше не пересчитываются под обрезанный текст; это проверено для отправки, редактирования, пересылки и подписей альбомов.

Ctrl+V с картинкой из буфера открывает существующий предпросмотр фото. После подтверждения фото прикрепляется к текущему черновику; отправка остаётся ручной. Подпись сохраняется. Несколько файлов из буфера обрабатываются обычным механизмом вложений. Вставка текста и пользовательских эмодзи сохранена. При редактировании сообщения или занятой отправке картинка не заменяет черновик: показывается причина.

Загрузчик GigaAM теперь запрашивает известные имена файлов по закреплённой ревизии без получения списка репозитория. Каждая завершённая загрузка сохраняется отдельно; Xet отключён, используются обычные HTTP-загрузки с таймаутами. В health и ответе о загрузке видны стадия и число файлов; в health также имя текущего файла и занятые байты. Ошибка отсутствия сети отличается от обычного ожидания модели. Это не заменяет настройку сети сервера: для изолированного контейнера используйте импорт выше.

## Полное обновление одной вставкой

Из существующей папки проекта с `.env`:

```sh
( set -eu; test -f compose.yaml && test -f .env; volna_update_dir=$(mktemp -d); trap 'rm -rf "$volna_update_dir"' EXIT; git clone --depth 1 --branch v0.12.97 https://github.com/andluk87/volna.git "$volna_update_dir/source"; git -C "$volna_update_dir/source" archive --output="$volna_update_dir/source.tar" HEAD; sh "$volna_update_dir/source/scripts/backup.sh"; if [ -d android-native/app/src ]; then mkdir -p backups; volna_source_backup=$(mktemp -d "$PWD/backups/android-source-0.12.97-XXXXXXXX"); mv android-native/app/src "$volna_source_backup/src"; fi; tar -xf "$volna_update_dir/source.tar" -C .; python3 scripts/improve-transcription.py; VOLNA_BUILD_NETWORK=host sh scripts/build-clients.sh )
```

Для исправления отображения установите Windows 0.12.97 поверх текущей версии и перезагрузите Web. Сервер тоже нужно обновить для сохранения пробелов и переносов по краям текста. Внутренние пустые строки старых сообщений, сохранившиеся в базе, появятся после обновления клиента. Ранее обрезанные сервером крайние пробелы восстановить автоматически нельзя. Android получает тот же серверный текст, отдельных изменений его редактора в этом выпуске нет.

Проверки: 240 Node-тестов; настоящий API и Chromium в режимах Windows/Web — набор Shift+Enter, отправка, редактирование, высота пустых строк, пробелы, табуляция, копирование выделения и реальный Ctrl+V из системного буфера с PNG, предпросмотр и отправка фото с подписью. Проверены цитаты/выделение текста, 19 Python/HTTP-тестов и Docker-образ распознавания, новая загрузка всех шести файлов в пустой кэш без API списка репозитория, работа реальных CPU-весов без сети, сборки Web/Windows renderer и APK. На пользовательском Windows установщике и с сетью вашего сервера автоматическая проверка недоступна.

Дополнительный старый сценарий `tests/windows-ui.mjs` прошёл форматирование и undo/redo, затем остановился на ожидании папок у нового аккаунта: его фикстура не создаёт папки. Целевые Windows/Web сценарии отправки, редактирования, Ctrl+V и цитат прошли. Полное прохождение этого старого сценария не заявляется.
