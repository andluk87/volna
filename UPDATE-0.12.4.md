# Волна 0.12.4 — переработка Web по ТЗ 2.0

Это сборка для проверки. Новый интерфейс реализован по публичному исходному коду Telegram Web K, но точное визуальное совпадение в пределах ±2/±3 px **ещё не подтверждено**. Не завершены сравнение одинаковых эталонных скриншотов и интерактивный браузерный прогон. Исходные измерения и процедура: `design/reference/README.md`.

## Что изменено

- Приложение занимает окно целиком; боковые панели по 360 px, внешние отступы desktop 16 px, область сообщений ограничена 696 px. На телефоне открывается одна панель.
- Список: строки 72 px, аватары 54 px, двухбуквенные инициалы, единые SVG-иконки Web K, Roboto из локальных файлов.
- Поле ввода и круглая кнопка отправки/микрофона разделены. Форматирование перенесено в меню вложений. Запись показывает время, волну и отмену внутри поля. Enter отправляет с обычной клавиатуры, Shift+Enter переносит строку; на сенсорном телефоне используйте кнопку отправки.
- Отдельные scroll viewport и содержимое переписки; групповые уголки и хвостики; время размещается у последней строки обычного текста. Время сохраняется у цитат, кода и вложений. Копирование текста исключает метаданные.
- Поиск открывается отдельным экраном левой панели с вкладками. Настройки и оформление тоже открываются внутри панели.
- Пользовательские локальные папки: создание, выбор чатов, переименование, удаление, сохранение на устройстве. Пока папок нет, панель вкладок скрыта. Папки не синхронизируются с сервером.
- В демо появились опросы: создание, выбор одного ответа, смена и отмена голоса, проценты, пересылка с независимым результатом. Настоящий серверный API опросов этим выпуском не добавлен, поэтому действие доступно только в демо.
- Сохранены действующие SMS/QR-вход, чаты, звонки, группы/подтемы, профиль, файлы, реакции, эмодзи, Whisper и Docker-сборщики Android/Windows.

Не реализованы изменение ширины/сворачивание боковой панели как в оригинале и полное воспроизведение всех переходов/состояний Web K. Геометрия правого профиля, фон и оттенки темы требуют дальнейшей калибровки по эталону.

## Обновить только сервисы и Web

Распакуйте полный архив `volna-messenger-0.12.4.zip` поверх существующего проекта. Сохраните `.env`, Docker volumes, `artifacts`, `backups`, Android signing key и кэши сборщиков. В архиве нет вашей `.env`, базы, APK или EXE.

```sh
cd ~/volna-messenger
VOLNA_BUILD_NETWORK=host sh scripts/update.sh
```

Ожидаемая строка проверки после успешного обновления: `Verified web assets: Volna 0.12.4.` Затем обновите страницу браузера. Если версия осталась прежней, проверьте завершение скрипта и обновите кэш установленного PWA.

Переход с 0.12.x не требует сброса базы. Не удаляйте Docker volumes. Для перехода с 0.11.x действует отдельная `UPDATE-0.12.0.md`.

## Android и Windows

Все сборщики сохранены. Чтобы собрать и опубликовать оба клиента и обновить сервисы:

```sh
VOLNA_BUILD_NETWORK=host sh scripts/build-clients.sh
```

Отдельно:

```sh
VOLNA_BUILD_NETWORK=host sh scripts/build-android.sh
VOLNA_BUILD_NETWORK=host sh scripts/build-windows.sh
```

Общая версия — 0.12.4, Android versionCode — 12004. Изменения интерфейса относятся к Web и общему Windows renderer. Функциональный код нативного Android этим выпуском не перерабатывался. APK/EXE в текущей среде не собраны; скрипты собирают их на вашем сервере, используя существующую подпись и метаданные обновлений.

## Проверка перед установкой

```sh
npm ci
npm ci --prefix client
npm test
npm run test:render
npm run build --prefix client
cd client
npx playwright install chromium
npm run test:visual -- --update-snapshots
npm run test:visual
```

Матрица Playwright включает 40 запусков: четыре сценария, пять разрешений, две темы. Первый запуск создаёт baseline **Волны** — его нужно проверить вручную. Он не заменяет сравнение с Telegram Web K. Для сравнения снимков предусмотрен `scripts/compare-reference.py` с 50% overlay и pixel diff.

В этой среде подтверждены: 77/77 тестов данных и API; SSR действующих React-компонентов, включая новые опросы, папки и timestamp; Web production build; Windows renderer build с HTTPS API; перечисление 40 Playwright тестов. Фактическая попытка запуска Playwright закончилась SIGTRAP Chromium до открытия страницы. Браузерные тесты, звонки на устройствах и точное сравнение скриншотов не пройдены.

## Демо и лицензии

Откройте `/app?demo=1`, нажмите «Открыть демо». Данные вымышлены и изолированы от настоящих аккаунтов. Новые папки находятся в «Настройки → Папки чатов», опрос — в меню вложений.

SVG-геометрия и рисунок обоев Web K распространяются с GPL-3.0; полный исходный веб-клиент и лицензия включены в архив. Шрифт Roboto — SIL OFL 1.1. Перечень и исходный commit: `client/licenses/THIRD-PARTY.md`. Лицензирование отдельных программ server/native Android этим выпуском не изменяется.
