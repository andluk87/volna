# Волна Native Desktop 0.1.1 — обновлённый интерфейс

[Скачать Windows x64](https://github.com/andluk87/volna/releases/tag/native-v0.1.1): установщик `Volna-Native-Setup-0.1.1.exe`, portable ZIP, соответствующие исходники и SHA-256.

Переработаны основной экран, список чатов и настройки. Папки расположены в отдельной боковой панели; появились аватары, компактные сообщения с отметками доставки, растущее поле ввода и панель эмодзи. Enter отправляет сообщение, Shift+Enter добавляет строку. Поиск внутри переписки открывает найденное сообщение, нажатие на дату вызывает календарь перехода к нужному дню.

Фотографии открываются в отдельном просмотрщике с масштабированием и сохранением. При открытии фотографии из альбома переключение ограничено снимками этого альбома. Превью и аватары загружаются с авторизацией, кеш ограничен памятью и очищается при выходе из аккаунта.

Сохраняются вход по QR/номеру, файлы, голосовые и аудио-/видеозвонки. Сборка Windows проверяет не только запуск упакованного приложения без Qt SDK, но и настоящий HTTPS-запрос к серверу и создание QR-запроса. Ошибки DNS, TLS, прокси и тайм-аута теперь различаются в диагностике.

## Установка

Закройте Native Desktop и запустите новый установщик. Сеанс версии 0.1.0 сохраняется. Автообновления нативного установщика пока нет; установщик не подписан цифровой подписью. Требуются Windows 10/11 x64. Действующие Electron- и Android-клиенты остаются отдельными приложениями.

Если звонки уже работают в Native 0.1.0, обновлять сервер для этой версии не нужно. Иначе серверу 0.12.112 нужна Web-страница `native-call.html`: [подготовка сервера](UPDATE-NATIVE-0.1.0.md#подготовить-сервер). Код входа приходит в «Волна — служебные уведомления» на уже подключённом устройстве.

## Проверки и ограничения

C++-тесты проверяют QR, палитры, SSE, защищённое хранилище и клавиатуру редактора. Интеграционные проверки работают с настоящим локальным API: вход по коду/QR, восстановление сеанса, повтор отправки без дубликатов, поиск, переход к сообщению, темы, фото и ограничение альбома. Аудио/видео проверяются через локальный coturn с тестовыми устройствами Chromium, включая RTP, кадры видео, обновление токена, сворачивание и голосовые. Физические устройства и смена сети Windows требуют проверки на компьютере.

Это самостоятельный Qt/C++-клиент протокола Волны с палитрами Telegram Desktop и QR-компонентом из его зависимостей. Звонки используют общий модуль Волны в изолированном Qt WebEngine. Полный перенос функций продолжается: пока нет управления группами, нескольких аккаунтов, реакций/стикеров, расписания отправки и выбора экрана для демонстрации. [Исходники, сборка и лицензии](desktop-native/README.md).
