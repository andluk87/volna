# VLN 0.12.77 — Android: главный экран по видеопримеру

Перелистывание папок свайпом и нажатием на вкладку, плавный индикатор и сохранение прокрутки. Нижняя панель остаётся на месте при переходах и в профиле. Выбор «Звонки» / «Настройки» и собственное оформление сохранены. Поиск раскрывается из шапки; круглые кнопки действий; в контактах — «Пригласить друзей» и «Недавние звонки».

Из прежней папки сервера с `compose.yaml` и существующим `.env`, одной вставкой:

```sh
( set -eu; test -f compose.yaml && test -f .env; volna_update_dir=$(mktemp -d); trap 'rm -rf "$volna_update_dir"' EXIT; git clone --depth 1 --branch v0.12.77 https://github.com/andluk87/volna.git "$volna_update_dir/source"; git -C "$volna_update_dir/source" archive --output="$volna_update_dir/source.tar" HEAD; sh "$volna_update_dir/source/scripts/backup.sh"; if [ -d android-native/app/src ]; then mkdir -p backups; volna_source_backup=$(mktemp -d "$PWD/backups/android-source-0.12.77-XXXXXXXX"); mv android-native/app/src "$volna_source_backup/src"; fi; tar -xf "$volna_update_dir/source.tar" -C .; sh scripts/build-clients.sh )
```

Команда создаёт резервную копию, сохраняет прежние исходники Android в `backups/`, загружает тег `v0.12.77` и запускает общий сборщик. `.env`, база, аккаунты, переписки и ключ подписи Android сохраняются.

После сборки откройте в VLN `Настройки → Обновления → Проверить обновления` и подтвердите установку поверх прежней версии. Обновите Windows поверх прежней версии и перезагрузите Web через `Ctrl+F5`.

Проверка на Android:

1. Создайте две папки с чатами, перелистните в обе стороны и нажмите вкладку. Список и выбранная вкладка должны совпадать.
2. Прокрутите разные папки, переключитесь и вернитесь — каждая сохраняет своё место.
3. Откройте контакты, недавние звонки и профиль. Нижняя панель остаётся видимой; настройки доступны из профиля и верхнего меню.
4. Раскройте поиск в шапке. Back закрывает поиск и возвращает папки; из архива Back возвращает список чатов.
5. В оформлении замените «Звонки» на «Настройки», измените цвета/размер панели. Переходы и выбранный раздел остаются корректными.
6. Отключите анимации или включите энергосбережение — переключение кнопками выполняется без длительного перехода.

Проверены 178 Android unit/UI-тестов, 199 Node-тестов, React render-тесты, production-сборка Web и APK (~103 МиБ, четыре ABI, ниже старого лимита 120 МиБ). Установка на физическом телефоне и сравнение плавности 60 FPS в этой среде не выполнялись.
