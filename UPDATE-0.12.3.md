# Волна 0.12.3 — Emoji Engine Web MVP

В этом выпуске переработан выбор и ввод эмодзи по первому этапу нового ТЗ. Полный исходный проект сохранён: сервер, Web, нативный Android, Windows и Docker-скрипты сборки.

## Что добавлено

- Кастомные статичные эмодзи прямо в поле ввода и тексте сообщений.
- 24 фирменные эмоции; каталог наборов, установка/удаление, поиск, избранное и недавние.
- Девять Unicode-категорий, поиск ru/en, тоны кожи, управление выбором с клавиатуры.
- Целостное редактирование флагов, семейных ZWJ-последовательностей, модификаторов и UTF-16 сущностей.
- Сохранение эмодзи при отправке, редактировании, пересылке, восстановлении черновика и в подписях альбомов.
- Совместимость с форматированием, цитатами и переносами; обычный Unicode fallback при недоступном изображении.
- Создание статичных наборов из PNG/WebP с нормализацией до PNG 100×100 и серверной проверкой.
- Настраиваемые лимиты реакций, базовые жалобы/блокировка и аудит модератора.
- Добавочный API, документация OpenAPI и ограниченный кэш в памяти с очисткой при выходе.

## Обновить сервер и Web

Распакуйте `volna-messenger-0.12.3.zip` поверх существующего проекта, сохранив `.env`, Docker volumes, `artifacts`, `backups`, Android signing key и кэши сборщиков. Архив содержит исходники целиком, APK/EXE в нём нет.

```sh
cd ~/volna-messenger
VOLNA_BUILD_NETWORK=host sh scripts/update.sh
```

Скрипт делает резервную копию и проверяет версию Web после обновления. Ожидаемая строка: `Verified web assets: Volna 0.12.3.` Затем обновите страницу браузера.

Миграции с 0.12.0–0.12.2 добавочные: аккаунты, SMS/QR-авторизация и переписки сохраняются. Не выполняйте `docker compose down -v` и не удаляйте базу. Для перехода с 0.11.x сначала прочитайте `UPDATE-0.12.0.md`.

## Android и Windows

Только `update.sh` не собирает клиенты. Чтобы собрать и опубликовать оба клиента и обновить сервисы:

```sh
cd ~/volna-messenger
VOLNA_BUILD_NETWORK=host sh scripts/build-clients.sh
```

Отдельные сборки также сохранены:

```sh
VOLNA_BUILD_NETWORK=host sh scripts/build-android.sh
VOLNA_BUILD_NETWORK=host sh scripts/build-windows.sh
```

Номер всех пакетов — 0.12.3, Android versionCode — 12003. Windows использует обновлённый React-интерфейс; новый редактор эмодзи этого выпуска относится к Web/Windows. Нативный Android сохранён с прежним функционалом, его новую панель Emoji Engine нужно реализовать отдельным этапом. В этой среде APK и EXE не собирались.

## Как пользоваться

В чате нажмите кнопку эмодзи. Вкладка «Эмодзи» — Unicode, «Волна» — кастомные наборы. Нажатие на изображение вставляет его в позицию курсора. На компьютере Enter отправляет, Shift+Enter переносит строку; на телефоне используйте кнопку отправки.

Во вкладке «Волна» откройте «Наборы», установите набор или скопируйте ссылку. Удаление из «Моих» сохраняет старые сообщения. «Создать свой набор» принимает PNG/WebP до 5 МБ: клиент преобразует их в статичный PNG 100×100. Один набор — до 200 элементов, один пакет загрузки — до 24 файлов. Укажите название, обычный эмодзи для fallback и ключевые слова. Публичный набор виден другим аккаунтам; приватный — только владельцу, но отправленный эмодзи доступен участникам сообщения.

## Настройки сервера

Необязательные поля `.env`:

```dotenv
EMOJI_PACK_MAX_ITEMS=200
EMOJI_REACTIONS_PER_USER=3
EMOJI_REACTION_TYPES=20
EMOJI_MODERATOR_USER_IDS=
```

Для последнего поля нужны числовые ID назначенных модераторов через запятую. Пустое значение не даёт эти права никому. Менять настройки следует до запуска скрипта обновления. Модерация доступна через защищённый API; полноценная административная панель не включена.

## Проверка выпуска

- 74 автоматизированных теста прошли, включая старые функции и новые emoji API, приватность, UTF-16, пересылку, альбомы, модерацию и реакции.
- Реальные React-компоненты прошли SSR-проверку; Web production build и Windows renderer собраны.
- Локальный HTTP smoke: 80 запросов, 8 одновременно, 0 ошибок, p95 22 мс. Временная SQLite в памяти; это не прогноз производительности VPS.
- Исправленный конфиг nginx из 0.12.2 и проверка `nginx -t` при Docker-сборке сохранены.

Перед эксплуатацией проверьте два аккаунта на реальных устройствах: отправку/редактирование кастомных эмодзи, семейные эмодзи и флаги, курсор и переносы, копирование, удаление набора и получение на втором устройстве. Реальные браузеры, Docker-запуск и APK/EXE здесь недоступны для проверки.

Для разработчика:

```sh
npm test
npm run test:render
npm --prefix client run build
node scripts/bench-emoji.mjs
```

Документация: `docs/emoji-engine.md`, `docs/emoji-openapi.json`. Исходник фирменных иллюстраций: `scripts/generate-emoji-pack.py` (Python + Pillow).
