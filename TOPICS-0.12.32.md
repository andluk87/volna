# Темы Волны: доработка по предоставленному описанию

Источники: [публичный разбор](https://chatgpt.com/share/6acbe3f8-a664-83eb-9031-05805a8929cd) и присланный PDF «Темы в Telegram». PDF содержит тот же материал. Описание Telegram используется как модель поведения Волны, а примеры вызовов Telegram Bot API — как пояснение внешнего API, не как команды подключить Telegram.

## Соответствие модели

| Пункт описания | Реализация в Волне |
|---|---|
| Группа → темы → сообщения | Темы привязаны к основной группе; создание второго уровня запрещено API. |
| Общие участники и администраторы | Вступление, удаление и смена роли распространяются на темы. Самостоятельное членство или роли отдельной темы не вводятся. |
| Системная общая тема | «Общие вопросы» представляет прежний поток основной группы; сохраняет старые сообщения и идентификаторы. Можно переименовать, скрыть из списка, закрыть, закрепить. Удалить нельзя. |
| Включение/выключение тем | Переключатель в настройках тем у администратора. Выключение сохраняет все истории; при открытии группы с существующими темами показывается общая лента. |
| Список и переключение | Название, значок, последнее сообщение, непрочитанное, признаки закрытия/закрепления. Вкладки под шапкой для Android/Web/Windows; список тем остаётся доступен через меню. |
| Единое представление | «Все сообщения»: хронологическая лента, поиск, загрузка ранней истории, названия тем и переход к конкретному сообщению. Просмотр ленты сам не меняет прочитанность тем. Для ответа открывается выбранная тема. |
| Отдельная история | Сообщения, ответы, файлы, медиа, реакции, закрепления, опросы и списки проходят существующий общий конвейер сообщений, сохраняя идентификатор темы. |
| Непрочитанное | Независимые счётчики темы и сумма группы; учтены удалённые сообщения и личная очистка истории. |
| Уведомления | «Как в группе», «Все сообщения», «Упоминания и ответы», «Без уведомлений». Отдельный явный выбор может переопределять режим группы; возврат к наследованию восстанавливает его. Проверка применяется к SSE и серверным push. |
| Управление | Создание по разрешениям группы, изменение названия/значка, закрытие/открытие, удаление с историей. Администратор может публиковать в закрытой теме, обычный участник — читать. |
| Закреплённые темы | Общие закрепления администратора и изменение порядка «Выше/Ниже»; сервер проверяет полный список и принадлежность группе. Личные закрепления чатов не заменяют эти закрепления. |
| Ссылки | HTTPS `/app?chat=<id>` открывает тему после авторизации. Android принимает ссылку только собственного настроенного сервера. Ссылки не дают членство и не обходят права. Web/Windows копируют внешний адрес сервера, а не `app://` Electron. |
| Ограничения доступа | Темы видимы участникам общей группы. Скрытие общей темы меняет список, не права чтения. Приватные разделы следует создавать отдельными группами. |
| Автоматизация | Существующие авторизованные REST API можно использовать для создания тем и публикаций; Telegram-токены и методы `api.telegram.org` к Волне не относятся. |

## API и совместимость

`GET /api/groups/:group/topics` сохраняет массив `topics` и дополнительно возвращает `general` и `enabled`. Системная тема использует ID основной группы, а не Telegram ID `1`: это сохраняет идентификаторы и ссылки существующих сообщений Волны. Физический `chat_id` сообщений остаётся прежним; дополнительно возвращаются `group_id`, `topic_id`, `message_thread_id`, `topic_name`.

- `POST /api/groups/:group/topics/settings`: `enabled`, `create_policy` (`owner`, `admins`, `all`).
- `PATCH /api/groups/:group/topics/:topic`: название/описание/значок, `closed`, `pinned`; для общей темы также `hidden`.
- `POST /api/groups/:group/topics/reorder`: `ids` — все закреплённые темы в желаемом порядке.
- `POST /api/groups/:group/topics/:topic/notifications`: `mode` (`inherit`, `all`, `mentions`, `none`). Общая тема не наследует сама себя.
- `GET /api/chats/:group/messages?forum=1`: общая лента; поддерживает `before` и `q`. Ответы и вложения гидратируются тем же конвейером, что отдельные чаты. Удалённые темы и лично очищенная история исключены.
- `POST /api/groups/:group/topics/:topic/messages`: прежний маршрут публикации в тему; поддерживает существующие файлы, ответы, форматирование, опросы и идемпотентность.

Миграции добавляют столбцы без переноса или удаления сообщений. Для прежних групп с темами режим включается при первой миграции; последующие перезапуски сохраняют выбранное состояние, в том числе выключенное.

## Проверка

Серверные сценарии проверяют сохранение старой истории, недопустимость удаления общей темы, роли в закрытой теме, закрепление/порядок, наследование уведомлений и ответы, поиск/пагинацию ленты, запрет доступа постороннему, личную очистку, удалённые темы и повторный запуск миграций. Отдельный сценарий проверяет файлы, опросы, реакции, ответы и закрепления внутри темы.

Браузерный сценарий через реальный API проверяет действия тем, копирование ссылок, форматированный поиск в общей ленте, цель перехода и выключение режима на размерах Web, Windows и мобильного браузера. Android: unit tests и сборка APK, включая ссылки и сохранение режима в кэше. Windows проверяется через общий интерфейс и режим Electron в Chromium; настоящий Windows 10 и системный выбор Android-приложения для HTTPS-ссылок требуют проверки на устройствах.
