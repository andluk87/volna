# VLN 0.12.71 — анимации и меню Android

Android теперь воспроизводит те же 580 одиночных анимированных эмодзи, которые добавлены в Web/Windows в 0.12.70. Файлы TGS берутся из уже закреплённого набора в Git, проверяются по SHA-256 и включаются в APK. Telegram/Hugging Face на телефоне не требуются. Сообщения по-прежнему содержат Unicode; история, сеансы и пользовательские наборы не меняются. Эмодзи внутри текста остаются статическими.

Анимация проигрывается один раз и повторяется по нажатию. Учтены системное отключение анимаций, энергосбережение, качество и уход приложения в фон. Ошибка декодирования оставляет статический эмодзи. Время и галочки располагаются снизу; настройка времени по нажатию продолжает работать.

Исправлена совместимость анимации 🥉 с Lottie Android 6.6.7: при сборке явно добавляются неизменные значения прозрачности на краях градиента. Цвета, геометрия и тайминг сохранены; отдельный тест сравнивает прозрачность до/после. Исходные TGS в Git и Web/Windows не изменяются. Manifest APK содержит исходный и упакованный SHA-256 и запись о преобразовании. Проверяются все 580 файлов нативным парсером и контрольные изображения, включая медаль.

Android-меню по образцу: фон из палитры темы, скругление 12 dp, компактные строки 48 dp, обычный шрифт 16 sp и иконки у всех пунктов. Основные действия: день/ночь, группа, избранное, настройки. «Ещё» открывает новый чат, канал, приглашение, архив и аккаунты. В нижней панели вместо настроек находятся «Звонки»; настройки доступны из верхнего меню и боковой панели. Остальные настройки оформления сохранены.

При сверке с соответствующими Lottie JSON выявлены неверные TGS в исходном датасете (например, файл сердца содержал череп). Такие файлы пересобираются из закреплённых JSON с сохранением исходных хешей для аудита. Web/Windows сохраняют проигрыватель 0.12.70 и получают исправленную графику; версия в URL TGS исключает старый кеш. Windows-установщик в этой Linux-среде не запускался.

Проверено: 135 Android-тестов без ошибок, сборка APK, SHA-256 всех 580 файлов в APK, нативная отрисовка сердца и медали, светлое/тёмное меню и его действия. В браузере проверены 580 анимаций на первом/среднем/последнем кадре и сценарии воспроизведения, настроек, копирования и ошибки загрузки. Production-сборка Web прошла.

Из прежней папки сервера с compose.yaml и .env:

```sh
( set -eu; test -f compose.yaml && test -f .env; volna_update_dir=$(mktemp -d); trap 'rm -rf "$volna_update_dir"' EXIT; git clone --depth 1 --branch v0.12.71 https://github.com/andluk87/volna.git "$volna_update_dir/source"; git -C "$volna_update_dir/source" archive --output="$volna_update_dir/source.tar" HEAD; sh "$volna_update_dir/source/scripts/backup.sh"; if [ -d android-native/app/src ]; then mkdir -p backups; volna_source_backup=$(mktemp -d "$PWD/backups/android-source-0.12.71-XXXXXXXX"); mv android-native/app/src "$volna_source_backup/src"; fi; tar -xf "$volna_update_dir/source.tar" -C .; sh scripts/build-clients.sh )
```

После сборки установите Android/Windows поверх прежней версии; Web перезагрузите.
