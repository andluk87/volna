# VLN 0.12.87 — надёжные звонки 1:1

Исправлены повторное создание вызова при потере ответа сервера, приём на нескольких устройствах и начало длительности до установления медиасвязи. Добавлены восстановление ICE в том же звонке (до 20 секунд), настройки доступа к звонкам, блокировки, режим только через TURN и код проверки ключей. [Технические подробности и проверка по ТЗ](docs/CALLS-1TO1.md).

Из прежней папки сервера с `compose.yaml` и `.env`, одной вставкой:

```sh
( set -eu; test -f compose.yaml && test -f .env; volna_update_dir=$(mktemp -d); trap 'rm -rf "$volna_update_dir"' EXIT; git clone --depth 1 --branch v0.12.87 https://github.com/andluk87/volna.git "$volna_update_dir/source"; git -C "$volna_update_dir/source" archive --output="$volna_update_dir/source.tar" HEAD; sh "$volna_update_dir/source/scripts/backup.sh"; if [ -d android-native/app/src ]; then mkdir -p backups; volna_source_backup=$(mktemp -d "$PWD/backups/android-source-0.12.87-XXXXXXXX"); mv android-native/app/src "$volna_source_backup/src"; fi; tar -xf "$volna_update_dir/source.tar" -C .; VOLNA_BUILD_NETWORK=host sh scripts/build-clients.sh )
```

Здесь включён `VOLNA_BUILD_NETWORK=host` для вашей ошибки DNS в Docker (`Temporary failure resolving deb.debian.org`). Хосту всё равно нужен рабочий DNS и доступ к Debian/GitHub; при сбое уже на хосте этот параметр не поможет. Скрипты не удаляют `.env`, данные или ключ подписи. Для Windows-сборки нужно не менее 4096 МиБ свободного места; при нехватке сборка остановится до запуска. Очистка данных и Docker volumes не требуется.

После завершения сборки обновите Android и Windows до 0.12.87. Новая схема подтверждения медиа и восстановления включается, когда оба участника используют новые клиенты. Старые версии совместимы, но сохраняют прежний режим звонков. Изменения SQLite применяются автоматически при запуске сервера.

Настройки: Android → Настройки → Звонки; Windows/Web → Настройки → Звук и камера. Блокировка звонков — в профиле собеседника. Для нормальной работы через разные сети необходим настроенный TURN. Если его ещё нет, используйте штатный `sh scripts/enable-calls.sh` после обновления исходников.

TLS TURN на TCP 443 поддержан отдельно: [конфигурация и инструкция](docs/CALLS-1TO1.md#turn-и-эксплуатация). Он требует выделенного хоста/IP и сертификата; текущий Caddy/HTTPS на основном 443 менять не нужно. Само обновление не разворачивает дополнительный TURN TLS.

Проверка после обновления: позвоните между двумя устройствами, примите на одном из двух принимающих клиентов, проверьте длительность и историю. Во время разговора переключите Wi-Fi на мобильную сеть; при восстановлении должен сохраниться тот же звонок. Проверьте запрет входящих, блокировку и совпадение кода проверки. Расширенная приёмка — в технической инструкции.

Проверены 225 Node-тестов, 202 Android unit/UI-теста, production-сборки Web и Windows renderer, интерфейс звонков Web/Windows и вызовы на фоновом аккаунте. APK 103.24 МиБ с четырьмя ABI, ниже лимита обновления 120 МиБ. Установщик Windows на реальной Windows и переходы Wi-Fi/LTE на физических устройствах в этой среде не проверены. Реальный ICE-тест в облачном Chromium пропущен из-за отсутствия ICE-кандидатов; сетевые SLO по ТЗ не заявляются.
