# VLN 0.12.89 — отправка файлов как в видео Telegram

Android, Web и Windows: после нажатия «Отправить» файл появляется в переписке как исходящая карточка с названием, круговым прогрессом, крестиком отмены и объёмом «передано / всего». После загрузки показывается «Отправляем…», после подтверждения сервера — обычное сообщение с файлом. Карточка готового файла получила круглый значок и согласованные размеры/шрифт.

В Web/Windows выбор файла теперь подготавливает локальное вложение, а передача начинается после «Отправить», вместе с подписью и ответом. В Android окно подтверждения закрывается после начала передачи. Несколько выбранных вложений показываются последовательно; отмена отменяет всю текущую отправку. При ошибке доступен повтор: уже загруженные вложения используются снова, сообщение отправляется с прежним ключом для защиты от дублирования.

Крестик прерывает HTTP-загрузку, а не только скрывает карточку. На короткой стадии подтверждения сообщения отмена недоступна: запрос уже мог создать сообщение. После ошибки этой стадии можно повторить отправку или убрать карточку. Уже созданные сообщения автоматически не удаляются. Прерванная незавершённая загрузка не создаёт файл или сообщение на сервере и не записывается как серверная ошибка.

Из прежней папки проекта с `compose.yaml` и `.env`, одной вставкой:

```sh
( set -eu; test -f compose.yaml && test -f .env; volna_update_dir=$(mktemp -d); trap 'rm -rf "$volna_update_dir"' EXIT; git clone --depth 1 --branch v0.12.89 https://github.com/andluk87/volna.git "$volna_update_dir/source"; git -C "$volna_update_dir/source" archive --output="$volna_update_dir/source.tar" HEAD; sh "$volna_update_dir/source/scripts/backup.sh"; if [ -d android-native/app/src ]; then mkdir -p backups; volna_source_backup=$(mktemp -d "$PWD/backups/android-source-0.12.89-XXXXXXXX"); mv android-native/app/src "$volna_source_backup/src"; fi; tar -xf "$volna_update_dir/source.tar" -C .; VOLNA_BUILD_NETWORK=host sh scripts/build-clients.sh )
```

После сборки обновите Android и Windows до 0.12.89, в Web перезагрузите страницу. Данные, настройки звонков только через TURN, ключ подписи и `.env` сохраняются. Для прежней ошибки Docker DNS включён `VOLNA_BUILD_NETWORK=host`; он требует рабочего DNS на самом хосте.

Проверка: выберите файл и добавьте подпись; нажмите отправку. На медленной сети проверьте изменение счётчика и кольца, отмените крестиком — сообщение не должно появиться у получателя. Повторите с отключением сети и кнопкой повтора. Проверьте, что успешная отправка оставляет одну обычную карточку, а не карточку прогресса. При пакете проверьте очередь и переход между файлами.

Размеры файлов и правила альбомов остаются прежними: до 20 МиБ на файл в клиентах, до 10 вложений в пакете; Web/Windows объединяют в альбом фото и видео. Вложения до нажатия отправки в Web/Windows остаются только в памяти и не переживают закрытие страницы; текст черновика сохраняется. Фоновая очередь после перезапуска приложения в этот выпуск не добавлялась.

Проверены 228 Node-тестов, 207 Android unit/UI-тестов, сборки Web/Windows renderer и APK (103.26 МиБ, ниже лимита 120 МиБ). Проверены реальная передача с ограничением скорости, отмена и повтор в полном приложении Web/Windows renderer; токены обновляются через прежний механизм сеансов. Android проверен сборкой, unit/UI-тестами и тестом отмены HTTP-сокета. Windows installer на физической Windows и работа на физическом Android в этой среде не проверяются.
