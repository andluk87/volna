# VLN 0.12.53 — пузыри, сообщения во время звонка и уведомления

Названия сохранены: приложения — **VLN**, сайт — **Volna**. Идентификаторы, адреса и существующая подпись Android при сборке на сервере сохраняются.

## Что изменилось

1. **Пузыри Android.** Убрано intrinsic-измерение и размещение времени/галочек внутри текста. Текст измеряется непосредственно, короткий пузырь сохраняет минимальную ширину, время и статус находятся в отдельной нижней строке. Настройка показа времени по нажатию скрывает только время, а не галочки.
2. **Сообщения во время звонка.** Подтверждение доставки Android теперь отправляет фоновая служба, даже если Activity чата закрыта экраном вызова, выключен экран, чат не выбран или уведомления заглушены. Подтверждения объединяются по чату, временные ошибки повторяются, более новое сообщение не теряется при запоздалом ответе. После восстановления SSE служба получает непрочитанные сообщения и подтверждает их доставку. Удалённый чат не блокирует очередь остальных. События доставки/прочтения сразу обновляют список чатов и галочки в открытом чате. Android/Web/Windows не отмечают сообщения прочитанными за полным экраном звонка; при возврате в видимый чат прочтение возобновляется.
3. **Свёрнутый звонок Web/Windows.** Блок начинается у верхнего края. Можно перетаскивать блок за основную область или маркер, в том числе касанием; для маркера работают клавиши со стрелками. Перетаскивание не разворачивает звонок. После уменьшения окна блок остаётся доступен, обычное нажатие разворачивает его.
4. **Уведомления Windows.** Отдельные карточки с именем и текстом сообщения, новые снизу, предыдущие поднимаются вверх. Максимум пять, шестое вытесняет старое; каждая карточка исчезает через 6 секунд, закрывается крестиком или открывает правильный аккаунт/чат по нажатию. Они располагаются в рабочей области монитора приложения и не забирают фокус. Текст по умолчанию включён; если пользователь явно отключал предпросмотр, это сохраняется. Настройка: Уведомления Windows → «Показывать имя и текст сообщения».
5. **Полоса звонка Android.** Зелёно-бирюзовый фон плавно пульсирует, звуковые столбики движутся. Имя, время, микрофон и завершение звонка остаются доступны. При отключённых анимациях или энергосбережении полоса остаётся яркой, но неподвижной.

## Проверки

- 169 Node-тестов: сообщения и SSE в обе стороны при активном серверном вызове, независимые доставка/прочтение, очередь карточек, ограничение пятью, таймеры, открытие аккаунта/чата, защита IPC и размещение на мониторе.
- 103 Android/JVM-теста, включая три Compose/Robolectric-теста реального компонента пузыря: ширина длинного текста, компактный короткий текст, видимые галочки при скрытом времени. Проверены рендеры длинного и короткого сообщения.
- Сборки Android Debug, Web и Windows прошли. APK: `dev.volna.messenger`, VLN, versionCode `12053`, versionName `0.12.53`; ресурсы эмодзи присутствуют.
- Chromium: Web и имитация Windows bridge, начальная верхняя позиция, перетаскивание/стрелки, границы после resize, разворачивание и завершение. Проверены текст, порядок пяти карточек, открытие, закрытие и безопасный вывод HTML-подобного текста.
- Проверены PE установщика Windows, SHA-512, размер, blockmap и наличие файлов нового окна уведомлений внутри ASAR.

Compose/Robolectric проверяет раскладку настоящего Android-компонента, но не заменяет проверку на телефоне. Серверный тест вызова проверяет сигнализацию и сообщения, не аппаратный звук. Запуск EXE в Windows и реальные звонки между устройствами в этой среде не выполнялись.

## Обновление сервера и установщиков

Это публикация исходников в теге `v0.12.53`. В рабочей среде нет производственного `.env` и доступа к установленному серверу. Проверочные APK/EXE используют `https://example.invalid` и не публикуются для установки.

Выполните в прежнем каталоге сервера с `compose.yaml` и `.env`. Блок создаёт резервную копию и собирает оба клиента с существующими адресами и Android-ключом, затем публикует их штатным процессом проекта.

```sh
(
  set -eu
  test -f compose.yaml && test -f .env
  volna_update_dir=$(mktemp -d)
  trap 'rm -rf "$volna_update_dir"' EXIT
  git clone --depth 1 --branch v0.12.53 \
    https://github.com/andluk87/volna.git "$volna_update_dir/source"
  git -C "$volna_update_dir/source" archive \
    --output="$volna_update_dir/source.tar" HEAD
  sh "$volna_update_dir/source/scripts/backup.sh"
  tar -xf "$volna_update_dir/source.tar" -C .
  VOLNA_BUILD_NETWORK=host sh scripts/build-clients.sh
)
```

Для первого запуска новых Compose/JVM-тестов потребуется сеть: Robolectric загружает Android runtime; последующие контейнерные сборки используют постоянный Gradle-кэш. Для ручного Gradle-прогона предварительно выполните штатный `python3 android-native/scripts/prepare-expressions.py --cache <каталог-кэша>`; Docker-сборщик делает это сам.

## Проверка после установки

- Android: длинный текст, короткий ответ, редактированное сообщение и реакции; затем включите «время по нажатию» и проверьте галочки.
- Начните голосовой разговор, откройте переписку и отправьте сообщения в обе стороны. Повторите с полным экраном звонка у получателя и с заблокированным телефоном: доставка должна подтверждаться без открытия чата; прочтение — при просмотре.
- Web/Windows: сверните вызов, перетащите верхний блок, уменьшите окно, разверните и завершите звонок.
- Windows: переведите фокус в другую программу и получите семь сообщений подряд. Проверьте текст, максимум пять карточек и исчезновение через 6 секунд.
- Android: сверните звонок и проверьте движение полосы и столбиков, затем повторите с отключёнными анимациями.
