# VLN 0.12.54 — сообщения, папки, звонки и настройки Windows

Приложения называются **VLN**, сайт — **Volna**. Существующие идентификаторы, профиль Windows и ключ подписи Android сохраняются.

## Изменения

- **Пузыри Android:** короткий текст, время и галочки помещаются в одну строку. Реакции идут компактными плашками с аватарами под текстом; при переносе для времени и галочек остаётся место справа. Длинный текст использует доступную ширину.
- **Несколько реакций:** можно независимо поставить до 20 разных реакций на одно сообщение и снять любую из них. Панель выбора остаётся открытой. Старое значение `EMOJI_REACTIONS_PER_USER=3` больше не ограничивает пользователя тремя реакциями: нижняя граница теперь 20, верхняя 100. По умолчанию на сообщении разрешены 100 типов реакций. Для этого изменения необходимо обновить сервер.
- **Папки Android:** единая округлая горизонтальная панель с синей плашкой выбранной папки, как в примере. Длинные списки прокручиваются, названия остаются доступными при увеличении шрифта.
- **Список чатов Windows:** при наличии папок — боковая полоса 72 px, папки, счётчики и кнопка редактирования. Без папок поиск и меню занимают всю ширину списка. Оформлены архив и избранное.
- **Свёрнутый звонок Windows/Web:** плавающий пузырь заменён анимированной полосой во всю ширину сверху. Имя, время, разворачивание и завершение доступны; для полосы зарезервировано место над перепиской. Декоративные волны/кольца вокруг аватара убраны. Статус звонка и аккаунт разделены отступом, в узком окне подпись аккаунта переносится. При отключённых анимациях или системном уменьшении движения полоса неподвижна.
- **Настройки Windows «Уведомления и звуки»:** все/активный аккаунт; карточки рабочего стола; мигание панели задач; звук, громкость и прослушивание; независимое отображение имени и текста; личные чаты, группы, каналы, реакции и исключения чатов; подсчёт сообщений/чатов и учёт заглушённых чатов; системные уведомления Windows или карточки VLN; учёт системного состояния запрета уведомлений; выбор угла и 1–5 карточек. Системные уведомления размещает сама Windows. Карточки VLN идут друг за другом и исчезают через 6 секунд. Счётчик Windows также выводится поверх значка на панели задач. Настройки сохраняются, изменения доступны в дополнительных окнах приложения.
- **Прокрутка настроек:** горизонтальная прокрутка убрана, раздел уведомлений расширяется до 480 px, длинные подписи переносятся. Вертикальные полосы используют цвета темы.
- **Выделение мышью Windows/Web:** протягивание через сообщения или свободное место рядом с ними выделяет диапазон; Ctrl/Cmd добавляет отдельное сообщение, Shift — диапазон. Кнопки и ссылки сохраняют свои действия, текст внутри одного пузыря можно выделять для копирования.
- **Фотоальбомы:** миниатюры образуют коллаж на всю ширину пузыря без зазоров и внутренних скруглений. Последнее нечётное фото занимает всю строку. Каждая фотография открывается отдельно; подписи и реакции сохраняются.

Исправления доставки и галочек во время звонка из 0.12.53 сохранены.

## Обновление сервера и установщиков

Это публикация исходников в теге `v0.12.54`. В рабочей среде нет производственного `.env` и доступа к установленному серверу. Проверочные APK/EXE используют `https://example.invalid` и не публикуются для установки.

Выполните в прежнем каталоге сервера с `compose.yaml` и `.env`. Блок создаёт резервную копию и собирает оба клиента с существующими адресами и Android-ключом, затем публикует их штатным процессом проекта.

```sh
(
  set -eu
  test -f compose.yaml && test -f .env
  volna_update_dir=$(mktemp -d)
  trap 'rm -rf "$volna_update_dir"' EXIT
  git clone --depth 1 --branch v0.12.54 \
    https://github.com/andluk87/volna.git "$volna_update_dir/source"
  git -C "$volna_update_dir/source" archive \
    --output="$volna_update_dir/source.tar" HEAD
  sh "$volna_update_dir/source/scripts/backup.sh"
  tar -xf "$volna_update_dir/source.tar" -C .
  VOLNA_BUILD_NETWORK=host sh scripts/build-clients.sh
)
```

Для первого запуска новых Compose/JVM-тестов потребуется сеть: Robolectric загружает Android runtime; последующие контейнерные сборки используют постоянный Gradle-кэш. Для ручного Gradle-прогона предварительно выполните штатный `python3 android-native/scripts/prepare-expressions.py --cache <каталог-кэша>`; Docker-сборщик делает это сам.

## Проверка после установки

- Android: длинный текст, короткий ответ, редактированное сообщение и реакции; затем включите «время по нажатию» и проверьте галочки.
- Начните голосовой разговор, откройте переписку и отправьте сообщения в обе стороны. Повторите с полным экраном звонка у получателя и с заблокированным телефоном: доставка должна подтверждаться без открытия чата; прочтение — при просмотре.
- Web/Windows: сверните вызов, проверьте анимированную полосу во всю ширину сверху, уменьшите окно, разверните и завершите звонок. Проверьте отдельную подпись аккаунта и отсутствие волн вокруг аватара.
- Windows: переведите фокус в другую программу и получите семь сообщений подряд. Проверьте текст, максимум пять карточек и исчезновение через 6 секунд.
- Android: сверните звонок и проверьте движение полосы и столбиков, затем повторите с отключёнными анимациями.

- Android: проверьте округлую панель папок и переключение между ними. Windows: проверьте список чатов с папками и без них.
- Windows: пройдите раздел «Уведомления и звуки», измените имя/текст, звук/громкость, категории, угол и число карточек, затем перезапустите приложение. Проверьте отсутствие горизонтальной прокрутки и цвет вертикальной полосы в обеих темах.
- Web/Windows: выделите несколько сообщений протягиванием мыши через пузырьки и свободное место; отдельно выделите текст одного сообщения.
- Все клиенты: отправьте 2, 3 и 5 фотографий, проверьте коллаж без зазоров и отдельное открытие каждой фотографии.
