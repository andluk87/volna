# VLN 0.12.51 — новый значок и проверка уведомлений Huawei

Во всех клиентах и на сайте установлен оригинальный PNG пользователя: глянцевая синяя V. Исходник сохранён без изменений в design/branding/vln-approved.png; прозрачность, пропорции и SHA-256 описаны в README рядом. Для Android и Web-уведомлений используется упрощённая белая V на прозрачном фоне: PNG 24/36/48/72/96 px. Windows ICO содержит семь размеров; PWA maskable-вариант защищает букву от обрезки. Временные ресурсы Telegram и диагностические лицензии удалены.

Приложения называются VLN — сокращение Volna. Сайт сохраняет название Volna. Android package и подпись, Windows AppUserModelID, PWA id, deep links, серверные адреса и существующая лента обновлений не меняются. Windows продолжает использовать каталог профиля Volna. Имя файла Volna-Setup-0.12.51.exe оставлено для совместимости публикации обновлений; исполняемый файл и ярлыки называются VLN.

Обычные сообщения Android и локальная проверка используют MessagingStyle, Person, стабильный account-scoped conversation shortcut и LocusId (API 29+). Ярлыки не содержат токенов, открывают соответствующий аккаунт/чат без перехода к старому message_id. При выходе из аккаунта ярлыки отключаются и удаляются. Ограничения Android на количество ярлыков или частоту их обновления не блокируют доставку уведомления. Тестовый ярлык отдельный от настоящих чатов. WearableExtender и ответ на сообщение сохранены. Реакции сохраняют прежний формат.

Это эксперимент по отличию, обнаруженному в дампах MAX и Telegram. Наличие ярлыка не доказывает причину отсутствующего значка Huawei. Результат требует проверки на Huawei Watch Ultimate / HarmonyOS 6.1.0 / Huawei Health 16.1.1.320.

## Проверка на телефоне и часах

1. Установите производственную сборку 0.12.51: значок приложения должен показывать синюю V, подпись — VLN.
2. Удалите старое тестовое уведомление. Настройки → Уведомления → «Проверить уведомление на часах», затем заблокируйте телефон.
3. Через 10 секунд проверьте новое уведомление «Проверка значка VLN и ярлыка диалога». Проверьте также обычное входящее сообщение и переход в чат из уведомления/ярлыка для обоих аккаунтов.
4. Если значка нет, пока тест остаётся в шторке, выполните `adb shell dumpsys notification > notification-vln-shortcut.txt`. В записи dev.volna.messenger должен появиться действующий shortcut; этот дамп проверяет применение изменения.

## Обновление сервера

Выполните в прежнем каталоге сервера с compose.yaml и .env; данные и подпись сохраняются. Облачные проверочные APK/EXE с example.invalid не устанавливайте.

```sh
(
  set -eu
  test -f compose.yaml && test -f .env
  volna_update_dir=$(mktemp -d)
  trap 'rm -rf "$volna_update_dir"' EXIT
  git clone --depth 1 --branch v0.12.51 \
    https://github.com/andluk87/volna.git "$volna_update_dir/source"
  git -C "$volna_update_dir/source" archive \
    --output="$volna_update_dir/source.tar" HEAD
  sh "$volna_update_dir/source/scripts/backup.sh"
  tar -xf "$volna_update_dir/source.tar" -C .
  VOLNA_BUILD_NETWORK=host sh scripts/build-clients.sh
)
```

Это публикация исходников. Производственные установщики и сервер обновляет указанная команда. Новый пост с иллюстрацией добавлен в официальный канал при запуске обновлённого сервера.

Этот дополнительный прогон не считается пройденным. Аппаратные проверки Huawei, реальный запуск Windows и производственная установка остаются проверками на устройствах.
