# VLN 0.12.75 — фото на Android, Windows и Web

На всех устройствах фото можно листать, рисовать на копии, пересылать, сохранять, показывать в чате, превращать в стикер, использовать для ответа, делиться и удалять с подтверждением. Действия относятся к текущему снимку после перелистывания.

Windows/Web получили альбомы с общими временем и галочками, для четырёх фото — крупный кадр и три миниатюры. Промежутки между фото прозрачные на всех платформах, включая альбомы с подписью Android.

Из прежней папки сервера с `compose.yaml` и существующим `.env`, одной вставкой:

```sh
( set -eu; test -f compose.yaml && test -f .env; volna_update_dir=$(mktemp -d); trap 'rm -rf "$volna_update_dir"' EXIT; git clone --depth 1 --branch v0.12.75 https://github.com/andluk87/volna.git "$volna_update_dir/source"; git -C "$volna_update_dir/source" archive --output="$volna_update_dir/source.tar" HEAD; sh "$volna_update_dir/source/scripts/backup.sh"; if [ -d android-native/app/src ]; then mkdir -p backups; volna_source_backup=$(mktemp -d "$PWD/backups/android-source-0.12.75-XXXXXXXX"); mv android-native/app/src "$volna_source_backup/src"; fi; tar -xf "$volna_update_dir/source.tar" -C .; sh scripts/build-clients.sh )
```

Команда создаёт резервную копию, сохраняет прежние исходники Android в `backups/`, загружает тег `v0.12.75` и запускает общий сборщик. `.env`, база, аккаунты, переписки и ключ подписи Android сохраняются.

После сборки откройте в VLN `Настройки → Обновления → Проверить обновления` и подтвердите установку поверх прежней версии. Обновите Windows поверх прежней версии и перезагрузите Web через `Ctrl+F5`.

Проверка: откройте альбом, перелистните на другой снимок и проверьте меню ⋮. Нажмите «Рисовать», проведите линию, отмените и верните штрих, примените рисунок. Сохраните или отправьте изменённую копию — оригинал в чате сохраняется. «Создать стикер» создаёт новый личный набор с указанным названием.

Android сохраняет фото в галерею (Pictures/VLN на Android 10+); Android 8/9 запрашивает разрешение. Windows предлагает диалог сохранения в «Изображения», Web использует доступный диалог или скачивание. «Поделиться» открывает системное меню там, где оно поддерживается; в Windows при отсутствии Web Share сохраняет файл и показывает его в папке для отправки через меню файла.

Проверено: 165 Android unit/UI-тестов, 196 общих Node-тестов, React render-тесты и браузерные сценарии Web/Windows; production-сборки Web/Windows и Android APK (~103 МиБ, все четыре ABI, ниже прежнего лимита 120 МиБ). Windows проверен в браузере с мостом Electron; физическая установка Android и запуск Windows EXE в этой среде не выполнялись.
