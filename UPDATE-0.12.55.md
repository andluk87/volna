# VLN 0.12.55 — выделение сообщений, эмодзи и компактные звонки

- **Выделение Windows/Web:** выбранные пузыри становятся синими, обводка убрана. Справа у всех сообщений появляются одинаково расположенные круглые отметки. Обычная шапка заменяется панелью «Переслать N», «Удалить N», «Отмена», под ней сохраняются закреплённые сообщения. Кнопка удаления учитывает существующие права: свои сообщения либо права администратора. Отмена возвращает обычный вид. Выделение текста, Ctrl/Cmd и Shift сохранены.
- **Волны Android:** удалены шесть значков `Icons.Outlined.Waves` из настоящего экрана аудиозвонка по бокам аватара. Предыдущая правка 0.12.54 касалась веб-оформления и не удаляла этот Android-элемент.
- **Эмодзи Windows:** наведение мыши на кнопку в строке ввода открывает маленькое окно с 24 эмодзи, включая недавние. Выбор вставляет символ в сохранённую позицию курсора и обновляет недавние. Нажатие на кнопку или «Все эмодзи» открывает полную панель справа. В узком окне она открывается поверх правой части, в широком — сохраняется отдельная колонка. Быстрое окно закрывается при уходе мыши, нажатии снаружи или Escape. В веб-клиенте сохранено открытие по нажатию.
- **Аудиозвонок Windows:** компактное окно по центру шириной до 420 px, аватар 132 px, уменьшенные отступы и кнопки. На небольшом экране высота ограничивается размером окна, доступна вертикальная прокрутка. Свёрнутый звонок остаётся анимированной верхней полосой; видеозвонок сохраняет своё окно с видео.

Приложения — **VLN**, сайт — **Volna**. Идентификаторы и профиль Windows сохранены.

## Обновление сервера и установщиков

Это публикация исходников в теге `v0.12.55`. В рабочей среде нет производственного `.env` и доступа к установленному серверу. Проверочные APK/EXE используют `https://example.invalid` и не публикуются для установки.

Выполните в прежнем каталоге сервера с `compose.yaml` и `.env`. Блок создаёт резервную копию и собирает оба клиента с существующими адресами и Android-ключом, затем публикует их штатным процессом проекта.

```sh
(
  set -eu
  test -f compose.yaml && test -f .env
  volna_update_dir=$(mktemp -d)
  trap 'rm -rf "$volna_update_dir"' EXIT
  git clone --depth 1 --branch v0.12.55 \
    https://github.com/andluk87/volna.git "$volna_update_dir/source"
  git -C "$volna_update_dir/source" archive \
    --output="$volna_update_dir/source.tar" HEAD
  sh "$volna_update_dir/source/scripts/backup.sh"
  tar -xf "$volna_update_dir/source.tar" -C .
  VOLNA_BUILD_NETWORK=host sh scripts/build-clients.sh
)
```

Для первого запуска новых Compose/JVM-тестов потребуется сеть: Robolectric загружает Android runtime; последующие контейнерные сборки используют постоянный Gradle-кэш. Для ручного Gradle-прогона предварительно выполните штатный `python3 android-native/scripts/prepare-expressions.py --cache <каталог-кэша>`; Docker-сборщик делает это сам.

## Проверка после установки

1. Выделите несколько входящих и исходящих сообщений мышью: проверьте синие пузыри, круги справа, счётчики, пересылку, доступное удаление и отмену. Отдельно выделите текст внутри одного сообщения.
2. Android: откройте полный экран аудиозвонка — вокруг аватара больше нет шести значков волн.
3. Windows: наведите на эмодзи и вставьте символ в середину текста; нажмите кнопку, проверьте большую правую панель, повторите после сужения окна.
4. Windows: начните аудиозвонок, проверьте компактное окно, сверните в верхнюю полосу, разверните и завершите. Проверьте выбор звукового устройства.
