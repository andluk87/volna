# Волна 0.12.104 — меню команд ботов и сохранение звонка после обновления токена

Подробный журнал 0.12.103 подтвердил сбой в Android: экран входящего звонка вызвал повторную настройку клиента с `trigger:call_activity`, `session_same:true` и `session_blank:false`. Сразу после этого клиент получателя завершил ещё звонящий вызов с `end_reason:session_reset`. Сервер получил `/end` через примерно 5,4 секунды после создания звонка, до принятия. Это завершение инициировал клиент, а не тайм-аут сервера или потеря уже установленного медиа.

Причина в сравнении исходных строк access-токенов: ранее сохранённый токен и обновлённый токен уже разрешались в одну действующую сессию, но `configure()` проверял строки буквально и заново инициализировал звонки с предварительным `end()`. Поэтому открытие экрана того же аккаунта после обновления токена могло сбросить первый входящий звонок; повторный вызов уже использовал обновлённое состояние.

Теперь `configure()` использует ту же проверку разрешённых сессий, что и `configuredFor()`. Для того же аккаунта сохраняются звонок, WebRTC, таймеры и опрос сервера. API продолжает получать действующий токен через существующий interceptor обновления учётных данных. Другой аккаунт не может заменить владельца текущего звонка; явный выход продолжает завершать звонок. Пустые результаты разрешения разных токенов не считаются одной сессией.

Журнал, его ротация по 1 МиБ, ссылки и бот «Волна — диагностика» остаются доступны. Выявленный сбой исправляется в Android, поэтому нужно установить новый APK на оба телефона. Меню команд доступно в новых Android, Web и Windows клиентах. Быстрое восстановление при отсутствии relay-кандидатов из 0.12.102 сохранено; этот выпуск исправляет именно подтверждённый сброс сессии, а не все возможные сетевые сбои.

## Меню ботов

В чате с ботом у поля ввода появилась синяя кнопка **«Меню»**. Нажатие открывает список команд с описаниями. Выбор пункта сразу отправляет отдельное сообщение с командой — нажимать Enter или кнопку отправки не нужно. Набранный текст, ответ на сообщение и вложения черновика при этом сохраняются.

Список берётся с сервера отдельно для каждого зарегистрированного бота; имя контакта и текст его сообщений не определяют меню. Для **«Волна — диагностика»** у администратора **+7 968 141-12-41** доступны:

- `/calllog` — ссылка на актуальный журнал на 24 часа;
- `/revoke` — отозвать доступ;
- `/help` — команды.

В обычной переписке кнопка не появляется. Меню учитывает доступ пользователя к боту и блокируется на время отправки. В Web/Windows поддержаны Escape, стрелки клавиатуры и закрытие нажатием снаружи. Права на выполнение команд проверяются самим ботом, даже если команду отправить вручную.

## Обновить все клиенты

Из `/root/volna-messenger`, где есть `.env` и `compose.yaml`:

```sh
( set -eu; test -f compose.yaml && test -f .env; volna_update_dir=$(mktemp -d); trap 'rm -rf "$volna_update_dir"' EXIT; git clone --depth 1 --branch v0.12.104 https://github.com/andluk87/volna.git "$volna_update_dir/source"; git -C "$volna_update_dir/source" archive --output="$volna_update_dir/source.tar" HEAD; sh "$volna_update_dir/source/scripts/backup.sh"; if [ -d android-native/app/src ]; then mkdir -p backups; volna_source_backup=$(mktemp -d "$PWD/backups/android-source-0.12.104-XXXXXXXX"); mv android-native/app/src "$volna_source_backup/src"; fi; tar -xf "$volna_update_dir/source.tar" -C .; VOLNA_BUILD_NETWORK=host sh scripts/build-clients.sh )
```

Стандартный скрипт собирает и публикует APK, Windows и Web, затем обновляет сервисы. Для Windows-builder требуется не менее 4 ГБ свободного места. `.env`, данные и старые артефакты сохраняются; создаётся резервная копия. Используется сеть хоста для ранее выявленной проблемы DNS внутри Docker.

После успешной сборки установите **Android 0.12.104 (12104)** на оба телефона через обновление приложения или `https://volna.lknet.ru/download/volna-android.apk`. Для меню обновите Windows до 0.12.104 и перезагрузите Web. Повторите первый и второй звонки. Ссылку на журнал можно получить прежней командой `/calllog` у бота «Волна — диагностика»; действующая ссылка также продолжает обновляться до своего истечения.

Если сейчас нужно только исправление Android-звонка, в приведённой команде можно заменить `sh scripts/build-clients.sh` на `sh scripts/build-android.sh`; меню в старом Windows-клиенте тогда не появится.

## Проверки

Прошли **267 Node-тестов и 237 Android-тестов**. Проверены меню разных ботов, немедленная отправка команды, сохранение черновика, запрет постороннему пользователю, скрытие меню обычного контакта, блокировка при отправке и управление клавиатурой. Собраны Android APK, Web и Windows renderer; версия APK проверяется отдельно.


Регрессия проверяется отдельно для старого и нового токена одного аккаунта, обоих направлений их замены, сохранения активного и неактивного клиента, запрета смены аккаунта во время звонка, явного выхода, пустых разрешённых учётных данных и первой настройки. Проверяются общий набор API-тестов, сборка Web, Android unit-тесты, сборка APK и его версия. Физические телефоны и сеть пользователя в среде сборки недоступны; результат в реальной сети нужно подтвердить новым звонком после установки APK.
