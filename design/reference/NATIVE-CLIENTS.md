# Сравнение нативных клиентов, версия 0.12.10

Источники использовались для проверки размеров, структуры интерфейса и поведения. Код, изображения и логотипы Telegram не переносились в Волну.

## Windows

Сравнение с [Telegram Desktop, 863cf10](https://github.com/telegramdesktop/tdesktop/tree/863cf10d9f34fb0b1b35b35da1bda75acfc58d2e): `dialogs/dialogs.style`, `window/window_main_menu.style`, `chat_helpers/chat_helpers.style`, темы `day-blue` и `night`.

| Элемент | Раньше в Волне | Теперь |
| --- | --- | --- |
| Список чатов | Веб-строка 72 px, аватар 54 px | 62 px, аватар 46 px |
| Панели | Плавающие скруглённые блоки веб-клиента | Прямые панели без внешних отступов |
| Меню | Всплывающее веб-меню | Боковая панель 274 px с затемнением |
| Настройки | Заменяли список чатов | Отдельное окно внутри приложения |
| Ввод | Плавающая форма | Панель на всю ширину переписки |
| Окно | Каждый запуск 1180 × 800 | Сохранение геометрии и развёрнутого состояния; перенос на доступный монитор |

Сочетания: Ctrl+K — общий поиск, Ctrl+F — поиск в открытом чате, Ctrl+, — настройки, Alt+↑/↓ — переключение чатов, Ctrl+W — закрыть окно в трей. В подсказке трея отображается число непрочитанных сообщений.

Это Electron-приложение Волны с отдельным desktop-оформлением. Функциональной и пиксельной идентичности Qt-приложению Telegram Desktop нет. Запуск и обновление на реальной Windows 10/11 нужно проверять отдельно; браузерная проверка desktop-режима не проверяет ОС.

## Android

Сравнение с [Telegram Android, f2908b1](https://github.com/DrKLO/Telegram/tree/f2908b14133bbffbf7ab04f641ecb5bfaf533242): `DialogCell.java`, `ActionBar.java`, `DialogsActivity.java`, `ChatActivityEnterView.java`.

Заменена плавающая нижняя навигация боковым меню: аккаунты, группа, контакты, звонки, избранное, настройки, канал, приглашение и архив. Поиск открывается кнопкой в шапке. Высота шапки 56 dp, строка чата 70 dp с аватаром 52 dp при стандартном масштабе. В чате эмодзи слева от ввода, вложение справа, поле без цветной рамки. Стеклянные панели по умолчанию отключены для новых настроек; сохранённый выбор пользователя остаётся доступным.

Клиент остаётся Kotlin/Compose-приложением Волны, с её сервером и возможностями. Проверка компиляции не заменяет проверку жестов, клавиатуры, уведомлений и звонков на устройстве.

## Распознавание голосовых

Раньше HTTP 422 от Whisper (речь не найдена), 400 (пустой/повреждённый файл), 413 (слишком большой файл) и 415 (формат) превращались в общую ошибку 502 «Локальное распознавание временно недоступно».

Теперь клиент получает конкретную причину. При HTTP 500/502/504 или кратковременном разрыве соединения сервер повторяет запрос один раз, в пределах общего лимита 180 секунд. Загрузка модели, ошибка её загрузки и занятость сервиса сохраняют отдельные сообщения. Ошибки декодера PyAV возвращают 400; временный файл удаляется во всех случаях. MIME с `codecs=opus` распознаётся корректно.

Это исправление обработки ошибок. Причина каждого сбоя на установленном VPS определяется по журналу `docker compose logs --tail 100 transcription server` и состоянию `/ready`, а не по общей надписи клиента.

## Проверки версии 0.12.10

- Node: 88 тестов сервера и общих модулей, включая геометрию окна и повторы распознавания — успешно.
- Whisper HTTP: 5 тестов реального FastAPI/uvicorn с тестовой моделью — успешно. Это проверка HTTP и обработки ошибок, без проверки качества настоящей модели Whisper на голосе пользователя.
- React: сборка Vite и проверка рендера компонентов — успешно.
- Playwright/Chromium: 24 запуска регрессионных сценариев веб-клиента (закрепы, эмодзи, меню, вложения; desktop и мобильный размер), 4 проверки Windows-режима (светлая и тёмная темы) — успешно.
- Android: `testDebugUnitTest` (17 тестов) и `assembleDebug` — успешно; проверены версия 12010/0.12.10, разрешения и ресурсы эмодзи в APK.
- Windows: NSIS EXE 0.12.10, размер, SHA-512 и blockmap — успешно.

Проверочные APK/EXE собирались с адресом `https://example.invalid` и не предназначены для подключения к установленной Волне. Инструкция обновления пересобирает клиенты с адресом из вашего `.env`. Проверки реального устройства Android, Windows 10/11, подключения к вашему VPS и качества распознавания настоящей записью здесь не выполнялись.
