# Сравнение настроек оформления с Telegram Web K

Эталон: https://web.telegram.org/k/ и публичный исходный код
[TelegramOrg/Telegram-web-k](https://github.com/TelegramOrg/Telegram-web-k/tree/125a31da7665d5ee09ceb9c5de66e2615e3276b6),
ревизия `125a31da7665d5ee09ceb9c5de66e2615e3276b6`.
Сравнивались `generalSettings.tsx`, `background.tsx`, `rangeSettingSelector.tsx`,
`_section.scss`, `_row.scss`, `_themes.scss`, `themeController.ts` и SVG-иконки.

Прямой запрос к web.telegram.org в этой среде получает HTTP 403 от сетевого прокси.
Авторизованная сессия Telegram и эталонные снимки настроек не предоставлены.
Поэтому результат — перенос структуры и поведения по исходному коду, а не
подтверждённая абсолютная или попиксельная копия опубликованной версии.
Изображение `web-k-login-background-light.jpg` в исходном архиве показывает
только фон входа и не является эталоном настроек.

| Область | Волна 0.12.5 из архива | Внесённое изменение |
| --- | --- | --- |
| Структура | Большой предпросмотр, списки параметров | Разделы внутри левой панели, строки 54 px, единая прокрутка |
| Размер текста | Ползунок среди дополнительных параметров | Первый раздел, значение справа, диапазон 12–20 |
| Темы | Сетка 3×2 и три кнопки режима | Горизонтальная лента, пять радиорежимов: классическая, ночная, дневная, тёмная, системная |
| Системная тема | Переключение светлого/тёмного | Также ночной фиолетовый акцент при стандартном системном оформлении |
| Фон | Выпадающий список и поле файла | Отдельные страницы обоев и цвета, загрузка, сброс, сетка локальных узоров |
| Размытие | Отсутствует | Переключатель для загруженных изображений; не размывает сообщения |

| Формат времени | Фиксированные 24 часа | Выбор 12/24 часов, примеры и реальное применение к сообщениям, списку чатов и поиску |
| Прежние настройки Волны | Шрифт, плотность, скругление, аватары и время при наведении | Сохранены в сворачиваемом дополнительном разделе |
| Иконки | Общие иконки фото и настроек | Иконки оформления, энергосбережения, загрузки, палитры и сброса из той же GPL-ревизии |

## Границы совпадения

- Лента использует локальные темы Волны. Облачный каталог тем, обоев, анимированные
  эмодзи на миниатюрах и синхронизация темы с аккаунтом Telegram не перенесены.
- Фон использует SVG-узор Web K и локальные цвета. Четырёхцветные анимированные
  градиенты, точные палитры всех облачных тем и их интенсивность не воспроизведены.
- Дополнительные настройки Волны сохранены, поэтому полный состав экранов отличается.
- Энергосбережение управляет анимациями интерфейса Волны; это не полный набор
  переключателей медиадекодирования и эффектов Telegram.
- Нативные Android-экраны, сервер, SMS/QR-авторизация и Windows-установщик не менялись.
  Electron использует общий веб-фронтенд, поэтому оформление в нём тоже обновится
  при следующей сборке Windows.

## Проверка и дальнейшая визуальная приёмка

```sh
npm ci --cache /tmp/volna-npm-cache
ELECTRON_SKIP_BINARY_DOWNLOAD=1 npm ci --prefix client --cache /tmp/volna-npm-cache
npm test
npm run test:render
npm run build --prefix client
PLAYWRIGHT_EXECUTABLE_PATH=/usr/bin/chromium npm run test:visual --prefix client -- appearance-web-k.spec.mjs
```

Браузерные тесты проверяют пять размеров экрана в светлом и тёмном режимах:
1920×1080, 1440×900, 1366×768, 1024×768, 390×844. Они проверяют поведение,
сохранение настроек, загрузку/сброс обоев, размытие, время, навигацию и отсутствие
ошибок JavaScript. Эти проверки не измеряют разницу пикселей с Telegram.

Для точной визуальной приёмки нужны скриншоты авторизованного Web K при
одинаковых размере окна, масштабе браузера, языке и состоянии: настройки
оформления, фоны, выбор цвета, энергосбережение и переписка в обеих темах.
Проверки `web-client.spec.mjs`, содержащие `toHaveScreenshot`, требуют отдельно
подготовленных эталонов: снимки Волны нельзя выдавать за эталоны Telegram.

## Результаты текущей проверки

- `npm test`: 81 пройден, 0 проваленных.
- `npm run test:render`: пройден. Проверка теперь восстанавливает существующий
  `client/src/qa-render.jsx`, который старый runner перезаписывал и удалял.
- `npm run build --prefix client`: пройден; сохранены прежние предупреждения
  Vite о скрипте `boot.js` и размере основного пакета.
- `appearance-web-k.spec.mjs`: 40 пройденных браузерных сценариев, 0 проваленных,
  5 размеров окна × 2 темы × 4 сценария.
- Проверка собранного `client/dist` через Vite preview: демо показывает 23
  неархивных чата; переключение темы работает; ошибок JavaScript нет.
- Дополнительная регрессия `web-client.spec.mjs` на desktop/light и mobile/dark:
  сценарий папок и опроса проходит в обоих случаях. Сценарий редактирования
  сообщения после реакции останавливается на недоступной кнопке
  «Редактировать»; сценарий удаления вставленного 👍🏽 оставляет эмодзи в начале
  текста. Итого 2 пройденных и 4 проваленных запуска.
- Оба последних сбоя воспроизведены на неизменённых исходниках из исходного
  ZIP в отдельном `/tmp/volna-original` на desktop/light. Они существовали до
  изменения оформления; эти сценарии не отключались и их проверки не ослаблялись.

Снимки результата: `design/checks/appearance/` (16 PNG: desktop/mobile,
light/dark, настройки/обои/цвет/энергосбережение). Это снимки **Волны**,
а не эталонные изображения Telegram.
