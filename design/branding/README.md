# Approved VLN artwork

vln-approved.png is the original PNG supplied by the user in the ZIP “Глянцевый синий значок с буквой V.zip”. It is retained unchanged. Android, Windows, Web and the website share generated variants. The site remains Volna, clients use the abbreviation VLN.

Regenerate: `node scripts/package-icons.mjs design/branding/vln-approved.png`.

The rectangular source canvas is fitted proportionally into a square; the artwork is not redrawn or forced into a circular shape. PWA maskable artwork is padded to protect the V. The Android/Web status icon is a simplified white V alpha mask in ic_volna.xml, emitted as density-specific PNGs. Temporary Telegram diagnostic icons are removed.
