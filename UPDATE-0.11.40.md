# Волна 0.11.40 — панель эмодзи и оформление Android

Полный проект: нативный Android на Kotlin/Compose, Windows/Electron, Web/API, сервер распознавания и Docker-сборщики обоих клиентов. Android versionCode — **11040**, versionName — **0.11.40**. Предыдущие звонки, экран входящего вызова, демонстрация экрана, группы, профили, вложения и встроенные обновления сохранены.

## Что добавлено

- Панель «Эмодзи / Стикеры / GIF» под полем ввода, переключение с клавиатурой, расширение панели, категории, русский поиск, недавние и варианты оттенков кожи.
- Встроенный Noto Color Emoji 2.051 / Unicode 17. Стандартные эмодзи отображаются единым набором на разных телефонах и доступны без сети. Семьи, флаги, оттенки кожи и другие составные последовательности удаляются целиком.
- Пользовательские эмодзи в тексте, включая отображение в поле ввода, сообщения, редактирование и пересылку. Web/Windows отображают присланные Android пользовательские эмодзи.
- Собственный каталог Волны: 12 стартовых стикеров и 8 GIF, установка наборов, поиск, недавние, избранные, предпросмотр удержанием и создание наборов из своих файлов. Поиск GIF работает по каталогу Волны, без платного сервиса.
- Кэш стикеров/GIF до 100 МБ на аккаунт, загрузка видимых элементов, остановка анимаций в фоне, повтор загрузки и очистка кэша из настроек. Черновики сохраняют текст, курсор, выделение и пользовательские эмодзи.
- Оформление: светлая/тёмная/системная тема и ночь по расписанию, дневной/ночной варианты, акцент, градиенты до четырёх цветов, скругление, фон из фото с обрезкой, blur, затемнением и яркостью, узоры и их интенсивность.
- Отдельные темы переписок, сохранение своих тем, копирование/удаление, импорт с предпросмотром, экспорт и обмен файлами тем. Живой пример показывает сообщения, голосовое, реакцию и панель ввода.
- Стеклянная нижняя навигация и поверхности с настоящим backdrop blur на поддерживаемых Android, быстрые анимации, режимы качества и энергосбережения. Системное отключение анимаций учитывается.
- Проверка версии **скомпилированного** APK перед экспортом. APK другой версии или без нужных разрешений/ресурсов не публикуется.

Подробная карта требований и оставшиеся различия: [ANDROID-EXPRESSIONS-THEMES-0.11.40.md](ANDROID-EXPRESSIONS-THEMES-0.11.40.md).

## Обновить Android, сервер и Web

Поместите архив рядом с существующим каталогом проекта и распакуйте поверх него:

```sh
cd ~
unzip -o volna-messenger-0.11.40.zip -d .
cd volna-messenger
ANDROID_BUILD_OFFLINE=0 VOLNA_BUILD_NETWORK=host sh scripts/build-android.sh
```

`host` предназначен для Linux VPS и использует сеть хоста при сборке, что помогает при прежней ошибке DNS Docker. Если обычная сеть Docker работает, можно убрать `VOLNA_BUILD_NETWORK=host`.

Для первого запуска 0.11.40 указан онлайн-режим: сборщик один раз получает Haze, Noto, Unicode и русский CLDR. Они сохраняются в существующем `artifacts`. После успешного заполнения кэша можно вернуться к стандартному `auto`:

```sh
VOLNA_BUILD_NETWORK=host sh scripts/build-android.sh
```

Скрипт собирает APK, выполняет Android JVM-тесты, проверяет готовый файл, публикует APK/описание обновления и обновляет сервер/Web с резервной копией. Сервер добавляет новые таблицы каталога и пользовательских эмодзи к существующей базе. При ошибке компиляции, тестов или проверки APK публикация и обновление сервисов не продолжаются.

**Сохраняйте действующий `.env`, тома Docker и весь `artifacts`, особенно `artifacts/android-home` с прежним ключом подписи.** Архив содержит исходники и не заменяет секреты, базу, вложения, модели, кэши и прежние установщики. Очистка Docker-кэша для этого выпуска не требуется. Ограничений CPU сборщику не добавлено.

## Если нужны Android и Windows

```sh
ANDROID_BUILD_OFFLINE=0 VOLNA_BUILD_NETWORK=host sh scripts/build-clients.sh
```

Клиенты собираются последовательно, затем сервисы обновляются один раз. Windows отдельно:

```sh
VOLNA_BUILD_NETWORK=host sh scripts/build-windows.sh
```

Если Android уже собран успешно, повторная сборка Android ради Windows не нужна. Общий скрипт прекращает работу при ошибке любого клиента; ранее опубликованные установщики сохраняются.

## Проверить выпуск и установить

Для Android ожидаются строки:

```text
Verified Android network permissions in compiled APK.
Verified compiled Android version: Volna 0.11.40 (11040).
Verified web assets: Volna 0.11.40.
Verified Android download and update manifest.
```

Проверка опубликованного APK:

```sh
curl -fsS https://volna.lknet.ru/download/volna-android-version.json
```

Ожидаются `version_name: 0.11.40` и `version_code: 11040`. Файлы доступны после успешной сборки и публикации на VPS:

- Android: [volna-android.apk](https://volna.lknet.ru/download/volna-android.apk).
- Windows: [volna-windows.exe](https://volna.lknet.ru/download/volna-windows.exe).
- Windows feed: [latest.yml](https://volna.lknet.ru/download/windows/latest.yml).

В установленном Android подтвердите предложенное обновление либо установите APK поверх старой версии. Android требует подтверждения системного установщика; приложение само скачивает и проверяет обновление. Переустановка с удалением приложения не нужна. Обновление только сервера не изменит интерфейс уже установленного APK.

## Где найти новые функции

В чате нажмите значок эмодзи рядом с полем ввода. Нижняя строка переключает эмодзи, стикеры и GIF. Кнопка «+» открывает наборы и создание собственного набора. Удержание стикера/GIF показывает предпросмотр; короткое удержание открывает действия с избранным и набором. Удержание эмодзи с вариантами открывает выбор оттенка кожи.

«Профиль → Настройки чатов» открывает оформление приложения. Для темы одной переписки: «⋯ → Изменить оформление» в чате. Изменения видны сразу; кнопка «Использовать общую тему» убирает локальную тему переписки. «Мои темы» сохраняют варианты на устройстве отдельно для аккаунта; файлом темы можно поделиться и импортировать его на другом устройстве.

В «Данные и память» можно очистить загруженные медиа. Установленные наборы, избранное, черновики, сохранённые темы и собственные фоны остаются.

## Проверки и границы

Проходят 90 Node-тестов и 3 Python-проверки подготовки ресурсов эмодзи. Проверены доступ к приватным наборам и файлам, повторы отправки/создания, UTF-16 позиции пользовательских эмодзи, пересылка и сохранность вложений. Сценарии сборочных скриптов используют подставленные Docker/Gradle/AAPT2, в том числе ошибку компиляции и отказ при APK другой версии.

Добавлены 7 Android JVM-тестов редактирования Unicode/эмодзи, границ удаления, расписания и контраста. Их запускает Docker-сборщик перед публикацией. Здесь нет Docker, Android SDK и Gradle/Kotlin-компилятора: новый APK/EXE не собран, Android JVM-тесты и интерфейс на телефоне здесь не запускались. Проверка синтаксической структуры Kotlin не заменяет компиляцию. Результаты сборки Web/desktop и другие проверки указаны в [VALIDATION.md](VALIDATION.md).

После установки проверьте на телефоне переключение клавиатуры/панели с ответом и выделением, удаление семейного эмодзи, пользовательский эмодзи в черновике/сообщении, GIF в фоне, темы дня/ночи, фото, импорт, поворот экрана, крупный системный шрифт и прежние звонки.
