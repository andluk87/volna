# VLN 0.12.66 — эмодзи Telegram во всех клиентах

Стандартная графика заменена в **Android, Windows и Web**. Использованы атласы из указанного репозитория Telegram Desktop, закреплённые по коммиту `a7f453612f4896ac04d0007a36ab0d377e5bcbcf`. Общий растровый шрифт содержит их изображения и используется в сообщениях, поле ввода, реакциях, списках и выборе эмодзи. Windows-уведомления внутри приложения также подключают этот комплект.

## Что сохраняется

- Отправляется и копируется обычный Unicode, а не URL картинки или новый идентификатор. Старую историю не нужно переносить или переписывать.
- Семейные ZWJ-последовательности, флаги, оттенки кожи, цифры-клавиши, форматирование и поиск работают с прежним текстом.
- Русские названия и ключевые слова взяты из Unicode 17 / CLDR 48. Общий каталог доступен в обычной панели и реакциях; список загружается порциями при прокрутке.
- Пользовательские эмодзи, установленные наборы, стикеры и GIF не удаляются.
- Учётные записи, сеансы, оформление интерфейса и папки не сбрасываются.

В исходных атласах 3900 изображений. Поддерживаются 3941 стандартная Unicode-последовательность: совместимые старые записи используют соответствующие изображения Telegram, не меняя исходный текст. Таблица совместимости находится в `client/public/site/emoji/manifest.json`. Отдельные служебные компоненты, для которых у Telegram нет самостоятельной картинки, не предлагаются в каталоге как полноценные эмодзи. Оформление внешних системных уведомлений Android/браузера определяет ОС.

## Источники и сборка

Графика встроена в `client/public/site/emoji/TelegramEmoji.ttf`; Android копирует тот же файл в APK. Старый `NotoColorEmoji.ttf` из ресурсов Android удаляется при подготовке. Пикселей старого набора в новом шрифте нет; из Noto сохранены таблицы Unicode-сопоставления и формирования лигатур. Семейство шрифта переименовано.

Приложения не обращаются к Telegram за графикой при использовании. В Windows и Android она поставляется с клиентом; Web получает её с вашего сервера и использует браузерный кеш. Файл шрифта около 32 МБ. В сборке включены исходные лицензии Telegram, лицензия таблиц формирования и сведения об источниках.

Обычная сборка использует готовый файл из Git и проверяет SHA-256. Для воспроизведения разработчиком: `python3 scripts/prepare-telegram-emoji.py --cache artifacts/telegram-emoji-source`. Нужны Pillow, fontTools и libharfbuzz; эти зависимости не требуются при обычной сборке клиентов. Скрипт загружает закреплённые атласы и таблицы, создаёт шрифт и CSS. Контрольные пиксели проверяются относительно исходных ячеек Telegram.

## Обновление всех клиентов одной командой

Выполните из прежней папки сервера с `compose.yaml`, `.env` и `artifacts`:

```sh
( set -eu; test -f compose.yaml && test -f .env; volna_update_dir=$(mktemp -d); trap 'rm -rf "$volna_update_dir"' EXIT; git clone --depth 1 --branch v0.12.66 https://github.com/andluk87/volna.git "$volna_update_dir/source"; git -C "$volna_update_dir/source" archive --output="$volna_update_dir/source.tar" HEAD; sh "$volna_update_dir/source/scripts/backup.sh"; if [ -d android-native/app/src ]; then mkdir -p backups; volna_source_backup=$(mktemp -d "$PWD/backups/android-source-0.12.66-XXXXXXXX"); mv android-native/app/src "$volna_source_backup/src"; fi; tar -xf "$volna_update_dir/source.tar" -C .; sh scripts/build-clients.sh )
```

Команда делает резервную копию, обновляет исходники, собирает APK и Windows-установщик, публикует оба обновления и обновляет сервер/Web один раз. Прежние исходники Android сохраняются в `backups`; данные, `.env` и ключи подписи остаются в прежних каталогах.

После сборки обновите Android и Windows поверх установленных приложений и перезапустите их. Web обновится после перезагрузки страницы.

## Проверка

Проверены 127 Android-тестов и сборка APK, наличие нового шрифта и отсутствие старого в архиве. В Web и Windows проверяются сообщения, ввод, поиск, реакции и точное сохранение Unicode при копировании/отправке. Отдельные тесты сравнивают реальные пиксели шрифта с контрольными ячейками Telegram и проверяют формирование всех поддерживаемых последовательностей. Выполняется production-сборка Web. Системные кнопки и Windows-установщик на настоящей Windows в этой Linux-среде не запускались.
