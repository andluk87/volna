# VLN 0.12.52 — уведомление, пузырьки, фото и аватары Android

Приложения называются **VLN**, сайт — **Volna**. В шапке и подвале сайта теперь явно показано Volna, кнопка скачивания — «Скачать VLN». Android package, Windows AppUserModelID, PWA id, адреса API и лента обновлений сохранены.

## Исправления

- В служебном уведомлении «Связь с сообщениями активна» убран большой второй логотип. Обязательный маленький системный значок остаётся. Уведомления сообщений, их ярлыки, MessagingStyle, Person и ответы сохранены.
- Ширина пузырька определяется содержимым и фактической областью чата. Внутренние строки с растяжением измеряются после определения ширины; фото, видео и альбомы получают минимальную ширину в пределах доступного места. Учтены аватары, режим выделения и масштаб интерфейса.
- Изображения Coil загружаются через тот же OkHttp-клиент с обновлением сеанса, что и API. При истечении часового access token запрос фотографии/аватара обновляет сеанс и повторяется. Кэш разделён по аккаунтам и не меняет ключ при ротации токена. Относительные пути к значкам сайта разрешаются в URL; Authorization добавляется только для файлов на собственном API origin.
- Выбранный аватар сначала уменьшается до 1024 px и преобразуется в JPEG вместо отправки исходника с ограничением 5 МБ. Прозрачные области получают белый фон; файл проверяется декодером. Фото в чате используют прежние 1600 px / JPEG 80%.
- На Android 8–8.1 BitmapFactory sample начинается с единицы: подготовка фото больше не делит на ноль. EXIF-поворот и отражение учитываются и на этих версиях Android.

## Обновление установленного сервера

Исходники опубликованы в теге `v0.12.52`. Выполните следующий блок в существующем каталоге сервера с `compose.yaml` и `.env`. Он делает резервную копию, переносит исходники и собирает оба клиента с вашими адресами и существующим Android-ключом, затем публикует установщики через штатный процесс проекта.

```sh
(
  set -eu
  test -f compose.yaml && test -f .env
  volna_update_dir=$(mktemp -d)
  trap 'rm -rf "$volna_update_dir"' EXIT
  git clone --depth 1 --branch v0.12.52 \
    https://github.com/andluk87/volna.git "$volna_update_dir/source"
  git -C "$volna_update_dir/source" archive \
    --output="$volna_update_dir/source.tar" HEAD
  sh "$volna_update_dir/source/scripts/backup.sh"
  tar -xf "$volna_update_dir/source.tar" -C .
  VOLNA_BUILD_NETWORK=host sh scripts/build-clients.sh
)
```

Рабочая среда проверки не содержит производственного `.env` и доступа к установленному серверу. Здесь проверочные APK/EXE собраны с `https://example.invalid`; они не являются производственными установщиками и не публикуются для установки. Обновление установленного сервера выполняется приведённой командой.

## Проверка на телефоне после установки

1. Проверьте служебное уведомление: справа нет большого дублирующего значка.
2. Проверьте короткий/длинный текст, ответ, реакции, голосовое, фото и альбом; также режим выделения и изменённый масштаб.
3. После часа работы откройте ещё не загруженную фотографию и аватар в обоих аккаунтах: обновление сеанса должно проходить без повторного входа.
4. Загрузите большой снимок камеры как аватар и как фото в чат; проверьте ориентацию. На Android 8–8.1 дополнительно проверьте отправку снимка из галереи.

Проверка интерфейса и EXIF на реальном Android, Huawei Watch и запуск Windows на устройстве в этой среде не выполнялись.
