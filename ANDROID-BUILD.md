# Android 0.11.41: новый интерфейс, звонки и сборка

Из корня действующего проекта выполните:

```sh
sh scripts/build-android.sh
```

При проблемах DNS внутри Docker на Linux VPS используйте `VOLNA_BUILD_NETWORK=host sh scripts/build-android.sh`. Для полного выпуска Android + Windows + сервер/Web: `VOLNA_BUILD_NETWORK=host sh scripts/build-clients.sh`. Общая инструкция: [UPDATE-0.11.41.md](UPDATE-0.11.41.md).

Скрипт собирает нативный Kotlin APK, выполняет JVM-тесты, публикует его и описание обновления, затем обновляет сервер и Web. Если компиляция или тесты завершились ошибкой, новый APK не публикуется. Сохраняйте действующий `.env`, данные Docker и **весь каталог `artifacts`** при распаковке следующих исходников. Архив обновления не содержит `.env`, APK и кеша. APK появится по адресу `https://volna.lknet.ru/download/volna-android.apk`; установленная версия с поддержкой обновлений предложит его установить. Подтверждение системного установщика обязательно.

После компиляции AAPT2 из уже установленного SDK читает разрешения готового APK. Перед экспортом обязательны `INTERNET`, `ACCESS_NETWORK_STATE` и `USE_FULL_SCREEN_INTENT`; ошибка чтения или отсутствие разрешения прекращает публикацию. Успешная проверка выводит `Verified Android network permissions in compiled APK.`

Дополнительно проверяются applicationId и версия готового APK через `aapt2 dump badging`. Для этого выпуска ожидается `Verified compiled Android version: Volna 0.11.41 (11041).` Файл другой версии не экспортируется. Перед публикацией проверяется присутствие встроенного шрифта эмодзи и каталога.

## Эмодзи и оформление 0.11.41

Панель «Эмодзи / Стикеры / GIF» заменяет системную клавиатуру под полем ввода. Курсор, выделение, текст и ответ сохраняются. Поиск эмодзи работает на русском без сети; семейные последовательности, флаги и оттенки кожи удаляются целиком. Стандартная графика Noto Color Emoji 2.051 встроена в APK; телефон не скачивает её отдельно. Пользовательские эмодзи отображаются в поле ввода, сообщениях и Web/Windows. В панели есть собственный каталог Волны, стартовые наборы, установка, избранное, недавние, создание наборов и предпросмотр удержанием. Поиск GIF использует сервер Волны.

«Профиль → Настройки чатов» открывает оформление с предпросмотром. Для отдельной переписки: меню чата «⋯ → Изменить оформление». Доступны дневной/ночной варианты, расписание, градиенты, фото, узоры, сохранение и обмен темами. Для слабого телефона выберите качество «Экономия» или отключите размытие. Полное описание: [ANDROID-EXPRESSIONS-THEMES-0.11.40.md](ANDROID-EXPRESSIONS-THEMES-0.11.40.md).

## Новый интерфейс (с версии 0.11.38)

Чаты, контакты, история звонков и профиль доступны с нижней панели. Поиск включает текст сообщений; папки и черновики сохраняются на устройстве. Полноэкранные профили и общие медиа, компактные реакции, выбор сообщений, карточки настроек и темы реализованы в Kotlin/Compose. В звонке можно включить камеру и сменить её, отдельно переключиться на показ экрана. Web/Windows принимают видео Android.

Короткое нажатие микрофона начинает запись, следующее отправляет. Удержание начинает запись сразу; отпускание отправляет, свайп влево отменяет, вверх фиксирует. Запись, время и настоящая волна заменяют поле ввода; неотправленное голосовое остаётся для повтора после ошибки или перезапуска. AAC: 48 kHz, 128 kbit/s, mono. Очистка кеша медиа сохраняет голосовые черновики.

Подробный список и сценарии телефона: [UPDATE-0.11.41.md](UPDATE-0.11.41.md). Границы реализации: [ANDROID-REDESIGN-0.11.38.md](ANDROID-REDESIGN-0.11.38.md).

## Входящий звонок при выключенном экране

Установите APK 0.11.41 поверх предыдущего. При входящем звонке используется отдельный экран поверх блокировки с кнопками ответа/отклонения и пробуждением дисплея. Для открытия переписки потребуется разблокировка. После ответа дисплей можно погасить: прежний foreground service обслуживает разговор.

Android 14+ может требовать отдельное разрешение полноэкранного показа. В списке чатов нажмите **«Включить экран входящего звонка»**, разрешите уведомления и полноэкранный показ. Канал «Входящие звонки» должен иметь высокую важность. На разблокированном телефоне система может показать всплывающее уведомление. При принудительной остановке приложения сервис связи не получает вызовы.

Enter вставляет новую строку; отправка — отдельной кнопкой. Плеер голосового получил адаптивную волну, время под ней и круговые кнопки скорости/«А». Гудок исходящего звонка звучит до ответа и прекращается при соединении/отмене.

Для обоих клиентов: `sh scripts/build-clients.sh`. Собирайте APK на своём VPS с прежним `artifacts/android-home`, чтобы сохранился ключ подписи и возможность установки поверх старой версии.

## Локальный кеш

| Каталог | Содержимое |
| --- | --- |
| `artifacts/android-sdk` | SDK, platform-tools и build-tools |
| `artifacts/android-downloads` | ZIP command-line tools, Noto Color Emoji, Unicode и русский CLDR |
| `artifacts/gradle-cache` | Плагины, библиотеки Maven, Gradle cache |
| `artifacts/android-build-cache` | Конфигурация и кеш проекта |
| `artifacts/android-app-build` | Инкрементальные результаты компиляции и APK |
| `artifacts/android-home` | Настройки Android и ключ debug-подписи |

Это постоянный локальный кеш, не публичный Maven-сервер. Первая сборка требует интернет. Новые библиотеки WebRTC, Coil и Coroutines тоже нужно скачать один раз. SDK Manager не запускается, когда нужные пакеты и лицензии уже присутствуют.

В 0.11.41 один раз добавляются Haze 1.5.4, шрифт и данные эмодзи. Для первой сборки выпуска можно явно указать `ANDROID_BUILD_OFFLINE=0 VOLNA_BUILD_NETWORK=host sh scripts/build-android.sh`. Графика хранится в `artifacts/android-downloads/noto-2.051-unicode-17-cldr-48` и затем повторно используется. Лицензии шрифта и Unicode включаются в APK вместе с ресурсами. Строгий режим `1` прекращает сборку до публикации при неполном кэше.

Режим задаётся в `.env`:

```dotenv
ANDROID_BUILD_OFFLINE=auto
```

- `auto` — сначала офлайн; при отсутствии зависимости или Gradle-плагина повторяет сборку онлайн ровно один раз. Ошибка исходного кода не вызывает повторную загрузку.
- `0` — обычная сборка с доступом к репозиториям и использованием кеша.
- `1` — строго офлайн; при неполном кеше завершается с ошибкой.

Docker может проверить наличие базового образа: кеш Gradle не отменяет первоначальную загрузку образов и SDK. Используется уже установленный Build Tools 36.0.0. Ограничений CPU сборщику не задано. Не удаляйте `artifacts/android-home`: смена ключа подписи помешает установке новой версии поверх старой.

Если в 0.11.30 появилось `Plugin [id: 'com.android.application' ...] was not found`, запуск для заполнения кеша:

```sh
ANDROID_BUILD_OFFLINE=0 sh scripts/build-android.sh
```

Это отключает офлайн-попытку только для данного запуска. SDK и загруженные библиотеки сохраняются. Если ошибка появляется и в явно указанном онлайн-режиме, требуется проверить доступ VPS к Google Maven и Maven Central; по одному такому сообщению нельзя установить сетевую причину. Обновление 0.11.31 исправляет автоматический переход, не заменяет сетевое соединение и не меняет версию AGP 8.10.1.

## Звонки и экран

Звонки личные: Android ↔ Android и Android ↔ Web. Обновите Волну у обоих участников. Для разных сетей необходим TURN. Если Web пишет «TURN не настроен», выполните `sh scripts/build-android.sh --enable-calls`: настройки сохраняются перед единственной сборкой APK и обновлением всех контейнеров. Для настройки без APK доступен `sh scripts/enable-calls.sh`. Существующий секрет сохраняется; ключи повторно создавать не нужно. TCP/UDP 3478 и UDP 49160–49200 необходимо открыть в firewall провайдера VPS. `sh scripts/check-calls.sh` проверяет реальные параметры API-контейнера и TCP-доступ к TURN, но не UDP-ретрансляцию. `TURN_MAX_BPS=512000` регулирует лимит байт/с на сессию; это значение по умолчанию.

Разрешите микрофон и уведомления. При ответе из уведомления приложение открывается для разрешения и запуска микрофона. Активный звонок использует отдельный foreground service и частичную блокировку сна; сворачивание окна не уничтожает WebRTC. На Android 12+ выбор аудиовыхода показывает доступные устройства, включая Bluetooth; раньше доступно переключение телефона/гарнитуры и динамика.

Каждый новый показ требует системного согласия MediaProjection. Остановка показа завершает захват и возвращает сервис к голосовому режиму. Android может прекратить показ при блокировке; голосовой сервис работает отдельно. Принудительное завершение приложения, отзыв разрешения, остановка сервиса или потеря сети могут прервать звонок. Входящие доступны, пока работает сервис связи; обход принудительной остановки приложения не реализован.

Документация ОС: [типы foreground service](https://developer.android.com/develop/background-work/services/fgs/service-types), [MediaProjection](https://developer.android.com/media/grow/media-projection).

## Разрешение сетевого монитора

В 0.11.34 добавлено `ACCESS_NETWORK_STATE`. [Сетевой монитор WebRTC](https://webrtc.googlesource.com/src/+/refs/heads/main/sdk/android/api/org/webrtc/NetworkMonitorAutoDetect.java) требует его для вызовов ConnectivityManager. Вызванное из JNI необработанное Java-исключение может завершить процесс через [fatal check WebRTC](https://webrtc.googlesource.com/src/+/refs/heads/main/sdk/android/src/jni/jvm.cc). Поэтому наличие разрешения проверяется ещё до запуска WebRTC. Настройка сетевого монитора и отслеживание смены сети сохранены.

Отсутствующее разрешение согласуется с присланным `network_thread / SIGABRT` при ICE. Это установленная ошибка исходников, но присланный стек не содержит Java-исключения и не доказывает причину конкретного SIGABRT. Для проверки требуется новый APK на Samsung; обновления сервера недостаточно.

## Диагностика вылета при звонке

Установите собранный APK 0.11.41 и повторите звонок. Нажмите «Диагностика звонка» в баннере ошибки и «Копировать». Если процесс закрылся полностью, снова откройте приложение и дождитесь дополнения отчёта. Он содержит версию Волны/WebRTC, режим видео, Android, ABI, модель, точную операцию SDP/ICE/очистки и Java-исключение, когда оно доступно.

На Android 11+ причина завершения читается через [ApplicationExitInfo](https://developer.android.com/reference/android/app/ApplicationExitInfo). Для нативного сбоя Android 12+ предоставляет tombstone в формате protobuf; Волна читает сигнал, abort и стек только потока сбоя по [официальной схеме](https://android.googlesource.com/platform/system/core/+/refs/heads/main/debuggerd/proto/tombstone.proto). PID и время исключают подстановку отчёта другого звонка/процесса. Чтение выполняется в фоне, ограничено 2 МиБ и 32 кадрами. Память, логи и чужие потоки в текст не включаются. ОС может уже удалить этот отчёт; в таком случае подключите телефон к Android Studio/ADB и сохраните журнал сразу после вылета:

```sh
adb logcat -b crash -d
```

Для проверки совместимости видеоканал использует программный VP8 без перечисления аппаратных MediaCodec. Демонстрация сохраняется; во время показа CPU может нагружаться сильнее. Создание/установка SDP ограничены 15 секундами, сбор ICE — 10 секундами. Это не гарантирует устранение присланного вылета без нового отчёта и проверки на Samsung. WebRTC выполняет AEC/NS программно. При невозможности создать EGL контекст аудиозвонок может продолжить работу, а показ экрана сообщит ошибку.

Шесть JVM-тестов `NativeCrashTraceTest` выполняются в Docker перед публикацией: сигнал/стек/BuildId, неупорядоченные поля, исключение памяти/логов/чужих потоков, предел 32 кадров, повреждённые protobuf, предел 2 МиБ и неизвестные поля. Они проверяют чтение отчёта, не медиасвязь. Здесь нет Android SDK/Docker, поэтому их запуск и сборка APK в этой среде не выполнены.

## Голосовые и фото

Скрепка → «Фото и видео»: до 10 файлов, предпросмотр и поле необязательной подписи. Имя исходного файла не становится подписью. Альбом показывается сеткой; касание открывает вложение, долгий тап — действия выбранного фото. При повторе после ошибки используется прежний ID, чтобы не создавать дубли. Удаление/ответ/редактирование относятся к выбранному фото, не ко всему альбому.

Голосовые: компактный плеер с реальной волной, длительностью, перемоткой и сохраняемой скоростью 1× / 1.5× / 2×. «А» запускает серверную расшифровку; повторное нажатие скрывает/показывает уже распознанный текст. Файлы до 5 МБ подгружаются автоматически, большие — при воспроизведении. Полная PCM-волна вычисляется для поддерживаемых файлов до 8 МБ; при неподдерживаемом декодировании остаётся полоса прогресса. Кеш аудио изолирован по сеансу и ограничен 64 МБ. Запуск плеера не ждёт декодирования остальных сообщений.

## Проверка после установки

1. Позвоните Android ↔ Web и Android ↔ Android. Проверьте звук, микрофон, динамик/Bluetooth, входящий вызов при свёрнутом окне и отклонение.
2. Сверните звонок, отправьте текст, заблокируйте телефон на несколько минут. Вернитесь и завершите вызов из уведомления. Проверьте смену сети; TURN проверяйте с участниками в разных сетях.
3. Покажите экран с Android и Web, смените ориентацию телефона, остановите и снова запустите показ. Голос должен продолжаться при остановке видео.
4. Создайте группу/канал, добавьте участника, смените роль, исключите и верните пользователя, отзовите приглашение, передайте владение и выйдите. Обычный подписчик не должен отправлять сообщения в канал.
5. Измените тему, текст, плотность, акцент и фото; перезапустите приложение. Проверьте фото в Web. Откройте и увеличьте фото в галерее, воспроизведите видео, сохраните и поделитесь файлом. Загрузите старые страницы сообщений.

Здесь APK не компилировался: отсутствуют Docker, Gradle и SDK. Автотесты API и кеширования не заменяют компиляцию Kotlin и проверку телефона. Полная Web-паритетность пока не заявляется: редактор форматирования и автоматический переход к следующему голосовому ещё отличаются. Проверьте новый плеер, альбомы и вызов на телефоне после сборки.
