# Волна Native Desktop 0.1.2 — восстановление загрузки чатов

[Установщик Windows x64 и portable ZIP](https://github.com/andluk87/volna/releases/tag/native-v0.1.2). Закройте Native Desktop и установите обновление поверх 0.1.1; защищённый сеанс сохраняется. Сервер, Electron и Android обновлять для этого исправления не требуется.

Постоянное соединение событий SSE вынесено в отдельный сетевой менеджер с отдельным пулом соединений. Для зависшего потока введён контроль ожидания первых данных и сердцебиения. После временного сетевого сбоя или HTTP 502/503/504 безопасный GET повторяется один раз через HTTP/1.1. После получения HTTP-ответа при повторе обычные запросы продолжают использовать HTTP/1.1 в текущем процессе. TLS и проверка сертификатов остаются обязательными. POST-запросы автоматически не повторяются этим механизмом.

После ошибки списка чатов клиент автоматически повторяет загрузку с паузой от 2 до 30 секунд, соблюдая серверную паузу при ограничении запросов. Видны загрузка и кнопка повтора; при восстановлении убирается именно ошибка загрузки чатов.

«Настройки → Копировать диагностику подключения» теперь включает последние 40 завершённых API-операций: путь без строки поиска, метод, время, длительность, код HTTP, протокол и тип сетевой ошибки. Токены, заголовки, тела запросов/ответов и текст сообщений не сохраняются. Журнал существует только в памяти процесса. Этот отчёт позволяет различить зависшую операцию и проблему протокола; наличие SChannel само по себе не доказывает успешное соединение.

Проверки включают настоящий 20-секундный тайм-аут ответа с успешным повтором и искусственную недоступность API: ограничение повтора GET, восстановление пустого списка после двух отказов без действий пользователя, очистку баннера и отсутствие поискового текста/токена в диагностике. Сохраняются проверки входа, переписки, галереи, сеанса и сборки Windows с HTTPS/QR из упакованного приложения. Точная причина тайм-аута на конкретном компьютере требует нового отчёта, если ошибка повторится.

Это предварительный самостоятельный Qt-клиент Волны; ограничения и лицензии — [desktop-native/README.md](desktop-native/README.md). Установщик пока без цифровой подписи.
