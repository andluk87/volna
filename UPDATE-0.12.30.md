# Обновление Волны до 0.12.30

Обновляются сайт, API, Android и Windows: оформление, настройки, фото, звонки, уведомления, обновления и канал новостей. [Изменения и проверки](CHANGES-0.12.30.md).

Запустите блок в прежнем каталоге Волны с `compose.yaml` и `.env`. Перед заменой исходников создаётся резервная копия данных. `.env`, данные и подпись Android сохраняются; не удаляйте `artifacts/android-home`. `VITE_API_URL` должен указывать на ваш настоящий HTTPS API. Облачные тестовые сборки с `example.invalid` устанавливать не нужно.

```sh
(
  set -eu
  test -f compose.yaml && test -f .env
  volna_update_dir=$(mktemp -d)
  trap 'rm -rf "$volna_update_dir"' EXIT
  git clone --depth 1 --branch v0.12.30 \
    https://github.com/andluk87/volna.git "$volna_update_dir/source"
  git -C "$volna_update_dir/source" archive \
    --output="$volna_update_dir/source.tar" HEAD
  sh "$volna_update_dir/source/scripts/backup.sh"
  tar -xf "$volna_update_dir/source.tar" -C .
  VOLNA_BUILD_NETWORK=host sh scripts/build-clients.sh
)
```

После сборки установщик Windows доступен на `/download`; установленный Windows-клиент получает версию 0.12.30 через штатную проверку обновлений. Web обновляется на сервере вместе с сервисами. Если открыта старая вкладка, перезагрузите её. Настройки, аккаунты и переписки сохраняются. Android пересобирается с прежней подписью, поэтому устанавливается поверх существующего приложения. Канал новостей создаётся после запуска обновлённого API.

Проверьте: главную страницу на телефоне и компьютере, выделение сообщений мышью и пересылку, переходы разделов настроек, Escape вложенных окон, подготовку фото и альбомов, голосовую связь между клиентами, уведомления обоих аккаунтов, обновление после перезапуска и сохранение настроек. На Android установка требует подтверждения системным установщиком.

Облачный проверочный установщик с `example.invalid` не предназначен для установки: используйте сборку из этого блока с вашим настоящим API.
