# Волна 0.11.36 — исправление сборки Windows

В журнале `no space left on device`: на VPS закончилось место при распаковке большого образа `electronuserland/builder:wine`. В новом выпуске он заменён на компактный Node slim; установщик собирается без Wine. Добавлена проверка диска до сборки. Функции Android/Web/Windows 0.11.35 сохранены.

## 1. Освободите место на VPS

Из домашней папки выполните:

```sh
if docker image inspect volna-windows-builder:latest >/dev/null 2>&1; then
  docker image rm volna-windows-builder:latest
fi
docker builder prune -af
df -h
```

Это удаляет старый Windows-сборщик и неиспользуемый кеш сборки Docker. **Не удаляйте `.env`, `artifacts` и тома Docker**: там ключ Android, база и файлы чатов. Кеши npm/Gradle/Electron в `artifacts` сохраняются. Другие базовые Docker-слои могут скачаться повторно. Если места всё ещё мало, увеличьте диск; проверка требует 4096 MiB (4 GiB) свободного места, а не памяти RAM.

## 2. Обновите исходники

Загрузите `volna-messenger-0.11.36.zip` в домашнюю папку VPS. Архив содержит папку `volna-messenger`; распаковывайте над существующим проектом, не внутрь него:

```sh
cd ~
unzip -o volna-messenger-0.11.36.zip -d .
cd volna-messenger
sh scripts/build-windows.sh
```

Последняя команда повторяет только Windows-сборку, публикует EXE/feed и обновляет сервер/Web. Android, успешно собранный предыдущим запуском, остаётся доступным. Если нужно собрать и Android 0.11.36, и Windows, используйте вместо последней команды:

```sh
sh scripts/build-clients.sh
```

Сборщик проверяет место, установщик и контрольные суммы. При ошибке обновление сервисов не продолжается. Настройки Telegram, прокси и TURN в прежнем `.env` сохраняйте; работавшие звонки не требуют повторного включения TURN.

## 3. Скачивание и обновления

После успешного обновления ссылки появятся на странице входа:

- Windows: https://volna.lknet.ru/download/volna-windows.exe
- Android: https://volna.lknet.ru/download/volna-android.apk

Windows установите один раз. Затем обновления проверяются при запуске, каждые шесть часов и из меню трея. По кнопке «Обновить» клиент скачивает, проверяет и устанавливает обновление; во время звонка перезапуск ждёт окончания разговора и вашего нажатия. Закрытие окна оставляет приложение в трее. Установщик пока без сертификата Authenticode.

Для обновления установленного Android скачайте новый APK после `build-clients.sh` и установите поверх старого, сохраняя тот же ключ подписи. Если обновляли только Windows, пересборка Android не нужна.

В архиве: `WINDOWS-BUILD.md`, `ANDROID-BUILD.md`, `UPGRADE.md`, `VALIDATION.md` с подробностями и границами проверки.
