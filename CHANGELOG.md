# 0.12.88 — все звонки только через TURN

Убрано сообщение «Звонок принят на другом устройстве»: остальные клиенты закрывают вызов без баннера ошибки.

- Сервер всегда выдаёт relay policy, Android и Web/Windows создают PeerConnection только с RELAY. Сохранённые P2P-предпочтения и ответы старого API не включают прямое соединение.
- Переключатель TURN заменён пояснением обязательного режима; доступ к звонкам и блокировки остаются настраиваемыми.
- Отсутствие настройки TURN останавливает звонок до захвата микрофона. При недоступном TURN нет возврата к P2P.
- Регрессии: старые сохранённые настройки, попытка выключить TURN, API с policy=all, отсутствие TURN и отображение обязательного режима в Android.

# 0.12.87 — надёжные звонки 1:1

- Идемпотентное создание и повторы команд при потере сетевого ответа; приём закрепляется за одним устройством, остальные получают «принят на другом устройстве».
- Длительность в истории новых клиентов начинается после подтверждения медиасоединения обоими участниками. Согласование SDP само по себе не считается разговором.
- Восстановление ICE в текущем PeerConnection с поколениями offer/answer и ограничением 20 секунд; исходный ID и время начала сохраняются. SSE ускоряет обновление, опрос страхует доставку.
- Настройки «Все / Мои контакты / Никто», блокировки звонков из профиля, TURN-only для скрытия IP. Отказ в доступе не раскрывает приватную причину.
- Поддержка отдельного TURN TLS endpoint на TCP 443, пример конфигурации для выделенного хоста и инструкция эксплуатации.
- Код проверки DTLS fingerprints с одинаковым алгоритмом Android/Web. Это проверка ключей текущего WebRTC-звонка, не копия криптопротокола Telegram.
- Версии состояния, безопасный журнал переходов без SDP/ICE и тесты повторов, таймаутов, потери ответа и устаревших поколений. Без разрешения камеры Android может начать аудиозвонок.
- Групповые SFU-звонки, групповое E2EE и перенос между устройствами оставлены следующим этапам. Реальные сетевые SLO требуют приёмки на устройствах.

- Звонки: сине-фиолетовый фон, крупный аватар, управление аудиоустройством, видео, микрофоном и завершением; показ экрана сохранён сверху. Маленькое собственное видео можно перемещать внутри экрана звонка.
- Видеовызовы: камера включается после соединения при исходящем и принятом входящем видеозвонке с разрешённой камерой. Отказ от камеры при ответе оставляет аудиозвонок.

- Разговор через телефонный динамик: системный датчик приближения выключает/включает экран у уха. Для громкой связи, гарнитуры, видео и показа экрана отключение не применяется; блокировка освобождается при завершении.
- Новая версия вызывает окно «Обновить / Позже»; приложение скачивает проверенный APK и открывает установку Android. Установка не начинается во время звонка или отправки вложения. [Обновление](UPDATE-0.12.19.md).
