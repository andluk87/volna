# История версий Волны

## 0.12.47

- Убрана большая дублирующая картинка Волны из уведомлений сообщений и теста часов Android. Системный smallIcon и значок приложения сохранены.
- Это эксперимент совместимости Huawei, а не подтверждённое исправление значка часов.

## 0.12.46

- Убраны дубли «Все чаты» во всех клиентах. Вкладка содержит только чаты, не входящие в другие папки.
- Полоса появляется только после добавления существующего чата в папку; пустые папки её не включают. Данные сохранённых папок не удаляются.

## 0.12.45

- Реакции: плашки с перекрывающимися аватарками, без цифры 1; время справа в той же строке. API передаёт публичные изображения и порядок добавления.
- Android: меню реакций сохраняет фокус клавиатуры; отправка больше не запускает подсветку поиска. Время текстового сообщения встраивается в нижнюю строку.
- Новые аккаунты начинают без папок. После первой папки вкладка «Все чаты» добавляется только в интерфейсе. Существующие папки сохраняются.
- Звуковая волна записи стала чувствительнее к реальной амплитуде; локальная запись используется для отображения без повторного скачивания. Android использует источник MIC при прежнем AAC 128 кбит/с, 48 кГц.

## 0.12.44

- Android: прежний некруглый launcher-значок; Web/Windows остаются круглыми.
- Монохромный PNG smallIcon для mdpi/hdpi/xhdpi/xxhdpi/xxxhdpi. Показ Huawei требует проверки устройства.
- Открытие чата у последнего сообщения без видимого пролистывания; Web/Windows не восстанавливают прежнюю позицию.

## 0.12.43

- Исправлена регрессия имён уведомлений: совпадение имени с ником больше не превращает отправителя в «Пользователь».
- Добавлены резервные имена из контакта и кэша чата, сохранено удаление отдельной приписки @username.
- Значок Huawei остаётся нерешённым; [обновление и результаты исследования](UPDATE-0.12.43.md).

## 0.12.42

- Android: папки на всю ширину, равные вкладки и горизонтальная прокрутка при переполнении. Круглые счётчики папок, чатов и нижней панели.
- Имена контактов/профилей вместо username в заголовках Android-уведомлений; дополнительное публичное поле API для надёжного различения нового отправителя.
- Отключаемая текстовая пометка «🌊 Волна» для узнавания сообщений на часах. Графический значок Huawei остаётся нерешённым; [проверка и обновление](UPDATE-0.12.42.md).

## 0.12.41

- PNG-значок пакета Android и ресурсный PNG-значок уведомлений для совместимости с приложениями-компаньонами часов. Адаптивный launcher-значок сохранён.
- Проверка уведомления на часах из настроек: один локальный тест через 10 секунд, отмена и проверка разрешений/канала.
- Исправление отображения на Huawei Watch Ultimate требует проверки устройства; не обещаем, что прошивка использует Android-иконки. [Проверка и обновление](UPDATE-0.12.41.md).

## 0.12.39

- Цветной значок Волны в уведомлениях сообщений Android и действие «Ответить» для совместимых часов/панели уведомлений. Ответ отправляется от исходного аккаунта; ошибки сети не скрывают уведомление.
- Очистка старых публичных установщиков Windows перед упаковкой Web.
- Отображение значка и поддержка ответа на Huawei зависят от прошивки и Huawei Health. [Обновление](UPDATE-0.12.39.md).

## 0.12.38

- Исправление публикации: старые публичные установщики Windows очищаются перед сборкой Web; остаются текущая и предыдущая версии. Инструкция восстановления при нехватке места: [UPDATE-DISK-RECOVERY.md](UPDATE-DISK-RECOVERY.md).

- Android и Windows: опция автоустановки после 10 минут простоя, с защитой звонков и отправки вложений.
- Android обновляется через PackageInstaller с сохранением текущего доступа к полноэкранным вызовам, возвратом в приложение после установки и кнопкой открытия, если ОС блокирует запуск. Не активирует ранее запрещённое разрешение.
- Согласие на микрофон/камеру Windows сохраняется в профиле устройства между перезапусками и обновлениями.
- Автоматическая загрузка и нижнее уведомление «Обновить сейчас / Не сейчас» вместо центрального окна. Отказ не устанавливает обновление; ручная проверка доступна.
- Huawei Watch Ultimate: CallerDisplayName и реальный номер сохранённого контакта для Bluetooth-сопоставления. Username никогда не подставляется. Контакт без номера может остаться неизвестным на этой прошивке.
- [Обновление и ограничения платформ](UPDATE-0.12.38.md).

## 0.12.37

- Убран баннер «Звонок завершён или собеседник не ответил» после обычного завершения в Web/Windows. Ошибки соединения сохраняются.
- Android передаёт имя контакта в Telecom и CallStyle; username, SIP-адрес и номер исключены из отображаемых данных вызова. Приоритет: личное имя, телефонная книга, имя профиля.
- [Обновление](UPDATE-0.12.37.md).

## 0.12.36

- Android передаёт имя и адрес звонящего через Telecom и CallStyle Person для системных интерфейсов и совместимых часов. Телефон используется только если раскрыт сервером; иначе передаётся VoIP-идентификатор.
- Громкая связь переключается через системный Telecom; Android 14+ использует CallEndpoint, старые версии — CallAudioState. Интерфейс подтверждает текущий маршрут, показывает ошибки и ожидание.
- Значки телефона, динамика, Bluetooth и наушников, выделение выбранного аудиовыхода и плавная смена значка/цвета.
- [Обновление](UPDATE-0.12.36.md).

## 0.12.35

- Web/Windows показывают входящий вызов для любого сохранённого аккаунта сразу с кнопками ответа/отклонения и названием аккаунта. Переключение аккаунта не размонтирует его обработчик вызова. Windows раскрывает окно при входящем.
- Android: полноэкранные CallStyle-уведомления фоновых аккаунтов, окно ответа внутри приложения, явная привязка действий к аккаунту и звонку. Действующий разговор на другом аккаунте защищён от смены обработчика.
- [Обновление](UPDATE-0.12.35.md).

## 0.12.34

Если доступ пропал, появляется окно с прямым переходом в системные настройки. При выданных разрешениях окна нет; закрытое окно не повторяется при каждом запуске той же версии.

## 0.12.28

- Папки: общий цвет в модели Android/Web/Windows, цветные метки Windows, ссылки в выбранные управляемые группы и каналы. Ссылки действуют 7 дней, отзываются; перед вступлением получатель видит список и выбирает чаты. Личные переписки не передаются. Права владельца ссылки проверяются повторно при открытии и принятии.
- Все клиенты: личная отметка непрочитанного; очистка истории и скрытие чата только у себя с подтверждением. Старые сообщения исчезают из поиска, закреплений и ответов; новый входящий текст возвращает скрытый чат. История собеседников сохраняется.
- Web/Windows: до 5 аккаунтов, отдельные сеансы и уведомления, переключение по уведомлению, сохранение независимых черновиков. Web использует отдельные HttpOnly cookies, Windows — зашифрованное системное хранилище. Одна Web Push подписка принимает уведомления всех подключённых аккаунтов; продление сеанса сохраняет подписку.
- Windows: отдельные окна чатов; звонки из дополнительных окон передаются основному окну. IPC доступен только доверенным окнам и их главному фрейму. Сеансы обновляются между окнами через канал в памяти.
- Windows: «Игнорировать слово» до выхода, очистка временных исключений после сбоя; переключатель темы на первом уровне; раздельные действия создания группы/канала; категории эмодзи внизу и плотная сетка. Длинные названия папок показываются с многоточием.
- Звук/камера Web/Windows: можно использовать общий выбор устройств либо отдельные микрофон, камеру и выход для звонков. Добавлен переход к контактам по кнопке «Новый звонок».
- Сверка экранов, проверки и оставшиеся отличия описаны в SCREENSHOT-REVIEW.md. Групповые звонки и нативная ручная проверка Windows/Samsung остаются отдельными пунктами.

## 0.12.27

- Android: при системном звонке аудиофокус передаётся Telecom без конкурирующего запроса AudioManager; принятый входящий звонок активируется до подготовки WebRTC. В режиме приложения поддержано ожидание отложенного аудиофокуса, корректное освобождение маршрута и отмена при потере системного звука. Проверка Samsung Android 16 требуется на устройстве.
- Android: отдельные потоки сообщений/реакций всех сохранённых аккаунтов, независимые идентификаторы уведомлений, подавление только для открытого чата того же аккаунта. Входящие звонки невыбранных аккаунтов показываются отдельным уведомлением с переходом в нужный аккаунт; истечение одного сеанса не отключает остальные.
- Android/Web/Windows: жирный, курсив (`__` и `*`), подчёркнутый, зачёркнутый, моноширинный, блок кода с базовой подсветкой языка, спойлер, цитата, гиперссылка. Меню форматирования и Ctrl/Cmd+B/I/U/K; сохранение диапазонов пользовательских эмодзи и ограничение безопасных ссылок HTTP(S).
- Windows: нативное контекстное меню редактора, отмена/повтор, форматирование, предложения проверки орфографии и добавление в словарь. Web: контекстное меню форматирования и горячие клавиши.
- Android: редактор текста больше не отключается на время отправки; клавиатура и фокус остаются на месте, поле сразу освобождается для следующего сообщения.
- Отправляемый текст сразу появляется обычным пузырём с часами до подтверждения сервера. Убрана подсветка всей строки собственного текстового сообщения; переходы к закрепам и ответам продолжают подсвечивать найденное сообщение.
- Подтверждение отправки не стирает следующий набранный текст. При ошибке восстанавливается пустой редактор либо неотправленный текст сохраняется отдельно, с пользовательскими эмодзи и без потери следующего черновика.
- Windows: вертикальная панель папок со счётчиками, настройка и удаление по правой кнопке, добавление чата в папку из контекстного меню. Папки сохраняются в общем аккаунте.
- Эмодзи: всплывающее окно в узком Windows-клиенте, отдельная правая колонка в широком; кнопка закрепления/открепления. Закреплённая панель остаётся открытой при наборе текста.
- Windows: контакты, история звонков, настройки и профиль открываются компактными окнами; сохранены рабочие действия и текущая тема. Закрепления открываются списком в области чата, доступно открепление всех с подтверждением.
- Web/Windows: история аудио/видеозвонков в переписке, общий список с повторным вызовом и загрузкой следующих записей. Очистка скрывает завершённые записи только для владельца на всех его устройствах, сохраняя историю собеседников и текущие звонки.
- Звук и камера: выбор микрофона, камеры и выхода для следующих звонков; проверка микрофона с индикатором, предпросмотр выбранной камеры, локальное управление приёмом звонков; переход в системные настройки звука Windows.
- Web/Windows: отправляемый текст сразу освобождает поле; при задержке серверного ответа можно набирать следующий текст без потери фокуса или черновика. Неотправленное сообщение сохраняется в пузыре с повторной отправкой.
- Проверки: 136 Node-тестов, 68 Android unit-тестов и APK 12027; React render; браузерные сценарии Windows при ширине 1140/1436, темы, папки и контекстное меню, форматирование/ссылки/спойлеры/подсветка кода/отмена и повтор, закрепления/открепление, контакты и история/очистка, проверка микрофона и выбранной камеры, задержанная отправка; регрессия папок/уведомлений и двустороннего видео с тестовыми камерами и имитацией ICE. Установщик Windows собран и проверен по версии/контрольным суммам. Физический Android и интерактивная Windows 10 требуют проверки на устройствах.
- [Обновление одной вставкой](UPDATE-0.12.27.md), [подробности](DESKTOP-SEND-0.12.27.md).
