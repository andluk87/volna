# Обновление Волны до 0.12.28

Обновляются сервер, Android, Web и Windows: приглашения и цвета папок, личные действия с историей, несколько аккаунтов Web/Windows, независимые уведомления, отдельные окна Windows и доработки меню/устройств звонка. Сверка и открытые пункты: [SCREENSHOT-REVIEW.md](SCREENSHOT-REVIEW.md).

Запустите блок в прежнем каталоге Волны с `compose.yaml` и `.env`. Перед заменой исходников создаётся резервная копия данных. `.env`, данные и подпись Android сохраняются; не удаляйте `artifacts/android-home`. `VITE_API_URL` должен указывать на ваш настоящий HTTPS API. Облачные тестовые сборки с `example.invalid` устанавливать не нужно.

```sh
(
  set -eu
  test -f compose.yaml && test -f .env
  volna_update_dir=$(mktemp -d)
  trap 'rm -rf "$volna_update_dir"' EXIT
  git clone --depth 1 --branch v0.12.28 \
    https://github.com/andluk87/volna.git "$volna_update_dir/source"
  git -C "$volna_update_dir/source" archive \
    --output="$volna_update_dir/source.tar" HEAD
  sh "$volna_update_dir/source/scripts/backup.sh"
  tar -xf "$volna_update_dir/source.tar" -C .
  VOLNA_BUILD_NETWORK=host sh scripts/build-clients.sh
)
```

После сборки новый Android APK доступен на `/download/volna-android.apk`, установщик Windows — на `/download`. Тег GitHub сам по себе не обновляет сервер: этот блок собирает и публикует клиенты на вашем сервере.

При первом запуске новые таблицы/поля SQLite создаются автоматически. Если в браузере уже был вход, первый запуск переносит действующий сеанс в отдельный защищённый cookie аккаунта. Следующие аккаунты добавляются из главного меню по QR. Настройки → Уведомления позволяют выключить сообщения одного аккаунта без отключения остальных.

Проверьте на реальных устройствах: светлую/тёмную тему, прозрачность вокруг скруглённых панелей, иконки статус-бара; отправку с открытой клавиатурой; два аккаунта и переход по уведомлению; отдельное окно Windows и звонок из него; создание/отзыв приглашения; личную очистку истории с сохранением истории собеседника.

Групповые видеочаты до 200 участников не реализованы: для них нужен медиасервер SFU и соответствующий протокол всех клиентов. Коммерческие разделы Telegram не добавляются как фиктивные функции «Волны».
