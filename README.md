- Android: новая раскладка пузырей, доставка сообщений во время звонка и анимированная полоса вызова. Web/Windows: звонок сверху с перетаскиванием. Windows: до пяти уведомлений с текстом.

Мессенджер с нативным Android-клиентом Kotlin/Compose, Web, Windows/Electron и API на Node.js/SQLite. Вход: телефон и SMS через выбранного провайдера (Notificore или HTTP-шлюз) в Android; Web и Windows подключаются по QR после подтверждения на телефоне.

### Дополнительная доработка веб-оформления

Настройки веб-клиента переработаны по публичному исходному коду Telegram Web K: пять режимов темы, лента тем, отдельные страницы фона и цвета, загрузка и размытие обоев, энергосбережение, формат времени 12/24 часа. Дополнительные параметры Волны сохранены в сворачиваемом разделе. Сравнение, результаты проверок и оставшиеся различия: [design/reference/APPEARANCE.md](design/reference/APPEARANCE.md). Абсолютное визуальное совпадение с текущей опубликованной версией Telegram не подтверждено.

С 0.12.0 аккаунты и переписки сохраняются; сброс базы не нужен. **Первоначальный ник содержит номер телефона и публичен** — его можно изменить в профиле. Username не используется для входа.

В существующий `.env` добавьте `NOTIFICORE_API_KEY`, `NOTIFICORE_ORIGINATOR`, `SMS_REFERENCE_START` и `AUTH_TRUST_PROXY` из `.env.example`. Сохраните домен, TURN, настройки Whisper, volumes и ключ подписи Android.

Переход только с 0.11.x:

```sh
VOLNA_BUILD_NETWORK=host sh scripts/upgrade-phone-auth.sh
```

Последующие обновления:

```sh
VOLNA_BUILD_NETWORK=host sh scripts/build-clients.sh
```

Главная страница содержит ссылки на Android APK, Windows EXE и Web `/app`. Docker-сборщики сохраняют кэш зависимостей, подписывают Android существующим ключом и публикуют метаданные обновления. Устанавливаемые клиенты собираются на вашем сервере.

Сохранены переписки, голосовые сообщения и серверная расшифровка Whisper, звонки и демонстрация экрана, группы/каналы, профиль, вложения, эмодзи/стикеры/GIF и оформление. В публичном профиле отдельное поле телефона не выдаётся, но первоначальный ник содержит его. Username — публичный изменяемый ник с уникальностью без учёта регистра; вход по нему отсутствует. Телефон можно использовать для точного поиска после входа.
