# Volna / VLN 0.12.72

- Android: новая раскладка пузырей, доставка сообщений во время звонка и анимированная полоса вызова. Web/Windows: звонок сверху с перетаскиванием. Windows: до пяти уведомлений с текстом.

Мессенджер с нативным Android-клиентом Kotlin/Compose, Web, Windows/Electron и API на Node.js/SQLite. Вход: телефон и SMS через выбранного провайдера (Notificore или HTTP-шлюз) в Android; Web и Windows подключаются по QR после подтверждения на телефоне.

**Исправление сайта включено в 0.12.33:** если видна старая главная с демо, выполните [обновление](UPDATE-0.12.33.md). Для отдельного исправления сайта без пересборки клиентов сохранена [инструкция](UPDATE-SITE-FIX.md).

### Дополнительная доработка веб-оформления

Настройки веб-клиента переработаны по публичному исходному коду Telegram Web K: пять режимов темы, лента тем, отдельные страницы фона и цвета, загрузка и размытие обоев, энергосбережение, формат времени 12/24 часа. Дополнительные параметры Волны сохранены в сворачиваемом разделе. Сравнение, результаты проверок и оставшиеся различия: [design/reference/APPEARANCE.md](design/reference/APPEARANCE.md). Абсолютное визуальное совпадение с текущей опубликованной версией Telegram не подтверждено.

В 0.12.5 переработаны настройки оформления и панель эмодзи веб-клиента по открытой сессии Telegram Web K. Добавлены готовые темы, управление избранными эмодзи и редактирование названия/описания собственных наборов. Убрана рамка при вводе сообщения. Инструкция: [UPDATE-0.12.5.md](UPDATE-0.12.5.md).

С 0.12.0 аккаунты и переписки сохраняются; сброс базы не нужен. **Первоначальный ник содержит номер телефона и публичен** — его можно изменить в профиле. Username не используется для входа.

Только переход с 0.11.x требует новой базы аккаунтов: [UPDATE-0.12.0.md](UPDATE-0.12.0.md).

В существующий `.env` добавьте `NOTIFICORE_API_KEY`, `NOTIFICORE_ORIGINATOR`, `SMS_REFERENCE_START` и `AUTH_TRUST_PROXY` из `.env.example`. Сохраните домен, TURN, настройки Whisper, volumes и ключ подписи Android.

Переход только с 0.11.x:

```sh
VOLNA_BUILD_NETWORK=host sh scripts/upgrade-phone-auth.sh
```

Последующие обновления:

```sh
VOLNA_BUILD_NETWORK=host sh scripts/build-clients.sh
```

Главная страница содержит ссылки на Android APK, Windows EXE и Web `/app`. Docker-сборщики сохраняют кэш зависимостей, подписывают Android существующим ключом и публикуют метаданные обновления. Устанавливаемые клиенты собираются на вашем сервере.

Сохранены переписки, голосовые сообщения и серверная расшифровка Whisper, звонки и демонстрация экрана, группы/каналы, профиль, вложения, эмодзи/стикеры/GIF и оформление. В публичном профиле отдельное поле телефона не выдаётся, но первоначальный ник содержит его. Username — публичный изменяемый ник с уникальностью без учёта регистра; вход по нему отсутствует. Телефон можно использовать для точного поиска после входа.

Проверки: `npm test`, `npm run test:render`, `npm run build --prefix client`. Android требует Docker/SDK; проверка скобок Kotlin не заменяет компиляцию и тест на устройстве. Документы старых релизов сохранены как история; для актуальных сценариев используйте [инструкцию 0.12.10](UPDATE-0.12.10.md).

### Веб-интерфейс 0.12.2

Двухпанельный макет, адаптивная правая панель информации и вложений, папки чатов, поиск сообщений по всем чатам, обои, группировка сообщений и повторная отправка. Для локальной демонстрации: `/app?demo=1` (24 чата, 288 сообщений, реальные API-запросы с демо-токеном не выполняются). Демо не является клиентом Telegram.

Запуск разработки: `npm ci --prefix client && npm run dev --prefix client`. Сборка: `npm run build --prefix client`. Проверки: `npm test` и `npm run test:render`. Подробности обновления: [UPDATE-0.12.3.md](UPDATE-0.12.3.md).

### Emoji Engine Web MVP — 0.12.3

Статичные эмодзи прямо в редакторе и сообщениях, UTF-16 сущности, фирменные 24 эмоции, каталог, наборы, поиск ru/en, избранное, Unicode категории и тоны кожи. Документация API, форматов, миграций, модерации и границ этапов: [docs/emoji-engine.md](docs/emoji-engine.md).

### Web K — 0.12.4 (визуальная приёмка ещё не завершена)

Геометрия панелей по публичному исходному коду Web K, Roboto из локальных файлов, оригинальные SVG-иконки и рисунок фона с лицензией GPL-3.0. Отдельная область сообщений с пределом 696 px, группировка пузырей и хвостики, время на последней строке, раздельные поле и кнопка отправки, поиск и настройки внутри левой панели. Локальные пользовательские папки можно создавать, переименовывать и удалять. В демо работают опросы.

Визуальное совпадение с оригиналом в пределах ±2/±3 px не подтверждено: отсутствуют эталонные снимки переписки с одинаковыми данными; запуск Chromium в текущей среде завершается SIGTRAP. Матрица Playwright и процедура сравнения: [design/reference/README.md](design/reference/README.md). Перед установкой выполните браузерные проверки в обычной среде. Лицензии веб-клиента: [client/licenses/THIRD-PARTY.md](client/licenses/THIRD-PARTY.md).
