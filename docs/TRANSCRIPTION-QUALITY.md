# Локальное распознавание голосовых — 0.12.96–0.12.97

Основной профиль для русской речи — **GigaAM v3 E2E RNN-T, ONNX, float32, CPU**. Это отдельный движок вместо Whisper; он восстанавливает регистр и пунктуацию. Аудио обрабатывается внутри приватного контейнера `transcription`. Интернет используется при первой загрузке открытых весов, а не для отправки голосовых внешнему API. GPU, API-ключи и платные сервисы не нужны.

Модель и лицензия: [GigaAM](https://github.com/salute-developers/GigaAM), [ONNX-экспорт](https://huggingface.co/istupakov/gigaam-v3-onnx), [onnx-asr](https://github.com/istupakov/onnx-asr). Ревизия весов и версии библиотек закреплены. Это не обещание безошибочной расшифровки: преимущество на конкретных голосовых проверяется по эталонному тексту.

## Настройки CPU

```dotenv
ASR_ENGINE=gigaam
ASR_CPU_THREADS=auto
WHISPER_LANGUAGE=ru
WHISPER_FALLBACK_MODEL=off
```

`auto` учитывает CPU affinity и cgroup v2 quota, использует до 16 потоков. Для выделенного сервера можно явно задать `ASR_CPU_THREADS=32` (разрешено 1–64). Большее число потоков не гарантирует ускорения; увеличивайте по измеренному времени. Полные float32-веса занимают около 0,9 ГБ; с рабочей памятью и распознаванием разумно оставить несколько гигабайт свободной RAM. Это не измеренный верхний предел потребления. Docker volume `whisper-models` сохраняет обе модели между пересозданиями контейнера.

GigaAM получает моноаудио 16 кГц из исходных WAV/AAC/Opus без промежуточного сжатия. VAD с порогом 0,35 сохраняет короткую и тихую речь, добавляет по краям запас 450 мс и делит длинные записи по паузам с целевой максимальной длиной 22 секунды. Защитный предел входа модели — 24 секунды; длинное сообщение обрабатывается до конца. Шумоподавление, способное вырезать согласные, и LLM-переписывание текста не добавлены.

Скрытого перехода на `base` в новом профиле нет. Пока основная модель загружается, распознавание явно недоступно; чаты продолжают работать. `/health` — проверка живого процесса, `/ready` возвращает 200 только с готовой моделью. Проверяйте `engine:gigaam`, `active_model:gigaam-v3-e2e-rnnt`, `state:ready`:

```sh
docker compose exec -T transcription python -c 'import urllib.request; print(urllib.request.urlopen("http://127.0.0.1:8000/health").read().decode())'
docker compose logs --since=15m --timestamps transcription
```

При проблемах первой загрузки проверьте доступ сервера к Hugging Face и его хранилищу весов, свободный диск и права volume. Повторная загрузка после сбоя использует постоянный кэш. Логи содержат имя модели, время и безопасный тип ошибки, без голоса и текста расшифровки.

## Whisper и другие языки

GigaAM этого профиля предназначен для русского языка. Для смешанной или иной речи задайте в `.env` `ASR_ENGINE=whisper` и нужный `WHISPER_LANGUAGE`, например `auto`. Остаётся полная `large-v3`, float32, beam=10, patience=2, температура 0, более щадящий VAD; повторяющиеся подсказки из предыдущего фрагмента отключены. `WHISPER_CPU_THREADS` регулирует потоки этого движка. Whisper и GigaAM не загружаются одновременно в стандартном профиле.

`python3 scripts/improve-transcription.py` переводит прежний стандартный русский профиль на GigaAM. Явно заданный `ASR_ENGINE`, нестандартные модели/локальные пути и язык сохраняются. Для старых пользовательских путей и нерусского/автоматического языка выбирается Whisper. Старый стандартный `base`-резерв отключается. Перед изменением создаётся приватная копия `.env` в `backups/`; запись атомарная. Прочие секреты и TURN не меняются.

После правки `.env` пересоздайте сервис:

```sh
docker compose up -d --build --no-deps transcription
```

## Если у контейнера нет интернета

`Network is unreachable` означает сетевую недоступность, а не медленное распознавание. Можно скачать полный набор весов на другом устройстве, перенести в `artifacts/gigaam-v3/` и запустить `sh scripts/import-asr-model.sh`. Скрипт сначала проверяет реальную загрузку модели на CPU и только затем выбирает локальный путь в `.env`; резервная копия настроек сохраняется приватно. Не нужно менять сеть самого сервиса или открывать порт 8000. [Файлы и команды импорта](../UPDATE-0.12.97.md).

В 0.12.97 загрузчик не зависит от получения списка репозитория: используются точные имена файлов закреплённой ревизии. Health содержит `download.stage`, `current_file`, `completed_files`, `total_files`, `bytes_on_disk`. Если требуется только запуск после ручного импорта, интернет не нужен вовсе.

## Старые результаты

В Android, Windows и Web нажмите **«Распознать заново»** под раскрытым текстом. Простое открытие ранее сохранённой расшифровки показывает старый кэш и не проверяет новую модель. Прежний текст заменяется только при успешном ответе. Ошибка, тишина или загрузка модели не стирают старый результат. Проверки членства в чате, скрытых/удалённых сообщений и объединение одинаковых запросов сохранены.

## Проверки

Проверены реальные float32-веса на CPU: публичные примеры GigaAM длительностью 11,29 и 71,25 секунды, Ogg/Opus, WebM/Opus, M4A/AAC, запись с громкостью 5% от оригинала, тишина и повреждённый файл. Docker-контейнер с обычным непривилегированным пользователем работает с кэшем в режиме только чтения и отключённой сетью. Unit/HTTP тесты охватывают длинные фрагменты, конец записи, постоянный кэш, квоту CPU, готовность, ошибки и удаление временных аудиофайлов.

На исходной тестовой машине с четырьмя CPU-потоками два WAV обрабатывались примерно за 1,4 и 7,7 секунды. Это функциональная проверка на двух публичных записях, а не WER-бенчмарк и не прогноз для вашего CPU. На пользовательских голосовых точность пока не измерялась. Для честного сравнения нужны записи с эталонным текстом, особенно с именами, адресами, быстрым темпом и шумом.
