# Распознавание голосовых — 0.12.90–0.12.91

С 0.12.91 по запросу владельца основной профиль — `large-v3`, CPU `float32`, `beam=5`, 8 потоков (можно настроить до 32). Новая миграция переводит стандартные tiny/base/small/medium/large-v1/v2 в large-v3 и старый int8 в float32, сохраняя пользовательские локальные пути. CUDA не включена: предоставленные сведения показывают только виртуальный видеоадаптер и отсутствие NVIDIA Runtime.

Если `WHISPER_FALLBACK_MODEL=base` найдена в кэше, она временно обслуживает запросы во время загрузки/отказа основной модели. Она никогда не скачивается автоматически. Health: `ready:true,state:degraded,active_model:base` означает резерв; `state:ready,active_model:large-v3` — основную модель. Время загрузки и код ошибки доступны в health; журнал распознавания указывает фактически выбранную модель. После загрузки новые запросы используют основную модель, текущий запрос заканчивается на выбранной ранее. При отсутствии кэшированного резерва недоступность модели остаётся явной.

Ниже сохранены пояснения исходного перехода 0.12.90 на small; актуальная установка — [0.12.91](../UPDATE-0.12.91.md).

Распознавание остаётся локальным: исходная запись отправляется из API только в приватный контейнер Whisper. Платные внешние сервисы и отправка аудио стороннему API не добавлены.

Прежние настройки `base` / `beam=1` отдавали приоритет скорости на CPU. Новые значения по умолчанию — мультиязычная `small` и `beam_size=5`: более ёмкая модель и поиск нескольких вариантов декодирования. Язык по умолчанию остаётся русским. Для записи в клиентах уже заданы 48 кГц (AAC 128 кбит/с в Android, Opus 64 кбит/с в Web/Windows), поэтому её формат не менялся. VAD и отключение зависимости от предыдущего сегмента сохранены; искусственные подсказки и исправления слов поверх результата не добавлены.

Более ёмкая модель требует больше CPU/RAM и времени, а также загрузки новых весов в постоянный volume `whisper-models`. Пока идёт первая загрузка, API распознавания может отвечать «модель ещё загружается»; основной сервер и чаты остаются доступны. Старый кэш модели не удаляется.

## Настройки существующего сервера

Само изменение значений по умолчанию не перекрывает существующий `.env`. `python3 scripts/improve-transcription.py` меняет только старый быстрый профиль:

- отсутствующее / пустое значение модели, `tiny` или `base` → `small`;
- отсутствующее / пустое значение beam или `1` → `5`;
- пользовательские модели (`medium`, `large-v3`, локальный путь и т. п.), другие beam и язык сохраняются.

Перед изменением создаётся отдельная копия `.env` в `backups/` с правами 600. Остальные ключи, в том числе TURN, сохраняются. Запись атомарная, повторный запуск не создаёт изменений. Скрипт включён в команду обновления 0.12.90, автоматически при каждом обычном запуске сервера он не вызывается.

При достаточных ресурсах можно выбрать `WHISPER_MODEL=medium` вручную и пересоздать контейнер. Это не гарантирует исправление конкретных слов: нужен замер на ваших записях. Для смешанной речи доступен `WHISPER_LANGUAGE=auto`; на коротких русских фразах фиксированный `ru` обычно надёжнее определения языка.

Проверка профиля и готовности без вывода аудио или секретов:

```sh
docker compose exec -T transcription python -c 'import urllib.request; print(urllib.request.urlopen("http://127.0.0.1:8000/health").read().decode())'
docker compose logs --since=15m --timestamps transcription
```

В health должны быть `model: small`, `beam_size: 5`, `language: ru`, `ready: true` (или сохранённая пользовательская конфигурация). Логи содержат модель, язык, beam и длительность, без содержимого аудио и текста расшифровки.

## Повторная расшифровка

Нажмите кнопку «А» у голосового, затем **«Распознать заново»** под раскрытым текстом. Доступно в Android, Web и Windows renderer. Первое раскрытие сохранённого текста не запускает модель. Повтор отправляет `POST /api/messages/:id/transcribe {force:true}`, обходит кэш и заменяет результат только после успешного распознавания.

При ошибке, тишине или недоступной модели прежний текст не удаляется. Доступ ограничен участниками чата; удалённые и скрытые сообщения недоступны. Одновременные запросы одного сообщения используют общую задачу, действующий предел параллельного распознавания сохранён. Расшифровка общая для сообщения и обновляется у участников чата.

## Проверки и пределы результата

Проверены настройки декодера и health, загрузка/отказ модели, приватная миграция `.env`, принудительный обход кэша, права доступа, сохранение старого текста при ошибке, интерфейс повторной расшифровки. Эти тесты не заменяют оценку качества речи: в текущей среде не загружались реальные веса и не измерялся WER на пользовательских аудио.

Для сравнения возьмите несколько записей с тихой речью, быстрыми фразами, именами и фоновым шумом; сохраните эталонный текст, прежний результат и результат «Распознать заново». Сравните пропущенные/заменённые слова и время ответа. Имена, адреса и шумные записи могут требовать более крупной модели или более чистого источника. Заявлять численный прирост точности без такого сравнения нельзя.
