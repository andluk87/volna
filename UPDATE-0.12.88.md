# VLN 0.12.88 — все звонки только через TURN

Убрано сообщение «Звонок принят на другом устройстве»: остальные клиенты закрывают вызов без баннера ошибки.

Аудио, видео и демонстрация экрана используют только TURN. Прямой P2P-маршрут отключён в Android, Web и Windows renderer. Сервер всегда выдаёт `iceTransportPolicy:relay`, новые клиенты дополнительно закрепляют relay независимо от прежних настроек API. Старое сохранённое значение «выключено» игнорируется; переключатель заменён пояснением обязательного режима. Настройки «кто может звонить» и блокировки сохранены.

Если TURN не настроен, клиент показывает ошибку до открытия микрофона. При сетевой недоступности TURN звонок не переходит на прямое соединение и завершается по штатному таймауту. Шифрование WebRTC сохраняется. TURN несёт весь трафик, поэтому его пропускная способность и доступность теперь обязательны для каждого звонка.

Из прежней папки проекта с `compose.yaml` и `.env`, одной вставкой:

```sh
( set -eu; test -f compose.yaml && test -f .env; volna_update_dir=$(mktemp -d); trap 'rm -rf "$volna_update_dir"' EXIT; git clone --depth 1 --branch v0.12.88 https://github.com/andluk87/volna.git "$volna_update_dir/source"; git -C "$volna_update_dir/source" archive --output="$volna_update_dir/source.tar" HEAD; sh "$volna_update_dir/source/scripts/backup.sh"; if [ -d android-native/app/src ]; then mkdir -p backups; volna_source_backup=$(mktemp -d "$PWD/backups/android-source-0.12.88-XXXXXXXX"); mv android-native/app/src "$volna_source_backup/src"; fi; tar -xf "$volna_update_dir/source.tar" -C .; VOLNA_BUILD_NETWORK=host sh scripts/build-clients.sh )
```

Обновите **оба участвующих клиента** до 0.12.88, обновите страницу Web. Старые бинарные версии, которые ещё игнорируют ICE transport policy, не получают новое поведение автоматически. Уже идущие звонки завершите и начните заново. Сервер на вашей машине этим изменением из облака не обновляется — нужно выполнить команду выше.

Для вашего Docker оставлен `VOLNA_BUILD_NETWORK=host`, данные и ключи подписи сохраняются. При нехватке 4096 МиБ свободного места Windows-сборка остановится до запуска. Не удаляйте Docker volumes.

Проверьте аудио и видео между Android и Windows/Web через разные сети. В настройках должен отображаться текст «Все звонки — только через сервер TURN» без выключателя. Если соединения всё ещё не устанавливаются, проверяем TURN: TCP/UDP 3478, UDP relay-диапазон 49160–49200, правильный внешний IP и доступность со стороны обоих участников. Для сетей, блокирующих UDP/3478, нужен отдельно настроенный TURN TLS на TCP 443; [инструкция](docs/CALLS-1TO1.md#turn-и-эксплуатация). Переход на обязательный TURN сам по себе не исправляет закрытые порты или неверный адрес сервера.

Проверки: 226 Node-тестов, 202 Android unit/UI-теста, серверные тесты принудительной политики и старых предпочтений, Web/Windows UI-тест с API, предлагающим `all` (клиент всё равно создаёт `relay`), ошибка при отсутствии TURN, Android unit/UI suite и production-сборки. Физическая сеть и TURN на вашем VPS здесь не проверяются.
