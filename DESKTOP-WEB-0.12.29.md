# Windows и Web: доработка 0.12.29

Изучены официальные страницы [Telegram Desktop](https://desktop.telegram.org/) и [Telegram Web K](https://web.telegram.org/k/), актуальные публичные исходники:

- [Desktop: строки чатов](https://github.com/telegramdesktop/tdesktop/blob/dev/Telegram/SourceFiles/dialogs/dialogs.style): высота 62 px, отступы 10/8 px.
- [Desktop: главное меню](https://github.com/telegramdesktop/tdesktop/blob/dev/Telegram/SourceFiles/window/window_main_menu.style): ширина 274 px, профиль 134 px.
- [Web K: размеры колонок](https://github.com/TelegramOrg/Telegram-web-k/blob/master/src/helpers/updateColumnWidths.ts): ширина по умолчанию 360 px, диапазон 320–480 px, переписка до 696 px, внешний отступ 16 px.

Ранее присланные скриншоты Telegram Desktop использованы как образцы расположения меню, папок и правых панелей. Авторизованный интерфейс Telegram в этой сессии не исследован. Снимки Волны сделаны на демонстрационных данных; они подтверждают вид Волны, а не пиксельное совпадение с оригиналом.

## Что исправлено

| Проблема | Новое поведение |
|---|---|
| Старые стили занимали часть строки чата невидимой кнопкой меню | Строка и выделение занимают всю доступную ширину; кнопка меню находится поверх строки |
| В Web размер аватара перекрывался старыми правилами | Web — 54 px, Desktop — 46 px |
| Длинное имя ограничивалось 195 px независимо от ширины списка | Имя использует доступную ширину и сокращается при нехватке места |
| Список Windows автоматически разрастался до 34% окна | По умолчанию 392 px с панелью папок; ширина регулируется мышью и сохраняется отдельно от Web |
| Панели зависели от фиксированных порогов ширины окна | Информация и эмодзи учитывают реальную ширину левой колонки и место для переписки |
| Счётчики папок переносили цифры | Однострочный счётчик |
| Меню сообщений и вложений оставались открытыми после щелчка снаружи | Щелчок снаружи закрывает меню; Escape закрывает верхний элемент |
| Второй Escape перехватывала кнопка уже закрытого меню | Следующий Escape закрывает открытую панель, ответ или редактирование |
| Навигация между чатами игнорировала папку | Alt+↑/↓ учитывает текущий список; поддержано в обоих клиентах |
| Быстрое редактирование требовало меню | ↑ в пустом поле открывает последнее своё редактируемое сообщение; Escape отменяет |
| Настройки Web требовали меню | Ctrl/Cmd+, открывает настройки |
| Меню Windows использовало отдельный синий блок профиля | Профиль соответствует общей теме; настройки компактнее; ночной режим отображается переключателем |

Разделитель колонок доступен мышью и клавиатурой. ←/→ меняет ширину на 10 px, Shift — на 40 px, Home/End выбирает границы. Двойной щелчок сбрасывает ширину. В узком однооконном интерфейсе разделитель скрыт.

## Проверка

- `npm test`: 143 теста серверных и общих модулей.
- `npm run test:render`: рендеринг реальных React-компонентов.
- `node tests/column-layout-ui.mjs`: светлая/тёмная темы Web и Windows; ширина, сохранение, темы, меню, папки, клавиши, отсутствие горизонтального переполнения и панели на размерах 1920, 1436, 1366, 1140, 1024, 800 и 390 px.
- `node tests/windows-ui.mjs`: действующий API, форматирование, папки, панели эмодзи, закрепления, контакты, история звонков, выбор камеры и проверка микрофона, отправка с задержкой и сохранением следующего черновика.
- Сборки Web и Windows проверяются отдельно. На реальной Windows 10 запуск, масштабирование ОС, tray, системные уведомления и устройства требуют проверки.

Облачный установщик с `https://example.invalid` используется только для проверки сборки. Для установки соберите его с настоящим адресом сервера по [инструкции обновления](UPDATE-0.12.29.md).

Эта версия дорабатывает интерфейс и существующие действия Волны. Открытые функции из прошлой сверки, включая групповые видеочаты через SFU и истории профиля, перечислены в [SCREENSHOT-REVIEW.md](SCREENSHOT-REVIEW.md).
