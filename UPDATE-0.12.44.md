# Обновление Волны до 0.12.44

Android: возвращён прежний некруглый рисунок из 0.12.39. Системный launcher может применять собственную маску к адаптивной иконке. Web и Windows сохраняют круглое изображение. Генератор их значков больше не перезаписывает Android-ресурсы.

smallIcon уведомлений — пять белых PNG на прозрачном фоне: 24/36/48/72/96 px по плотностям. Ресурс drawable-nodpi удалён, идентификатор и механизм setSmallIcon сохранены. Это проверяемая попытка улучшить совместимость, а не подтверждённое исправление Huawei Watch.

Android скрывает первоначальный список до мгновенного перехода к последнему событию. Web/Windows устанавливают конец истории до показа списка и не возвращают старую позицию при обычном открытии. Поиск, переход к конкретному сообщению и загрузка старой истории сохраняются.

Выполните в прежнем каталоге сервера с compose.yaml и .env. Данные и подпись Android сохраняются. Облачный Debug APK использует тестовый API и не предназначен для установки пользователям.

```sh
(
  set -eu
  test -f compose.yaml && test -f .env
  volna_update_dir=$(mktemp -d)
  trap 'rm -rf "$volna_update_dir"' EXIT
  git clone --depth 1 --branch v0.12.44 \
    https://github.com/andluk87/volna.git "$volna_update_dir/source"
  git -C "$volna_update_dir/source" archive \
    --output="$volna_update_dir/source.tar" HEAD
  sh "$volna_update_dir/source/scripts/backup.sh"
  tar -xf "$volna_update_dir/source.tar" -C .
  VOLNA_BUILD_NETWORK=host sh scripts/build-clients.sh
)
```

Исходники публикуются отдельно от производственных сборок: сервер и установщики обновляет приведённая команда. Проверка часов в облаке недоступна.

Проверки: 161 Node-тест, 89 Android/JVM-тестов, успешные сборки Android Debug и Web. Браузерная проверка первого и повторного открытия чата: остаток прокрутки 0 px, ошибок JavaScript нет. Дополнительно проверены размеры PNG, белые видимые пиксели и прозрачные углы.
