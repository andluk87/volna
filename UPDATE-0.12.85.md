# VLN 0.12.85 — Windows: выделение фрагмента в полном клиенте

Исправлен автоматический перевод фокуса в поле ввода после отпускания мыши: он сбрасывал выделение текста.

Также найден конфликт: обработчик выделения целых сообщений в истории стирал нативное текстовое выделение, когда мышь выходила за пузырь. Теперь жест, начатый на тексте, остаётся текстовым. Выбор целых сообщений доступен через Ctrl/Shift, флажки и жест из свободного места.

В меню сообщения добавлена команда **«Выбрать фрагмент для цитаты»**: она открывает отдельное окно, где можно выделить текст и нажать «Цитировать фрагмент».

Из прежней папки сервера с `compose.yaml` и `.env`, одной вставкой:

```sh
( set -eu; test -f compose.yaml && test -f .env; volna_update_dir=$(mktemp -d); trap 'rm -rf "$volna_update_dir"' EXIT; git clone --depth 1 --branch v0.12.85 https://github.com/andluk87/volna.git "$volna_update_dir/source"; git -C "$volna_update_dir/source" archive --output="$volna_update_dir/source.tar" HEAD; sh "$volna_update_dir/source/scripts/backup.sh"; if [ -d android-native/app/src ]; then mkdir -p backups; volna_source_backup=$(mktemp -d "$PWD/backups/android-source-0.12.85-XXXXXXXX"); mv android-native/app/src "$volna_source_backup/src"; fi; tar -xf "$volna_update_dir/source.tar" -C .; sh scripts/build-clients.sh )
```

После сборки установите Windows 0.12.85 поверх прежней версии и полностью перезапустите VLN через выход из приложения в трее. Проверьте номер версии в настройках. Web перезагрузите через Ctrl+F5. Данные и вход сохраняются.

Проверка: выделите текст в пузыре и доведите курсор до его края — вместо текста не должны выбираться сообщения целиком. Нажмите правой кнопкой внутри фрагмента и выберите «Ответить с цитатой». Также попробуйте «Выбрать фрагмент для цитаты» без предварительного выделения.

Проверка выполняется на полном App в режиме Windows с настоящим тестовым API, включая отправку цитаты и чтение сохранённого фрагмента. Нативный Windows EXE в этой среде не запускается.

Проверено: 214 Node-тестов, render-тесты React, браузерные сценарии полного App и компонента цитат, сохранение выбора нескольких сообщений; сборки Web, интерфейса Windows и APK (~103 МиБ, четыре ABI, ниже 120 МиБ).
