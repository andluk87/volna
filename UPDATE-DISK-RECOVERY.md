# Продолжение обновления при нехватке места

Ошибка `no space left on device` при экспорте Web-образа означает нехватку места на разделе Docker/containerd. В журнале 0.12.38 Android и Windows уже собраны и опубликованы в каталоге загрузок; повторять их сборку не требуется. Скрипт остановился до замены работающих контейнеров.

1. В прежнем каталоге с `compose.yaml` и `.env` освободите неиспользуемый кэш сборки: `docker builder prune --all --force`. Команда удаляет кэш сборки Docker, последующие сборки могут занять больше времени. Контейнеры, тома, данные аккаунтов и подпись Android она не удаляет.
2. Запустите `python3 scripts/clean-windows-downloads.py`. Если старые исходники ещё не содержат этого файла, загрузите его из текущей ветки main репозитория. Скрипт сохраняет установщик из `latest.yml` и одну предыдущую версию. Удаляет только более старые файлы `Volna-Setup-*.exe` и их `.blockmap` в публичной папке Windows. Архивы сборок, `.env`, базы и подпись не затрагиваются.
3. Выполните `VOLNA_BUILD_NETWORK=host sh scripts/update.sh`, затем `sh scripts/check-downloads.sh all`. Это соберёт Web/сервер и продолжит запуск сервисов с уже подготовленными клиентами.

Если место всё ещё заканчивается, проверьте `df -h /`, `df -i /` и `docker system df`. Не используйте `docker system prune --volumes` и не удаляйте `artifacts/android-home` либо каталоги данных. При недостаточном освобождении места увеличьте диск/раздел Docker.

Очистка старых публичных установщиков включена перед следующей сборкой Web и после публикации Windows. Текущие исходники 0.12.38 в main содержат исправление; исторический тег v0.12.38 остаётся неизменным.
