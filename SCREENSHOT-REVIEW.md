# Сверка с присланными скриншотами

Образцы Windows — Telegram Desktop. Они задают ожидаемые действия и компоновку «Волны»; коммерческие разделы Telegram не являются функциями «Волны».

| Экран / состояние | Что сверено | Результат / оставшаяся проверка |
|---|---|---|
| Android: светлые и тёмные настройки | Скругление с первого кадра, прозрачное пространство вокруг панелей, статус-бар | Реализация прозрачных системных панелей и контрастных значков существует; окончательный вид на Samsung требует проверки на устройстве |
| Android: список чатов и контакты | Панель навигации, отступы прокрутки, кнопка нового сообщения | Исправления отступов существуют; физическое устройство ещё не проверено |
| Android: оформление | Шрифт, размер текста, масштаб интерфейса, верхняя панель | Настройки разделены; проверка на устройстве остаётся |
| Windows: папки | Редактирование, удаление, исключения, закрепления, порядок | Реализовано; длинные названия больше не разрываются посреди слова |
| Папки на всех клиентах | Цвет и метки | Добавлены общий формат хранения, выбор цвета и синхронизация; Android окрашивает название папки |
| Папки: приглашения | Группы/каналы, предварительный просмотр, выбор перед вступлением, отзыв | Добавлены сервер, Web/Windows и Android. Только управляемые сообщества; срок 7 дней. Автоматические правила и личные переписки не передаются |
| Windows: меню чата | Архив, закрепление, уведомления, добавление в папку | Существуют |
| Меню чата | Пометить непрочитанным, очистить историю, удалить из списка | Добавлены личные синхронизируемые действия; подтверждения прочтения не откатываются |
| Windows: отдельное окно чата | Действие из контекстного меню | Добавлено доверенное окно Electron; браузер проверяет запрос открытия, нативная проверка Windows остаётся |
| Windows: главное меню | Темы, профиль, контакты, звонки, настройки | Переключатель темы вынесен на первый уровень; добавлены до 5 аккаунтов и независимые уведомления |
| Windows: эмодзи | Плавающая/боковая панель, категории, поиск, вкладки | Панели существуют; размер эмодзи уменьшен, боковая сетка уплотнена. Категории перенесены вниз |
| Windows: закрепления | Баннер, просмотр всех, открепить все | Реализовано |
| Windows: редактор | Отмена/повтор, буфер, выделить всё, 9 форматов, горячие клавиши | Реализовано |
| Windows: орфография | Словарь, варианты исправления, игнорировать слово | Добавлено временное игнорирование с очисткой при выходе и после сбоя; нативное меню требует проверки в Windows 10 |
| Windows: звук и камера | Выбор устройств, уровень микрофона, приём звонков, системные настройки | Реализовано; добавлен общий/отдельный выбор устройств для звонков |
| Звонки | Двустороннее видео, темы, история в чате, повтор звонка | Реализовано для звонков один на один |
| Windows: повторные звонки одному контакту | Объединённая запись с числом вызовов | Отдельные вызовы отображаются; объединение повторов как на образце не реализовано |
| Групповые звонки | Новый групповой вызов, список активных видеочатов, до 200 участников | Ещё не реализовано. Нужен медиасервер SFU и новый протокол групповых звонков; текущий сервер поддерживает двух участников |
| Уведомления | Запрос при запуске, Web Push, Windows toast, Android полноэкранные вызовы | Реализовано; поведение прошивки и системных настроек проверяется на устройстве |
| Несколько аккаунтов | Независимые уведомления | Реализовано в Android/Web/Windows; проверены отдельные сеансы, истории, черновики и уведомления |
| Профиль | Аватар, имя, телефон, username, редактирование | Реализовано; истории и дата рождения как на образце не реализованы |

Серверные и браузерные сценарии: `npm test`, `npm run test:render`, `node tests/windows-ui.mjs`, `node tests/accounts-ui.mjs`, `node tests/folder-sharing-ui.mjs`. Сборки Android/Windows проверяются отдельно.

Проверки не являются подтверждением полного визуального совпадения на реальных Android/Windows устройствах. Сборки cloud с `https://example.invalid` предназначены только для проверки компиляции.

Проверка версии 0.12.28: 141 серверный тест и 69 тестов Android прошли; проверены рендеринг React, сценарии Windows, двух аккаунтов, приглашений в папки, уведомлений и двустороннего видео в браузерной среде. Android APK собран с versionCode 12028. Видео проверено с тестовыми камерами и имитацией ICE-соединения; качество реального соединения через TURN не подтверждено.
